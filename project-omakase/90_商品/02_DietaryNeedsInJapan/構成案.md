## ⚠ 安全上のルール（この商品を作る・直すときは必ず守る）

食物アレルギーは**命に関わる**。以下は例外なく守る。

1. **特定の商品・店・料理を「安全」と保証しない。** 原材料は予告なく変わる。教えるのは「何に注意するか」「どう読むか」「どう伝えるか」まで
2. **表紙の次のページに免責を大きく置き、カードのページにも再掲する**：
   *This guide is not medical advice. If you have a severe allergy, consult your doctor before travelling, carry your prescribed medication, and always confirm directly with staff.*
3. **食品表示制度の記述は、消費者庁または自治体の一次情報で確認してから書く。** 制度は改正される（実際に2026年4月に改正された）
4. **アレルギーカードの日本語は、あなた（ネイティブ）の確認が出品の条件。** 誤訳は事故に直結する
5. 「ハラル認証」について断定しない。ハラルの判断は宗派・個人で異なるため、**「判断材料を提供する」立場に徹する**

## 2. 確認済みの事実（出典つき・2026年10月20日確認）

### 2.1 食品表示制度（容器包装された加工食品）

| 区分 | 内容 |
| --- | --- |
| **特定原材料（表示義務）** | **9品目**：えび・**カシューナッツ**・かに・くるみ・小麦・そば・卵・乳・落花生（ピーナッツ） |
| 改正 | **2026年4月1日施行**で「カシューナッツ」が推奨→義務に。**経過措置は2028年3月31日まで**（この期間はカシューナッツの表示がない商品が流通し得る） |
| 前回の改正 | くるみが2023年3月に義務化（経過措置は2025年3月31日まで） |
| **特定原材料に準ずるもの（表示推奨＝任意）** | 約20品目。アーモンド、あわび、いか、いくら、オレンジ、キウイフルーツ、**牛肉**、ごま、さけ、さば、大豆、**鶏肉**、バナナ、**豚肉**、マカダミアナッツ、もも、やまいも、りんご、**ゼラチン**、**ピスタチオ（2026年4月追加）**。※2024年3月にマカダミアナッツ追加・まつたけ削除 |

> **ガイドで最も強調すべき点**：豚肉・牛肉・鶏肉・ゼラチン・ごま・大豆は**「推奨」であって義務ではない**。アレルギー表示欄にマークがないことは、含まれていないことを意味しない。**必ず原材料欄そのものを読む。**
> ※ 推奨品目の正確な一覧は出品前に消費者庁の最新資料で再確認すること（本表は自治体・関係機関の解説に基づく）

### 2.2 飲食店（外食）

- **飲食店には、アレルギー表示の法的義務がない。** 表示は事業者の任意の取り組み
- 消費者庁の2022年の調査で、患者団体の **67%** が外食で情報を「得られていない／あまり得られていない」と回答（中食は77%）
- → **ガイドの結論：飲食店では、表示がないことを前提に、カードで直接伝えて確認する**

### 2.3 ハラル・ベジで「隠れやすい」もの

| 隠れ方 | 例 |
| --- | --- |
| **だし（魚）** | 味噌汁、うどん・そばのつゆ、天つゆ、煮物、おでん、茶碗蒸し、多くのドレッシングや漬物（かつお節・煮干し・魚介エキス） |
| **豚由来** | ラーメンのスープ、餃子、とんかつ、カレールウ（動物性油脂）、**ゼラチン**（ゼリー・グミ・一部のパン・アイス）、**ラード**（揚げ物・菓子） |
| **アルコール** | **みりん・料理酒**（照り焼き、すき焼き、煮物、丼のたれ）、一部の調味料の「酒精」「アルコール」 |
| **表示で見落としやすい点** | 原材料欄の「/」より後ろは添加物。乳化剤・ショートニング等は動植物どちら由来か表示されないことがある |

> 「ベジタリアン向け」に見える野菜料理でも、だしで魚が入っていることが多い。**"vegetable" ≠ "vegetarian"** が日本の食の最大の落とし穴。

## 4. 日本語カード（案）— 作成時にあなたの確認が必須

**店員に見せる前提。** 1枚に1つの要件。丁寧で、誤解の余地がない言い方にする。

| # | 用途 | 伝える内容（英語の意図） |
| --- | --- | --- |
| 1 | ベジタリアン | 肉・魚を食べられません。**だし（かつお節・煮干し）も食べられません**。卵・乳は食べられます |
| 2 | ヴィーガン | 肉・魚・卵・乳・はちみつを食べられません。**だしも食べられません** |
| 3 | 魚介・だしのみ不可 | 魚介類とだし（かつお節・煮干し・魚介エキス）が食べられません |
| 4 | **ハラル（豚）** | 宗教上の理由で、**豚肉・豚由来の材料（ラード・ゼラチン・ポークエキス）**を食べられません |
| 5 | **ハラル（アルコール）** | 宗教上の理由で、**アルコール（みりん・料理酒を含む）**を口にできません |
| 6〜14 | **アレルギー（9品目それぞれ）** | 「私は〇〇の重いアレルギーがあります。少量でも症状が出ます」 |
| 15 | 微量・混入 | 同じ調理器具・油で調理したものも食べられません |

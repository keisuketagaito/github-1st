作成日：2026年7月28日（v2整合／指標を訪問店舗数からレシピ商品・検証済みレシピ・訪日セグメント比率へ差し替え）
関連：`02_KPIダッシュボード.xlsx`／`01_収支計画モデル.xlsx`／`../20_実行/02_タスク管理.md`

---

## 0. レビューの原則

**原則1：先行指標で判断し、遅行指標では判断しない。**

| 種別 | 指標 | 使い方 |
| --- | --- | --- |
| **先行指標** | メールリスト純増数、平均保存率 | **毎週の意思決定はこの2つだけで行う** |
| 中間指標 | LM登録率、フォロワー純増 | 先行指標が動かない原因の切り分けに使う |
| 遅行指標 | 売上、販売数、アフィリ収益 | 月次で確認。**週次で見て一喜一憂しない** |

**原則2：単週で判断しない。** 4週移動平均で見る。SNSの数値は1本のバズで簡単に倍になり、翌週半分になる。

**原則3：レビューは「数字を眺める会」ではなく「来週やることを3つ決める会」。** 決まらなかったらレビューをした意味がない。

## 1. 週次レビュー（日曜夜・30分）

### 手順

**① 数値入力（10分）**
`02_KPIダッシュボード.xlsx` の「週次実績」シートに、黄色セルを埋める。

| 入力項目 | 取得元 |
| --- | --- |
| メールリスト累計 | メール配信ツール |
| フォロワー累計（IG＋TikTok） | 各インサイト |
| 投稿本数 | 実績 |
| 平均保存率 | Instagramインサイト（保存数÷リーチ） |
| プロフィール訪問数 / LM登録数 | インサイト＋配信ツール |
| レシピ商品販売数 / 返金数 | Gumroad |
| アフィリエイト収益（食材・調理器具） | 各ASP管理画面 |
| 検証済みレシピ数（累積） | レシピデータベース |
| 投下時間（実測） | **必ず実測する。体感で書かない** |

**② AIに読ませる（5分）**
`../10_運用/03_AIプロンプト集.md` の **P-11** に該当週を貼り付け、要約・異常値・仮説・行動案を出させる。

**③ 判断（10分）**
AIの提案を鵜呑みにせず、以下を自分で決める。

- [ ] 先行指標（リスト純増・保存率）は4週移動平均で上向きか
- [ ] 下向きなら、原因は「到達」か「導線」か「商品性」か
- [ ] 来週やることを **3つ** 決める（増やさない）
- [ ] 投下時間が15時間を超えていないか → 超えていれば投稿本数を減らすか外注する

**④ ボード更新（5分）**
`../20_実行/02_タスク管理.md` を更新手順に従って書き換える。

### 週次で見る5指標

| # | 指標 | 目安 | 下回ったときの一次的な打ち手 |
| --- | --- | --- | --- |
| 1 | **メールリスト純増** | 計画比80%以上 | カルーセルの本数を増やす（Reelsより登録率が高い） |
| 2 | **平均保存率** | 3%以上 | 「役に立つ」情報の密度を上げる。フック（食材の置き換え）を見直す |
| 3 | LM登録率（プロフィール訪問→登録） | 15%以上 | プロフィール文とリンク導線を見直す |
| 4 | 投稿本数 | 週5本 | 在庫が切れている。まとめ撮り頻度の問題 |
| 5 | **投下時間** | 15時間以内 | 超過は最も危険な兆候。**放置すると6ヶ月目に必ず止まる** |

## 2. 月次レビュー（月末・3時間）

### 手順

**① KPI 7指標の記録（30分）**
`02_KPIダッシュボード.xlsx` の「月次サマリ」を確認。7指標は `../00_戦略/01_事業計画書.md` 9章に定義：①メールリスト純増 ②平均保存率 ③LM登録率 ④**訪日予定セグメント比率**（3ヶ月目に確定させる）⑤商品販売数・返金率 ⑥検証済みレシピ数（累積）⑦投下時間。

**② 予実差の確認（30分）**
`01_収支計画モデル.xlsx` の標準シナリオと実績を突き合わせる。

- 計画比 80%未満が2ヶ月続いたら、**計画ではなく前提を疑う**
- 前提条件シートの黄色セル（転換率・アフィリ単価・フォロワー成長）を実績値に置き換え、着地見込みを引き直す
- **計画を守るために無理をするのではなく、計画を実態に合わせる**

**③ コンテンツ分析（30分）**
- 伸びた投稿トップ3・伸びなかった投稿ボトム3を確認
- 共通点を言語化し、翌月の7本柱の配分に反映（`../00_戦略/04_マネタイズ設計.md` 1章）
- **保存率で見ること。** 再生数で見ると、実用性のない投稿を増やす方向に誤導される

**④ 収益構成比の確認（15分）**
単一収益源が50%を超えていないか。超えていれば分散の手を打つ。訪日セグメント向け商品は構成比4%が設計上の帰結（`../00_戦略/04_マネタイズ設計.md` 5章）。

**⑤ アフィリエイトの棚卸し（15分）**
収益ゼロのリンク（食材・調理器具）を差し替える。国別リンクが揃っているか確認。プロフィールのリンクは常時4つまで。

**⑥ 商品・食材置換表の更新（30分）**
読者からの「その食材が手に入らない」報告を確認し、食材置換表・レシピデータベースに反映。次回の代替検証リストへ回す。

**⑦ 翌月の計画（30分）**
- 翌月の献立テーマの決定（季節性を踏まえる：欧米豪は秋〜冬に自炊が増える。`../00_戦略/04_マネタイズ設計.md` 2章②）
- 翌月の重点（1つだけ決める。複数決めると全部中途半端になる）

## 5. レビューが形骸化する兆候と、その対処

| 兆候 | 意味 | 対処 |
| --- | --- | --- |
| 数値を入力するだけで終わっている | 判断していない | 「来週やること3つ」を必ず書く。書けないなら数値の見方が間違っている |
| 投下時間を体感で書いている | 最も危険。**過小に見積もる** | 実測する。実測しないなら、この指標は削除したほうがまだ良い |
| 2週続けてレビューを飛ばした | 事業が止まりかけている | 15分でよいので再開する。完璧なレビューより継続 |
| 毎週「様子見」と書いている | 意思決定を先送りしている | 4週続いたら、それは判断の先送りではなく判断の放棄。ゲート基準に照らす |
| 売上だけを見るようになった | 遅行指標に引きずられている | 先行指標2つに戻る |

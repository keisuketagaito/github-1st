# マネタイズ設計（コンテンツ × 収益の対応）

作成日：2026年7月27日
関連：`01_事業計画書.md`（4層モデルの全体像）／`03_媒体戦略.md`／`../30_管理/01_収支計画モデル.xlsx`

本書は「どのコンテンツが、どの収益に、どの時間軸で繋がるか」を1対1で対応させたもの。
事業計画書が「何で稼ぐか」を定義するのに対し、本書は **「何を作れば稼げるか」** を定義する。

---

## 0. 結論

**最初にマネタイズすべきは eSIM のアフィリエイト。** ガイド販売ではない。

理由は3つ。①全訪日客が必要とする、②単価が低く即決される（比較検討が入らない）、③季節性がない。フォロワー数千人の段階から収益が立つ唯一の収益源であり、**「1円でも稼げた」という事実が、6ヶ月間コンテンツを作り続けるための現実的な燃料になる。**

## 1. コンテンツ → 収益の対応表

| # | コンテンツ | 直接つながる収益 | 効き始める時期 | 制作コスト |
| --- | --- | --- | --- | --- |
| 1 | **実用系（eSIM・Suica・両替・現金事情）** | **アフィリエイト（最速）** | 2ヶ月目 | 低 |
| 2 | The Gauntlet（予約攻略の実演） | ガイド販売 | 5ヶ月目 | 中 |
| 3 | Walk With Me（1日動線） | ガイド販売＋アクティビティ・宿泊アフィリ | 5ヶ月目 | 高 |
| 4 | ¥1,000 vs ¥10,000（価格帯比較） | ガイド販売 | 5ヶ月目 | 中 |
| 5 | Don't Order That（作法・失敗回避） | ガイド販売（間接） | 5ヶ月目 | 低 |
| 6 | Ask a Local（DM質問への回答） | 商品仕様の源泉＋信頼 | 常時 | 低 |
| 7 | **店主インタビュー・長尺** | **タイアップ営業の実績資料** | 10ヶ月目 | 高 |
| 8 | 日本食を海外の食材で作る（レシピ変換） | 運用代行の営業材料 | 19ヶ月目 | 中 |

**「制作コストが低く、収益が早い」のは #1 と #5。立ち上げ期はここに寄せる。**
**「制作コストが高いが、単価の高い収益に繋がる」のは #3 と #7。中期に増やす。**

## 2. 収益源ごとの設計

### ① アフィリエイト（2ヶ月目〜／24ヶ月目の構成比 22%）

**最速で立ち上がる。ここを最初に置く。**

| 種別 | サービス | 転換率 | 備考 |
| --- | --- | --- | --- |
| **eSIM** | Ubigi / Airalo | **最高** | 全訪日客が必要。単価が低く即決。**最初に置くべき** |
| アクティビティ | Klook / GetYourGuide | 高 | 単価が高い。Walk With Me と相性が良い |
| 宿泊 | Agoda / Booking | 中 | 成果地点が「宿泊完了」のため入金が2〜3ヶ月遅れる |
| 鉄道パス | JR Pass 系代理店 | 低 | 単価は高いが対象者が限られる |

**運用ルール**
- プロフィールのリンクは **常時4つまで**。①リードマグネット（固定・最上位）②有料ガイド ③eSIM ④季節に応じて1つ
- 動画内でアフィリを直接訴求しない。リンクを見に来た人にだけ提示する
- **ガイドPDF内にもリンクを置く。購入者は最も行動意欲が高い層**
- 月次で収益ゼロのリンクを差し替える

**収益モデル**：フォロワー数 × 月間単価（標準 2.5円/人）。感度が高い前提なので、実績が出たらモデルを更新すること。

### ② デジタルガイド販売（5ヶ月目〜／構成比 25%）

商品ラダーと1店舗1ページの仕様は `01_事業計画書.md` 5章、ローンチ手順は `../10_運用/02_マーケティング運用マニュアル.md` 4章。

**販売数の計算式（モデルの中核）**

```
月間販売数 ＝ 当月の新規メール購読者 × 8%  ＋  既存リスト × 0.25%
             （ローンチ月のみ ＋ 既存リスト × 4%）
```

**「リスト全体 × 転換率」で見積もってはいけない。** 単品デジタル商品は既存リストに一度しか売れないため、その計算では必ず過大になる。売上を伸ばす手段は「リストへの売り込みを強める」ことではなく **「新規購読者を増やす」こと**——これがKPIをメールリスト純増に置く理由。

**販売の季節性**：購買は旅行の2〜4ヶ月前に起きる。桜（3〜4月）に来る客に売るなら販売ピークは **11〜12月**、紅葉（10〜11月）なら **6〜8月**。ローンチはこの逆算で置く。

### ③ 店舗・DMOタイアップ（10ヶ月目〜／構成比 21%）

**中期の本命。単価15万円/件。**

**営業の武器はフォロワー数ではなく「実際の来店数」。**
掲載店にクーポンコードや専用の予約経路を仕込んでおけば、「うちの読者が◯人来店した」が数字で言える。**この1点でタイアップ単価が2〜3倍変わる。** 初回掲載時から仕込むこと。

**営業の入口は、掲載前の一報。**
リスク対策（無断掲載のクレーム回避）と営業活動が同一動作になる。「掲載しました、こういう反応がありました」の報告が、そのまま次の商談になる。

**提案の順序**
1. 無償掲載 → 実績データを取る（0〜9ヶ月目）
2. 実績を持って有償タイアップを提案（10ヶ月目〜）
3. DMO・観光協会へ横展開（13ヶ月目〜。単価が上がり、複数店をまとめられる）

### ④ Itinerary Review（13ヶ月目〜／構成比 8%／$65）

**収益以上に、顧客理解の価値が大きい。**
実際の旅程を見せてもらうことで、「何が分からないか」が最も高い解像度で分かる。ガイドv2の仕様はここから作る。**収益が小さくても続ける理由がここにある。**

労働集約なので、月10件を上限とする。それ以上は受けない。

### ⑤ 運用代行（19ヶ月目〜／構成比 24%／月25万円）

料理系・グルメ系クリエイターの海外向けチャンネル運用を受託する。

**なぜ筋が良いか**
- 権利問題が発生しない（本人の依頼として正規に行う）
- 収益が安定する（月額）
- **A案で作った実績とノウハウがそのまま資産になる**

**なぜ19ヶ月目なのか**
提案が通るのは「自分のアカウントで結果を出した後」だから。実績がない状態での営業は通らない。**順序が逆になると成立しない収益源。**

## 3. 意図的に採らない収益化

| 選択肢 | 不採用の理由 |
| --- | --- |
| YouTube広告収益（AdSense） | 到達に時間がかかり単価も低い。Shortsは集客手段と割り切る |
| **他クリエイターのレシピをAI動画化** | ①レシピの手順自体は著作物でないが、動画・映像・構成は著作物であり依拠性が問題になる、②YouTubeが大量生産型AIコンテンツの収益化を明確に否定しており、資産が消える構造 |
| 月額サブスク・有料コミュニティ | 継続コンテンツの供給負荷が副業の稼働と両立しない。24ヶ月目に再検討 |
| 物販（Tシャツ等） | 利益率と在庫リスクが見合わない |
| 未訪問店を含めた網羅型データベース販売 | **商品の唯一の差別化を自ら壊す行為** |

## 4. 立ち上がりの順序（これを間違えると折れる）

```
2ヶ月目  eSIMアフィリ           → 初めての売上。金額は小さいが、継続の燃料になる
5ヶ月目  Tokyo Access Guide     → 商品が売れるかの検証
9ヶ月目  Osaka版                → 横展開が機能するかの検証
10ヶ月目 タイアップ初成約        → BtoB需要が実在するかの検証
13ヶ月目 Itinerary Review       → 顧客理解を深める
19ヶ月目 運用代行               → 安定収益化
```

各段階は**前段の検証が済んでから**進む。飛ばすと、需要のない商品を作る時間が発生する。

## 5. 24ヶ月目の収益構成（標準シナリオ・月商約106万円）

| 収益源 | 構成比 |
| --- | --- |
| デジタルガイド販売 | 25% |
| 運用代行（BtoB） | 24% |
| アフィリエイト | 22% |
| 店舗・DMOタイアップ | 21% |
| Itinerary Review | 8% |

**この分散こそが目標。** 単一収益源が50%を超えている状態は、プラットフォーム変更や需要変動で一撃を受ける。月次レビューで構成比を必ず確認し、偏りが出たら是正する。

## 6. マネタイズを壊す4つの行動（禁止事項）

1. **訪問していない店を載せる** — 差別化の根拠が消える。1件でも露見すれば全体の信用が落ちる
2. **プロフィールをアフィリリンクで埋める** — 信頼が落ち、結果として全収益が下がる
3. **返金を渋る** — 悪いレビュー1件の損失は、返金額の数十倍
4. **ローンチの締切を延長する** — 一度延長すると、以降どの締切も機能しなくなる

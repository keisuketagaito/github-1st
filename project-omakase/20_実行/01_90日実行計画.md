# 90日 実行計画（v2・家庭料理モデル）

作成日：2026年7月28日
稼働前提：週12〜15時間（週末5時間のまとめ撮り／火・木夜 各2h／日曜夜 2h）

**この90日のゴール（2つだけ）**

> ① **メールリスト 300件**を獲得する
> ② **訪日予定セグメントの比率を実測する**

売上はこの期間の目標に置きません。リストが育つ前に商品を出すと必ず滑ります。②は事業計画書3.3の最重要仮説で、**ここを12ヶ月後まで放置するのが最悪の失敗**なので、初月から計測を組み込みます。

> **期間の定義**：`../30_管理/01_収支計画モデル.xlsx` の「1ヶ月目」は**投稿を開始した月**を指します。本計画の Day 1〜30（在庫30本の撮り溜め期間）はモデルの対象外なので、カレンダー上は **モデルの月数 +1ヶ月** として読んでください。

## Week 1（Day 1–7）｜意思決定

- [ ] **本業の就業規則で副業条項を確認する**（ここが通らなければ全部止まる。最初にやる）
- [ ] アカウント名・ハンドルを決定（3プラットフォームで同一ハンドルが取れるもの）
- [ ] ポジショニング1文を英語で確定し、プロフィールに落とす
  - 例：`Japanese home cooking, translated into what you can actually buy where you live. Every recipe tested with substitutes.`
- [ ] Instagram / TikTok / YouTube 開設、プロフィール整備
- [ ] 競合20件をリスト化（`../40_資産/競合リサーチ`）
  - フォロワー数／投稿頻度／伸びている投稿／**商品を売っているか・価格**
  - **狙うのは「伸びているが食材の置き換えを体系化していない」領域**
- [ ] Gumroad アカウント開設（本人確認に時間がかかるので先に）
- [ ] メール配信ツールを開設。**登録フォームに「日本に行く予定はありますか？」を必ず入れる**
  - 選択肢：`Within 12 months / 1–2 years / Someday / No plans`
  - **この1問が、訪日商品を作るかどうかの判断材料になります**

**終了条件**：3プラットフォームのプロフィールが公開され、登録フォームに訪日質問が入っている。

## Week 2（Day 8–14）｜まとめ撮りの型づくり

- [ ] 撮影機材を購入・セットアップ（三脚2本＝定点＋手元、照明、マイク）
- [ ] **まとめ撮り1回目を実施**（3品。「良い動画を撮る」ではなく**型を検証する**のが目的）
- [ ] 献立の組み方を確立する
  - 選定基準は「作りたい料理」ではなく **「同じ調味料を使い回せる3〜4品」**。食材費と買い出し回数を決める最大要因
  - 例：醤油・みりん・だしで回す週 → 肉じゃが／親子丼／ほうれん草のおひたし
- [ ] レシピ記録テンプレートを作る（下記9項目をその場で埋める）
  - 材料（日本／海外で買えるもの／代替可）／分量（g＋cup）／手順／**失敗しやすい点**／保存可否／ベジ・ハラル・GF対応の可否
- [ ] **1本あたりの制作時間を実測する**（撮影〜編集完了）

**終了条件**：1本の動画が完成し、制作時間が数字で分かっている。

> **ここでの分岐**：1本の編集に90分以上かかるなら、投稿を週5から週3に落とすか、編集の型を単純化する。無理な本数計画で2ヶ月後に燃え尽きるのが最頻の失敗パターン。

## Week 3–4（Day 15–30）｜在庫を作る（投稿はまだしない）

- [ ] まとめ撮りを4回（週末2回 × 2週）→ **検証済みレシピ 20品**
- [ ] 動画を **30本**編集して保管
- [ ] 5本柱それぞれで最低4本ずつ作る
  - The Pantry（調味料の解説）／Weeknight（平日15分）／**Substitutions（代替食材の検証）**／Make It Work（ベジ・ハラル・GF）／Ask Me
- [ ] **代替食材の検証を最低5件行う**（みりん→？、だし→？、酒→？ など）
  - **必ず代替品で実際に作って食べる。** ここが competitor との唯一の差
- [ ] サムネイル・字幕のテンプレートを固定
- [ ] 英語ネイティブチェックの委託先を確保（月次固定契約で単価を下げる）

**終了条件**：**投稿在庫30本。** これがない状態で投稿を始めない。

> **なぜ在庫を先に作るか**：投稿開始後は自転車操業になり、撮影が1回飛ぶと投稿が止まる。アルゴリズムは連続性に強く反応するため、序盤の断絶が最も損失が大きい。30本＝約6週間分のバッファを持って始める。

**終了条件**：フォロワー合計 1,800／LM公開済／アフィリ導線が生きている。

| 指標 | 目標 | 実績 | 判定 |
| --- | --- | --- | --- |
| メールリスト | 300件 | | |
| LM登録率（プロフィール訪問→登録） | 15% | | |
| フォロワー合計 | 5,400 | | |
| 平均保存率（Reels） | 3%以上 | | |
| 検証済みレシピ数 | 55品 | | |
| 週あたり投下時間（実測） | 15h以内 | | |
| アフィリエイト月収 | 1万円以上 | | |
| **訪日予定セグメント比率** | **実測すること** | | |

**判定ルール**

| 状況 | 判断 |
| --- | --- |
| リスト300件以上 | Phase 2 へ。商品制作に着手 |
| 150〜299件 | **商品を出さずにもう60日リスト構築を続ける**（薄いリストへのローンチは返金率を上げ商品寿命を縮める） |
| 150件未満 | コンテンツの型かターゲット設定が誤っている。競合分析からやり直す |
| 投下時間が週15時間超 | 投稿本数を減らすか編集を外注。**放置すると6ヶ月目に確実に止まる** |
| **訪日比率 20%以上** | 訪日向け商品を15ヶ月目に投入（計画通り） |
| **訪日比率 10〜20%** | 商品化するが優先度を下げる |
| **訪日比率 10%未満** | **訪日商品・予約代行を計画から外し、レシピ商品の深化に全振り**（＝失敗ではなく、早期に正しい形へ寄せる判断） |

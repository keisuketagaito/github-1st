# 90日 実行計画
## Project OMAKASE — Phase 0（設計）＋ Phase 1 立ち上げ

作成日：2026年7月27日
起点：2026年8月1日（Day 1）と仮置き
稼働前提：週12〜15時間（火・木夜 各2h／週末 5h／日曜夜 2h）

> **期間の定義について**：`../30_管理/01_収支計画モデル.xlsx` の「1ヶ月目」は**投稿を開始した月**を指す。本実行計画の Day 1〜30（在庫30本の撮り溜め期間）はモデルの対象外なので、カレンダー上は **モデルの月数 +1ヶ月** として読むこと。

**この90日のゴール（1つだけ）**
> **メールリスト 300件**を獲得し、**週5投稿を4週連続で維持**する体制を作る。売上はこの期間の目標ではない。

売上を90日以内の目標に置くと、リストが育つ前に商品を出して滑る。この期間の唯一の仕事は「集客の再現性」と「取材の型」を作ること。

## Week 1（Day 1–7）｜意思決定

- [ ] 本業の就業規則で副業条項を確認する（**ここが通らなければ全部止まる。最初にやる**）
- [ ] アカウント名・ハンドルを決定（3プラットフォームで同一ハンドルが取れるものを選ぶ）
- [ ] ポジショニング1文を英語で確定させ、プロフィール文に落とす
  - 例：`Restaurants in Japan you can actually get into. Reservation steps, what to say, what to bring. Every place personally visited.`
- [ ] Instagram / TikTok / YouTube アカウント開設、プロフィール整備
- [ ] 競合アカウント20件をリスト化し、以下を記録
  - フォロワー数／投稿頻度／伸びている投稿の型／**商品を売っているか**／売っているなら価格
  - **狙うのは「伸びているが商品化していない」領域**。競合が既に売っている領域は避ける
- [ ] Gumroad アカウント開設（商品はまだ作らない。決済まわりの本人確認に時間がかかるため先に済ませる）
- [ ] メール配信ツールを選定・開設（無料枠のあるもの。〜1,000件は無料で足りる）

**Week 1 終了条件**：3プラットフォームのプロフィールが公開状態にある。

## Week 2（Day 8–14）｜取材の型づくり

- [ ] 東京の取材エリアを3つ選定する
  - 選定基準は「有名かどうか」ではなく **「徒歩圏に4〜6店が密集しているか」**。移動時間が工数の最大要因
  - 候補：新宿三丁目／神楽坂／人形町・浜町／恵比寿・広尾／立石・北千住（価格帯の幅が出る）
- [ ] 撮影機材を購入・セットアップ（ジンバル、指向性マイク、小型LED）
- [ ] **取材1回目を実施**（4店。ここは「良い動画を撮る」ではなく「型を検証する」のが目的）
- [ ] 取材メモのテンプレートを作る（下記の9項目をその場で埋める運用にする）
  - 予約手段／何日前から／海外番号可否／海外カード可否／支払い手段／現金のみか／タトゥー・子連れ・撮影の可否／滞在時間の目安／併せて行ける場所
- [ ] 撮影から編集完了までの実測時間を記録する（**1本あたり何分かかるかが、この事業の全計画の前提になる**）

**Week 2 終了条件**：1本の動画が完成し、1本あたりの制作時間が数字で分かっている。

> **ここでの分岐**：1本の編集に90分以上かかるなら、投稿本数を週5から週3に落とすか、編集の型を単純化する。無理な本数計画を立てて2ヶ月で燃え尽きるのが最頻の失敗パターン。

## Week 3–4（Day 15–30）｜在庫を作る（投稿はまだしない）

- [ ] 取材を4回実施（週末2回 × 2週）→ 累計 **20〜25店**
- [ ] 動画を **30本**編集して保管する
- [ ] 5本柱それぞれで最低4本ずつ作る
  - The Gauntlet（予約プロセス実演）／Don't Order That／¥1,000 vs ¥10,000／Walk With Me／Ask a Local
- [ ] サムネイル・字幕のテンプレートを固定する（毎回デザインを考えない仕組みにする）
- [ ] 英語ネイティブチェックの委託先を確保（クラウドソーシング可。**月次で固定契約にすると単価が下がる**）

**Week 4 終了条件**：**投稿在庫30本**。これがない状態で投稿を始めない。

> **なぜ在庫を先に作るか**：投稿開始後は「毎週撮る→編集する→出す」の自転車操業になり、取材が1回飛んだ瞬間に投稿が止まる。アルゴリズムは連続性に強く反応するため、序盤の途切れが最も損失が大きい。30本＝約6週間分のバッファを持って始める。

## Week 5–8（Day 31–60）｜発信開始

- [ ] **週5投稿を開始**（Reels 5本／TikTokは同一素材をリパーパス／Shorts 3本／カルーセル1本）
- [ ] 毎週の取材は継続（週末1回・4〜6店）→ 累計 **45店**
- [ ] 全コメント・DMに48時間以内に返信する（初期はここが最大の差別化になる）
- [ ] **DMで来た質問を全てスプレッドシートに記録する** → これがそのまま商品仕様になる
- [ ] リードマグネット「Tokyo 10 — with the exact reservation steps」を制作
  - 10店 × 標準フォーマット9項目、日本語スクリプト画像つき、10〜14ページ
  - **これは無料PDFだが、有料商品と同じ品質で作る**。ここの品質が有料商品の転換率を決める
- [ ] ネイティブチェックを通す
- [ ] Day 55 目標：LM完成・配信フロー（登録→自動送付）のテスト完了
- [ ] アフィリエイトプログラムに登録（Klook / GetYourGuide / Agoda / eSIM）、プロフィールリンクを整備（**リンクは4つまで**）

**Week 8 終了条件**：フォロワー合計 1,500／LM公開済／アフィリ導線が生きている。

> 収支モデルの1ヶ月目（＝Day 31〜60）の想定純増は標準シナリオで1,500人。Week 5–8 はこれに相当する。

## Day 90 レビュー（意思決定の場）

以下を数字で埋め、続行・修正・撤退を判断する。

| 指標 | 目標 | 実績 | 判定 |
| --- | --- | --- | --- |
| メールリスト | 300件 | | |
| LM登録率（プロフィール訪問→登録） | 15% | | |
| フォロワー合計 | 4,500 | | |
| 平均保存率（Reels） | 3%以上 | | |
| 訪問店舗数（累計） | 60店 | | |
| 週あたり投下時間（実測） | 15h以内 | | |
| アフィリエイト月収 | 1万円以上 | | |

**判定ルール**

- メールリスト 300件以上 → Phase 2 へ。商品制作に着手
- 150〜299件 → **商品を出さずに、もう60日リスト構築を続ける**（リストが薄いままローンチすると、返金率が上がりレビューが死に、商品の寿命が縮む）
- 150件未満 → コンテンツの型かターゲット設定が誤っている。競合分析からやり直す
- 投下時間が週15時間を超えている → 投稿本数を減らすか編集を外注。**この状態を放置すると6ヶ月目に確実に止まる**

## 90日間で「やらないこと」

着手前に明示しておく。これらは全て、この期間に着手すると失敗する。

- 有料商品の制作（Day 90 のレビューを通過してから）
- 2つ目のアカウントの開設
- 東京以外のエリアへの取材
- レシピ系コンテンツの本格投入（月2本のテストまで）
- 独自サイト・ブログの構築（SEOは効き始めるまで6〜12ヶ月かかる。今の稼働を割く先ではない）
- 法人化・開業届以上の手続き（初売上が立ってから）

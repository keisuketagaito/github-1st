## ファイルの正本はどこか

**Google ドライブが正本（日々の編集はドライブ側で行う）。このリポジトリは履歴の保管庫。**

| | Google ドライブ | このリポジトリ |
| --- | --- | --- |
| 役割 | 日々の作業・編集・共有 | 節目のスナップショットと変更履歴 |

> アップロード用のzipバンドルはこのリポジトリには置いていません。**古いzipが残ると、それ自体が3つ目の「正本もどき」になる**ためです。必要になったら、このフォルダをそのまま圧縮してください。

## 決まっていること（要約）

| 論点 | 決定 |
| --- | --- |
| **誰に** | 英語圏の**訪日2回目以降**のリピーター。初回訪問者は狙わない（無料情報で満足するため） |
| **どの国** | Tier 1＝米国・豪州・英国・シンガポール・カナダ。**韓国・中国本土は対象外** |
| **何語** | **英語1本**（米国表記）。ローカライズは3年目まで行わない |
| **どの媒体** | 主戦場 Instagram。TikTok／YouTube Shorts は転用。Pinterest は工数ゼロの中期資産。Reddit は発信せずリサーチに使う |
| **何を売る** | 「50選リスト」ではなく **「50店ぶんの入店攻略パック」**（$19）。1年間の無料アップデート付き |
| **最初の収益** | ガイド販売ではなく **eSIMアフィリエイト**（2ヶ月目〜） |
| **アカウント数** | **1つ。** 週3本×2媒体は週6本×1媒体に負ける |
| **やらないこと** | 他クリエイターのレシピのAI動画化（権利依拠＋YouTube収益化ポリシー抵触） |

判断の理由と経緯は `20_実行/02_タスク管理.md` の **意思決定ログ** に残してある。

**投下時間の上限は週15時間。** 超えたら投稿本数を減らすか外注する。放置すると6ヶ月目に必ず止まる。

## この事業を壊す6つの行動

1. **訪問していない店を載せる** — 唯一の差別化が消える
2. **「50店」を埋めるために基準を下げる** — 20店の高密度 > 50店の低密度
3. **2つ目のアカウントを開設する** — アルゴリズムはアカウント単位で学習する
4. **AIに一次情報を書かせる** — ハルシネーションが商品の根幹を壊す
5. **フォロワー数を成果として見る** — 意思決定を誤らせる。見るのはメールリストと保存率
6. **投下時間を体感で見積もる** — 必ず過小になり、気づいたときには止まっている

## AI活用の一行原則

> **AIに任せてよいのは「変換」。任せてはいけないのは「一次情報」。**

この線を守る限り、AIをどれだけ使っても事業は強くなる。越えた瞬間に壊れる。
週26時間ぶんの作業が6時間になり、**浮いた時間は必ず取材に投下する**（投稿本数の増加には回さない）。

詳細：`10_運用/01_AI運用設計.md` ／ 実物のプロンプト：`10_運用/03_AIプロンプト集.md`

## 表計算ファイルについて

| ファイル | 入力するセル |
| --- | --- |
| `30_管理/01_収支計画モデル.xlsx` | 前提条件シートの黄色セル（感度の高い主要前提） |
| `30_管理/02_KPIダッシュボード.xlsx` | 週次実績シートの黄色セルのみ |
| `40_資産/店舗データベース.xlsx` | 店舗DBシートの黄色（必須）・橙（任意）セル |

3つとも作成環境の制約でキャッシュ値を保存していないため、**開いた時点で全数式が自動再計算**される設定にしてあります。

**Google スプレッドシートに変換すれば、この制約は完全になくなります**（読み込み時に必ず全数式が計算されるため）。加えてスマホから入力できるようになり、**週次のKPI入力を移動中に済ませられる**のは実務上とても大きい利点です。変換手順は `10_運用/04_Googleドライブ運用ルール.md` 3章。

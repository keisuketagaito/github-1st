# Project OMAKASE

海外向け 日本家庭料理メディア／デジタルコンテンツ販売事業（副業）

最終更新：2026年7月28日（v2整合）

> **v2について**：本プロジェクトは元々v1「店舗取材モデル」（訪日リピーターに入店攻略パックを売る）だったが、47都道府県×50店＝2,350店の取材が副業では成立せず、出口が訪日客に限定され母数が小さいことから、2026年7月28日に**「自宅で制作する家庭料理レシピメディア」へ転換**した。v1一式は `50_アーカイブ/旧版_店舗取材モデル/` に保存。本READMEおよび各戦略ファイルはv2に整合済み。

## 1行で言うと

> **海外で日本食を"ちゃんと"作りたい人に、日本の家庭料理を「あなたの街で買える食材で作れる形」に翻訳して届ける。**

競合は「レシピ」を教える。我々は **「その食材をどこで買い、何で代替すればいいか」という買い物の意思決定** を売る。
みりんが売っていない、だしをどうするか、醤油の種類が多すぎる、計量単位が違う——ここは日本語レシピを英訳しても埋まらず、**実際に代替品で作って食べた人間しか書けない**。だから生成AIにも大手レシピサイトにも埋められていない。

## 決まっていること（要約）

| 論点 | 決定 |
| --- | --- |
| **誰に** | 英語圏（米・豪・英・加・星）の**28〜50歳・自炊習慣があり食に可処分所得を使う層**。**訪日予定の有無を問わない**（母数が訪日客より1〜2桁大きいことが核心） |
| **どの国** | Tier 1＝米国・豪州・英国・シンガポール・カナダ。選定軸は可処分所得×食支出×英語到達性×SNS利用率。**韓国・中国本土は対象外** |
| **何語** | **英語1本**（米国表記）。ローカライズは3年目まで行わない |
| **どの媒体** | 主戦場 Instagram。TikTok／YouTube Shorts は転用。Pinterest は工数ゼロの中期資産。Reddit は発信せずリサーチに使う |
| **何を売る（4層）** | ①食材・調理器具アフィリエイト（2ヶ月目〜）②**レシピデジタル商品（5ヶ月目〜・主軸）**③日本食ブランドのタイアップ（10ヶ月目〜・中期の本命）④訪日セグメント向け商品（15ヶ月目〜・**24ヶ月目でも売上の4%**） |
| **主力商品** | `Weeknight Japanese`（60レシピ＋食材置換表・$24）。1年間の無料アップデート付き |
| **最初の収益** | ガイド販売ではなく **食材・調理器具アフィリエイト**（2ヶ月目〜） |
| **アカウント数** | **1つ。** 週3本×2媒体は週6本×1媒体に負ける |
| **やらないこと** | **作って食べていないレシピの掲載**／他クリエイターのレシピのAI動画化（権利依拠＋YouTube収益化ポリシー抵触） |

**意思決定ゲート**：3ヶ月目（リスト300件・訪日比率実測）→ 6ヶ月目（レシピ商品初月30本・返金率5%未満）→ 12ヶ月目（月商25万円）→ 18ヶ月目（タイアップ3件）→ 24ヶ月目（月商80万円で法人化検討）。**3ヶ月目に訪日セグメントが10%未満なら、層④を計画から外しレシピ商品に全振り**（`01_事業計画書.md` 11章）。

判断の理由と経緯は `20_実行/02_タスク管理.md` の **意思決定ログ** に残してある。

## 運用のリズム

| 頻度 | 所要 | やること | 参照 |
| --- | --- | --- | --- |
| 週末（土 or 日） | 5.0h | **まとめ撮り**：買い出し1h＋調理・撮影4h で **3〜4品** | `01_事業計画書.md` 7章 |
| 火・木夜 | 各2h | 編集・字幕・投稿予約 | 同上 |
| 日曜夜 | 2h | 数値確認 → メール執筆 → コメント/DM返信 → **翌週の献立確定** | `30_管理/03_週次月次レビュー.md` |
| 月末 | 3h | 予実レビュー、翌月のテーマ決定 | 同上 |

**投下時間は週12〜15時間、上限15時間。** 超えたら本数を減らすか外注する。放置すると6ヶ月目に必ず止まる。
**v1との最大の違いは移動時間がゼロになったこと。** 自宅撮影で移動工数が消え、同じ時間でより多くの本数が出せる。

## この事業を壊す6つの行動

1. **作って食べていないレシピを載せる** — 唯一の差別化（実検証）が消える
2. **代替食材を検証せずに書く** — 読者が実際に失敗し、返金と信頼喪失に直結する
3. **家庭料理の観客に訪日商品を売り込む** — 転換率が崩れる。訪日商品は手を挙げたセグメントにだけ出す
4. **「60レシピ」を埋めるために品質基準を下げる** — 20の高密度 > 60の低密度
5. **2つ目のアカウントを開設する** — アルゴリズムはアカウント単位で学習する
6. **フォロワー数を成果として見る／投下時間を体感で見積もる** — 見るのはメールリスト純増と保存率。工数は必ず実測する

## AI活用の一行原則

> **AIに任せてよいのは「変換」。任せてはいけないのは「一次情報」。**

この線を守る限り、AIをどれだけ使っても事業は強くなる。越えた瞬間に壊れる。
一次情報とは「実際に代替食材で作って食べた検証」。**浮いた時間は必ず調理・検証に投下する**（投稿本数の水増しには回さない）。

詳細：`10_運用/01_AI運用設計.md` ／ 実物のプロンプト：`10_運用/03_AIプロンプト集.md`

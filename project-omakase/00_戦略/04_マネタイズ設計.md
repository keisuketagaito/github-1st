## 0. 結論

**最初にマネタイズすべきは食材・調理器具のアフィリエイト。**

レシピ動画とアフィリエイトの整合性が完璧だからです。「この醤油を使っています」「この鍋です」は、動画を見た人が最も自然に知りたい情報であり、売り込みになりません。**しかも視聴者が日本に来なくても成立します。**

そして最も重要な設計判断がこれです。

> **家庭料理の観客には、まず家庭料理の商品を売る。**
> 訪日向け商品は、手を挙げた部分集合にだけ、後から売る。

## 2. 収益源ごとの設計

### ① 食材・調理器具アフィリエイト（2ヶ月目〜／構成比 28%）

**最速で立ち上がり、視聴者が日本に来なくても成立する唯一の収益源。**

| 種別 | サービス | 転換率 | 備考 |
| --- | --- | --- | --- |
| **調味料・食材** | Amazon（US/UK/AU/CA）、Japan Centre、Bokksu 等 | **最高** | レシピ動画の直後に最も自然。単価は低いが件数が出る |
| 調理器具 | 包丁、土鍋、玉子焼き器、すり鉢 | 高 | **単価が高い。** 包丁は特に強い |
| 定期便 | 日本食材のサブスクEC | 中 | 継続報酬型があり、積み上がる |
| 書籍 | 和食の英語レシピ本 | 低 | 補助的 |

**運用ルール**
- プロフィールのリンクは **常時4つまで**。①リードマグネット（固定・最上位）②有料商品 ③今月の食材リスト ④季節もの1つ
- **動画内でアフィリを直接訴求しない。** 「使っている道具はプロフィールから」で十分
- **国別リンクを用意する。** Tier 1が5カ国に分かれているため、US向けリンクだけだと豪・英・加の売上を落とす
- 商品PDF内にもリンクを置く（購入者は最も行動意欲が高い）
- 月次で収益ゼロのリンクを差し替える

**収益モデル**：フォロワー数 × 月間単価（標準 3.0円/人）。旅行系（2.5円）より高く置いている。**購買行動が視聴と地続きで、季節性もないため。**

### ② レシピデジタル商品（5ヶ月目〜／構成比 39%／主軸）

**販売数の計算式**

```
月間販売数 ＝ 当月の新規メール購読者 × 10%  ＋  既存リスト × 0.3%
             （ローンチ月のみ ＋ 既存リスト × 4.5%）
```

v1の8%から10%へ引き上げている。**理由は観客と商品が一致しているから。** レシピを見に来た人にレシピ商品を売るので、旅行商品を売るより素直に通る。**これがモデル転換の最大の経済効果。**

**「リスト全体 × 転換率」で見積もってはいけない。** 単品デジタル商品は既存リストに一度しか売れない。売上を伸ばす手段は「リストへの売り込みを強める」ことではなく**「新規購読者を増やす」こと**——これがKPIをメールリスト純増に置く理由。

**商品ラダー**

| 商品 | 価格 | 狙い |
| --- | --- | --- |
| Weeknight Japanese（60レシピ＋食材置換表） | $24 | 主力 |
| Dashi & Fundamentals | $29 | 単価引き上げ・上位層 |
| バンドル | $45 | 客単価の底上げ |

**季節性**：欧米豪は**秋〜冬（10〜2月）に自炊が増える**。ローンチはこの手前、9〜10月に置くのが最も効率が良い。

### ③ 日本食ブランドのタイアップ（10ヶ月目〜／構成比 29%／中期の本命）

**v1の飲食店・DMOより、こちらのほうが市場が大きい。**

海外展開したい日本の食品・調味料・調理器具メーカーは、**英語で日本食を発信するチャネルを探している**が、供給が少ない。訪日インバウンドのDMO予算より、食品メーカーの海外販促予算のほうが規模が大きく、かつ継続的です。

| 相手 | 例 | 単価目安 |
| --- | --- | --- |
| 調味料メーカー | 醤油・味噌・みりん・だしの海外向けブランド | 15〜30万円/件 |
| 調理器具メーカー | 包丁、鉄鍋、土鍋 | 20〜40万円/件 |
| 日本食材EC | 海外向け通販事業者 | 10〜20万円/件＋成果報酬 |
| 自治体・JETRO系 | 食品輸出プロモーションの補助事業 | 案件による |

**営業の武器はフォロワー数ではなく「アフィリエイト経由の実売数」。**
「うちの読者がこの醤油を月◯本買っている」と数字で言えるかどうかで単価が2〜3倍変わります。**だから①のアフィリエイトを、収益源としてだけでなく実績データの生成装置として初期から仕込む。**

### ④ 訪日セグメント向け商品（15ヶ月目〜／構成比 4%）

リスト内の訪日予定層にのみ販売。$19。

**3ヶ月目の実測が10%未満なら、この層は計画から外す。** 詳細は `01_事業計画書.md` 3.3。

### ⑤ 予約代行（20ヶ月目〜・任意）

**レストラン予約のみなら旅行業登録は不要**です。ただし**運送・宿泊の手配とセットにすると旅行業に該当し得る**ため、その線を絶対に越えない。

粗利は極めて高い（原価は電話代のみ）が労働集約なので**月10件を上限**とする。訪日セグメントが十分に育った場合のオプションであり、計画の前提には置かない。

なお通訳・アテンドは2018年の通訳案内士法改正により無資格でも有償で可能ですが（「全国通訳案内士」の名称は使用不可）、人材確保とスケジューリングが必要な実質的な人材事業であり、**副業の稼働では回らない**ため計画に含めない。

## 3. 意図的に採らない収益化

| 選択肢 | 不採用の理由 |
| --- | --- |
| YouTube広告収益（AdSense） | 到達に時間がかかり単価も低い。Shortsは集客手段と割り切る |
| **他クリエイターのレシピのAI動画化** | レシピの手順自体は著作物でないが、動画・映像・構成は著作物であり依拠性が問題になる。加えてプラットフォームが大量生産型AIコンテンツの収益化を否定している |
| 月額サブスク・有料コミュニティ | 継続コンテンツの供給負荷が副業と両立しない。24ヶ月目に再検討 |
| 料理教室・オンラインレッスン | 時差が最大の障害。Tier 1が5カ国に分かれているため開催時間が組めない |
| 物販（調味料キット等） | 在庫・配送・食品表示規制。副業では扱えない。**ただし24ヶ月目以降・法人化を検討する段階で再検討する**（`../40_資産/他文化圏モデル研究_202608.md`：Maangchiが2026年に「Korean pantry essentials」の物販ラインへ実際に拡張した実例あり。「The Japanese Pantry」ブランドは物理パントリーキットへ拡張できる方向性が実例で裏付けられている。**今すぐ着手はしない**——在庫・配送・食品表示規制を法人の体制で扱える段階になってから） |

## 4. 立ち上がりの順序

```
2ヶ月目  食材アフィリエイト     → 初めての売上。金額は小さいが継続の燃料になる
5ヶ月目  Weeknight Japanese    → 商品が売れるかの検証
10ヶ月目 ブランドタイアップ初成約 → BtoB需要が実在するかの検証
11ヶ月目 Dashi & Fundamentals  → 単価引き上げが効くかの検証
15ヶ月目 訪日セグメント商品     → 3ヶ月目の実測が10%以上の場合のみ
20ヶ月目 予約代行              → 任意
```

各段階は**前段の検証が済んでから**進む。飛ばすと、需要のない商品を作る時間が発生する。

## 5. 24ヶ月目の収益構成（標準・月商約104万円）

| 収益源 | 構成比 |
| --- | --- |
| レシピデジタル商品 | 39% |
| 日本食ブランドのタイアップ | 29% |
| 食材・調理器具アフィリエイト | 28% |
| 訪日セグメント向け商品 | **4%** |

**訪日セグメント向け商品が4%にとどまる点は、設計の帰結として受け止めてください。** 家庭料理の観客を集める以上、訪日層は部分集合にしかならず、そこに大きな売上を期待すると判断を誤ります。この4%を大きくしたいなら、コンテンツ型を訪日寄りに変えるしかありません。

単一収益源が50%を超えている状態は、プラットフォーム変更や需要変動で一撃を受けます。月次レビューで構成比を確認し、偏りが出たら是正すること。

## 6. マネタイズを壊す5つの行動

1. **作って食べていないレシピを載せる** — 唯一の差別化が消える。特に代替食材は、検証せずに書くと必ず失敗報告が来る
2. **家庭料理の観客に旅行商品を押し売りする** — 転換率が崩れ、リスト解除が増える
3. **プロフィールをアフィリリンクで埋める** — 信頼が落ち、結果として全収益が下がる
4. **返金を渋る** — 悪いレビュー1件の損失は返金額の数十倍
5. **ローンチの締切を延長する** — 一度延長すると、以降どの締切も機能しなくなる

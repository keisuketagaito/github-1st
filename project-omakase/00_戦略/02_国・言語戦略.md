# 国・言語戦略

作成日：2026年7月27日
関連：`01_事業計画書.md` / `03_媒体戦略.md` / `04_マネタイズ設計.md`

---

## 0. 結論

**言語は英語（米国表記）1本。ローカライズは3年目まで行わない。**
**国は「訪日者数」ではなく「1人あたり支出 × 英語到達可能性 × 訪日頻度」で選ぶ。Tier 1 は米国・オーストラリア・英国・シンガポール・カナダの5市場。**

訪日客数が最も多い韓国・中国本土は、**意図的に対象外とする。**

## 2. 市場のTier分け

### Tier 1｜初期に集中する5市場（英語・そのまま届く）

| 国 | 選ぶ理由 | 注意点 |
| --- | --- | --- |
| **米国** | 訪日者数330万人と英語圏最大。デジタル商品を$で買う習慣が定着。$19の心理的抵抗が最も低い | 初回訪日者の比率が高い＝リピーター層を選別する必要 |
| **オーストラリア** | 1人あたり支出が世界最上位クラス（約39万円）。滞在日数が長く、food-motivated。時差が小さく投稿時間が組みやすい | 市場規模が小さい（100万人） |
| **英国** | 1人あたり支出が世界2位（約39万円）。食メディアへの支出習慣がある | 訪日者数が少なく、成長は緩やか |
| **シンガポール** | **訪日頻度が突出（年複数回のリピーター比率が高い）**。英語が公用語。食への関心と解像度が極めて高い。時差1時間 | 短期滞在が多く、エリア特化型の商品が刺さる |
| **カナダ** | 米国と行動様式がほぼ同じで、追加コストゼロで取れる | 単独では規模不足 |

**Tier 1 の共通点は「英語ネイティブまたは英語での購買が自然」かつ「支出単価が高い」こと。** 同一コンテンツ・同一商品で5市場すべてをカバーできるため、追加コストがかからない。

### Tier 2｜同じ英語コンテンツで自然に流入する市場（狙わないが歓迎する）

香港／マレーシア／ニュージーランド／アイルランド／オランダ／北欧／**ドイツ**

- ドイツは1人あたり支出が世界1位（約39.3万円）だが、ドイツ語圏。ただし**英語運用率が高いため英語コンテンツでも一定届く**。ローカライズせずに取れる分だけ取る
- これらは「取りにいかないが、来たら顧客として扱う」層。商品の対応通貨をUSDに統一しておけば購入の障壁はない

### Tier 3｜意図的に対象外とする市場

| 市場 | 除外の理由 |
| --- | --- |
| **韓国** | 訪日者数は最大級だが、①短距離・短期・低単価、②韓国語圏で英語コンテンツが届かない、③情報流通がNAVER等の独自圏 |
| **中国本土** | ①プラットフォームが完全に別（小紅書・抖音）、②決済が別（WeChat Pay / Alipay）、③1人あたり支出は前年比11%減。**参入するなら別事業として設計すべきで、片手間では成立しない** |
| **台湾** | 訪日頻度は極めて高く魅力的だが、繁体字が必要。**3年目に単独で検討する価値がある唯一の非英語市場**（下記4章） |
| タイ・ベトナム・インドネシア | 単価が低く、有料デジタル商品の購買習慣が薄い |

**除外は「価値がない」という意味ではなく、「限られた稼働をどこに置くか」の判断。** 副業の週15時間を分散させた瞬間に、どの市場でも勝てなくなる。

## 3. 言語戦略

### 3.1 英語1本にする理由

1. **Tier 1 の5市場を1つのコンテンツでカバーできる**（追加コストゼロ）
2. Tier 2 の英語運用層にも自動的に届く
3. **更新コストが決定的に違う**。閉店・予約手段変更の反映を四半期ごとに行う商品なので、言語がn個あれば更新コストもn倍になる。差別化要素である「更新され続けること」が、多言語化した瞬間に破綻する
4. 翻訳品質の担保コスト（ネイティブチェック）が言語数に比例する

### 3.2 英語の「種類」

| 項目 | 方針 |
| --- | --- |
| 綴り | **米国式**（color, traveling）。最大市場に合わせる |
| 通貨表記 | **USD基準**、日本円を併記（`¥12,000 / approx. $80`）。為替は四半期ごとに更新 |
| 日付 | 誤解を生まない形式（`March 3` / `2027-03-03`）。`3/3` は使わない |
| 料理名 | **ヘボン式ローマ字＋短い説明**（`Yakitori — grilled chicken skewers, charcoal`）。イタリック等で統一 |
| 敬体 | フレンドリーだが断定的に。旅行者は「判断」を求めている。`you might want to` より `do this` |
| 数量・距離 | メートル法を主、`(≈ 5 min walk)` で体感を補う |

### 3.3 やらないこと

- 機械翻訳の自動多言語展開（品質が担保できず、返金率とレビューに直結する）
- SNSアカウントの言語別分割（アルゴリズムがアカウント単位で学習するため、分割は純粋な損失）

## 4. ローカライズの判断ゲート（3年目）

**唯一検討に値するのは繁体字（台湾・香港）。** ただし着手は以下を全て満たした場合に限る。

- [ ] 英語版の月商が70万円を安定的に超えている
- [ ] 台湾・香港からのアクセスが全体の15%以上ある（英語のまま来ている＝需要の証明）
- [ ] 繁体字ネイティブの協力者を確保できている（自分で書かない）
- [ ] 更新体制（四半期ごとの改訂）を2言語で回せる目処がある

1つでも欠けたら着手しない。**英語版の深化のほうが常に投資対効果が高い。**

## 5. 国別の運用への落とし込み

### 5.1 投稿時間（日本時間）

Tier 1 の5市場は時差が大きく分かれるため、**1日2枠に集約する**のが最も効率的。

| 枠 | 日本時間 | カバーする市場 |
| --- | --- | --- |
| **朝枠** | **09:00〜10:00 JST** | 米国東部（前夜20〜21時）／米国西部（前夜17〜18時）／カナダ |
| **夜枠** | **20:00〜21:00 JST** | シンガポール（19〜20時）／オーストラリア東部（21〜22時）／香港・マレーシア |

英国は朝枠（現地01:00）・夜枠（現地12:00）ともにずれるが、**規模が小さいため専用枠は設けない**。Instagramのレコメンドは投稿時刻より初速に反応するため、英国分は取りこぼしを許容する。

> 投稿時間は仮説。3ヶ月分の実データが溜まった時点で、インサイトのフォロワーアクティブ時間で検証し直すこと。

### 5.2 季節性（コンテンツ計画の骨格）

| 時期 | 訪日の山 | 出すべきコンテンツ |
| --- | --- | --- |
| 1〜2月 | 豪州（夏休み）、シンガポール（旧正月） | 冬の鍋・おでん・カニ、スキー地の食 |
| 3〜4月 | 桜（全市場のピーク） | **最大の商戦期。ローンチはここに合わせる**。花見の食、混雑回避 |
| 6〜8月 | 米国（夏休み）、豪州（冬休み） | 夏の食、かき氷、ビアガーデン、暑さ対策 |
| 10〜11月 | 紅葉（欧米豪のピーク） | **第2の商戦期**。秋の味覚、松茸、新蕎麦 |
| 12月 | 年末年始 | おせち、年越しそば、正月の営業状況 |

**購買は「旅行の2〜4ヶ月前」に起きる。** つまり桜シーズン（3〜4月）に来る客に売るなら、**販売のピークは11〜12月**。商品ローンチはこの逆算で置くこと。

### 5.3 市場別に効くコンテンツの違い

| 市場 | 特に反応する切り口 |
| --- | --- |
| 米国 | 「観光客がいない店」「予約が取れない店」。希少性の訴求が最も効く |
| オーストラリア | 「地方・郊外」「長期滞在向け」。滞在日数が長いため東京以外の需要が早い |
| 英国 | 「文化・歴史の背景」。なぜこの店がこうなのかの説明を好む |
| シンガポール | 「価格対品質」「同カテゴリ比較」。食の解像度が高く、比較コンテンツが最も刺さる |
| カナダ | 米国と同傾向。差別化不要 |

**この差は、コンテンツを分けるのではなく「5本柱の配分」で吸収する。** アカウントは分けない。

## 6. この戦略が外れるとしたら（前提の脆さ）

| 前提 | 外れる条件 | 検知方法 |
| --- | --- | --- |
| 英語1本でTier 1をカバーできる | 米国からの流入が想定の半分以下 | 3ヶ月目にInstagramインサイトの国別分布を確認 |
| 単価の高い市場ほど有料商品を買う | 支出は現地消費に向かい、事前のデジタル購入はしない | 6ヶ月目のローンチで購入者の国別分布を確認 |
| 訪日リピーターが課金する | 実は初回訪問者のほうが不安が大きく課金する | 購入時アンケートで「訪日回数」を必ず取る |

**3ヶ月目・6ヶ月目のチェックポイントで、この3つを必ず実データで検証する。** 外れていた場合はTier定義を組み直す。

# 国・言語戦略

作成日：2026年7月28日（v2整合／国選定ロジックを「訪日頻度」から「家庭料理課金層の厚さ」へ組み直し）
関連：`01_事業計画書.md` / `03_媒体戦略.md` / `04_マネタイズ設計.md`

> **v1からの変更点**：v1は「訪日リピーターに入店攻略情報を売る」モデルだったため、国選定の主軸を訪日者数・訪日頻度に置いていた。v2は「訪日予定の有無を問わない、日本食を家で作りたい英語圏の自炊層」を顧客とするため（`01_事業計画書.md` 3章）、**訪日データを主軸から外し、参考情報に格下げした。** 選定軸を家庭料理コンテンツの課金可能性で組み直している。**結論（英語1本・Tier 1＝米豪英星加）は維持されるが、その根拠が入れ替わっている点が本改訂の要点。**

---

## 0. 結論

**言語は英語（米国表記）1本。ローカライズは3年目まで行わない。**
**国は「訪日頻度」ではなく「1人あたり可処分所得 × 食への支出性向 × 英語コンテンツ到達性 × SNS利用率」で選ぶ。Tier 1 は米国・オーストラリア・英国・シンガポール・カナダの5市場。**

訪日者数が最も多い韓国・中国本土は、**意図的に対象外とする。**

> **結論が v1 と同じでも、選定ロジックは別物。** v2 の顧客は日本を訪れないまま日本食を家で作る層であり、彼らが有料レシピ商品と食材アフィリエイトに反応するかどうかが唯一の判断軸になる。訪日者数の多寡はもはや第一の変数ではない。

## 1. 判断の土台となる数字

### 1.1 選定に使う軸（v2の主軸）

有料デジタル商品（レシピ）と食材アフィリエイトで稼ぐ事業なので、見るべきは「その国に、食にお金を払う英語話者がどれだけ厚くいるか」。**訪日するかどうかは問わない。**

| 軸 | なぜ効くか | 上位に来る市場 |
| --- | --- | --- |
| **1人あたり可処分所得** | 有料デジタル商品（$24）の購入抵抗を直接下げる | 米・豪・星・加・英 |
| **食への支出性向・外食/食材支出** | 「食に金を使う文化」がある層ほどレシピ・調味料に投資する | 星・豪・英・米 |
| **英語コンテンツ到達性** | 英語1本のまま追加コストなしで届く | 米・英・加・豪・星（星は英語公用語） |
| **Instagram / TikTok 利用率** | 主戦場がIG（`03_媒体戦略.md`）。SNSでの食コンテンツ消費が濃い層が母数 | 米・豪・英・加・星 |
| **英語圏フードメディアへの課金習慣** | 有料レシピ・料理ebookを買う下地があるか | 米・英・豪 |

> これら4〜5軸で上位に来る市場は、いずれも英語圏（またはシンガポールのように英語での購買が自然な市場）に収束する。**人数ではなく「食に金を払う英語話者の密度」で選ぶと、自然に同じ5市場が残る。** 定量値は運用開始時に各国統計・Meta/TikTokの広告リーチ推計で更新すること（現時点は方向性としての順位付け）。

## 2. 市場のTier分け

### Tier 1｜初期に集中する5市場（英語・そのまま届く）

| 国 | 選ぶ理由（v2＝家庭料理課金層として） | 注意点 |
| --- | --- | --- |
| **米国** | 英語圏最大の人口。デジタル商品を$で買う習慣が定着し、$24の心理的抵抗が最も低い。フードメディア（レシピサイト・料理系クリエイター）の消費層が世界最大 | 競合クリエイターも最も多い。差別化（食材の置き換え）で抜ける |
| **オーストラリア** | 1人あたり所得が世界最上位クラス。**food-motivated な食文化**で、アジア食材店の普及率が高く「日本食を家で作る」下地がある。時差が小さく投稿時間が組みやすい | 人口規模が小さい（母数はUSの1/10） |
| **英国** | 食メディア・料理ebookへの支出習慣が根付いている。英語ネイティブでそのまま届く。アジア食材のオンライン流通が成熟 | 日本食材の実店舗入手性は米豪よりやや低い→「オンラインで買う」導線を厚めに |
| **シンガポール** | 英語が公用語。**食への関心と解像度が極めて高く**、1人あたり所得も高い。日本食材が身近で「家で作る」のハードルが低い。時差1時間で運用しやすい | 人口が小さい。比較・品質訴求のコンテンツが刺さる（下記5.3） |
| **カナダ** | 米国と行動様式・食文化がほぼ同じで、同一コンテンツ・同一商品で追加コストゼロで取れる | 単独では規模不足。米国とセットで扱う |

**Tier 1 の共通点は「英語での購買が自然」かつ「食に可処分所得を使う層が厚い」こと。** 同一コンテンツ・同一商品（USD建て）で5市場すべてをカバーでき、追加コストがかからない。**訪日予定の有無は問わない。母数が訪日客より1〜2桁大きいことが、この事業の母集団の核心である。**

### Tier 2｜同じ英語コンテンツで自然に流入する市場（狙わないが歓迎する）

香港／マレーシア／ニュージーランド／アイルランド／オランダ／北欧／**ドイツ**

- ドイツは所得も食支出も高いがドイツ語圏。ただし**英語運用率が高いため英語コンテンツでも一定届く**。ローカライズせずに取れる分だけ取る
- これらは「取りにいかないが、来たら顧客として扱う」層。商品の対応通貨をUSDに統一しておけば購入の障壁はない

### Tier 3｜意図的に対象外とする市場

| 市場 | 除外の理由（v2の観点） |
| --- | --- |
| **韓国** | 韓国語圏で英語コンテンツが届かず、情報流通がNAVER等の独自圏。**訪日は多いが、v2で売る英語レシピ商品の顧客にはならない** |
| **中国本土** | ①プラットフォームが完全に別（小紅書・抖音）、②決済が別（WeChat Pay / Alipay）、③言語も別。**参入するなら別事業として設計すべきで、片手間では成立しない** |
| **台湾** | 繁体字が必要。訪日頻度が高いことはv2の選定軸では加点にならない。ただし**日本食を家庭で作る文化・所得・食支出は高く、3年目に単独で検討する価値がある唯一の非英語市場**（下記4章）。判断軸は「訪日頻度」ではなく「英語版に繁体字圏から自然流入があるか＝家庭料理需要の証明」に置き換える |
| タイ・ベトナム・インドネシア | 有料デジタル商品の購買習慣が薄く、1人あたり所得も低い |

**除外は「価値がない」という意味ではなく、「限られた稼働をどこに置くか」の判断。** 副業の週12〜15時間を分散させた瞬間に、どの市場でも勝てなくなる。

## 3. 言語戦略

### 3.1 英語1本にする理由

1. **Tier 1 の5市場を1つのコンテンツでカバーできる**（追加コストゼロ）
2. Tier 2 の英語運用層にも自動的に届く
3. **更新コストが決定的に違う**。読者の「その食材が手に入らない」報告を半期ごとに反映して改訂する商品なので（`01_事業計画書.md` 5.3）、言語がn個あれば更新コストもn倍になる。差別化要素である「更新され続けること」が、多言語化した瞬間に破綻する
4. 翻訳品質の担保コスト（ネイティブチェック）が言語数に比例する

### 3.2 英語の「種類」

| 項目 | 方針 |
| --- | --- |
| 綴り | **米国式**（color, flavor）。最大市場に合わせる |
| 通貨表記 | **USD基準**、必要に応じ日本円を併記。為替は四半期ごとに更新 |
| 日付 | 誤解を生まない形式（`March 3` / `2027-03-03`）。`3/3` は使わない |
| 料理名 | **ヘボン式ローマ字＋短い説明**（`Nikujaga — simmered beef and potatoes`）。イタリック等で統一 |
| 敬体 | フレンドリーだが断定的に。読者は「この食材で作れるか」の判断を求めている。`you might want to` より `use this instead` |
| 計量 | **グラム＋カップ／oz を併記**（`01_事業計画書.md` 5.2）。海外の計量文化に合わせるのが商品価値そのもの |

### 3.3 やらないこと

- 機械翻訳の自動多言語展開（品質が担保できず、返金率とレビューに直結する）
- SNSアカウントの言語別分割（アルゴリズムがアカウント単位で学習するため、分割は純粋な損失）

## 4. ローカライズの判断ゲート（3年目）

**唯一検討に値するのは繁体字（台湾・香港）。** ただし着手は以下を全て満たした場合に限る。

- [ ] 英語版の月商が70万円を安定的に超えている
- [ ] 台湾・香港からのアクセスが全体の15%以上ある（英語のまま来ている＝**家庭料理コンテンツの需要が言語障壁を越えて存在する証明**）
- [ ] 繁体字ネイティブの協力者を確保できている（自分で書かない）
- [ ] 更新体制（半期ごとの改訂）を2言語で回せる目処がある

1つでも欠けたら着手しない。**英語版の深化のほうが常に投資対効果が高い。**

## 5. 国別の運用への落とし込み

### 5.1 投稿時間（日本時間）

Tier 1 の5市場は時差が大きく分かれるため、**1日2枠に集約する**のが最も効率的。

| 枠 | 日本時間 | カバーする市場 |
| --- | --- | --- |
| **朝枠** | **09:00〜10:00 JST** | 米国東部（前夜20〜21時）／米国西部（前夜17〜18時）／カナダ |
| **夜枠** | **20:00〜21:00 JST** | シンガポール（19〜20時）／オーストラリア東部（21〜22時）／香港・マレーシア |

英国は朝枠（現地01:00）・夜枠（現地12:00）ともにずれるが、**規模が小さいため専用枠は設けない**。Instagramのレコメンドは投稿時刻より初速に反応するため、英国分は取りこぼしを許容する。

> 投稿時間は仮説。3ヶ月分の実データが溜まった時点で、インサイトのフォロワーアクティブ時間で検証し直すこと。

### 5.2 季節性（コンテンツ計画の骨格）

v2の客層は訪日と無関係な自炊層なので、季節性は**「在宅で料理をする動機が高まる時期」**で組む。訪日の山ではなく、英語圏の家庭料理カレンダーに合わせる。

| 時期 | 家庭料理の需要 | 出すべきコンテンツ |
| --- | --- | --- |
| 11〜12月 | **Thanksgiving / Christmas 前のホームクッキング需要（英米加）** | 人が集まる場の一品、作り置き、鍋・すき焼きなど「みんなで囲む」日本食。**最大の商戦期。主要ローンチはここに合わせる** |
| 12〜1月 | **年末年始の在宅調理需要／新年の「今年は自炊する」決意** | おせち風の簡単版、年越しそば、正月に作り置ける常備菜。新年は有料商品の転換率が上がる |
| 1〜2月 | 冬の在宅・鍋需要 | 鍋・おでん・煮込み。同じ調味料で回せる献立提案 |
| 5〜6月 | **母の日・父の日（作ってあげる料理需要）** | 「家族に作る一皿」。丼・照り焼きなど映える定番 |
| 6〜8月 | 夏休み・在宅時間の増加（豪州は冬） | 火を使いすぎない夏の食、冷やし麺、作り置き。豪州向けに冬の温かい料理も同時に流す |
| 9〜10月 | 秋の食欲・新学期後の自炊回帰 | 炊き込みご飯、きのこ、煮物。**第2の商戦期** |

**購買は「作りたい気持ちが高まる時期＝季節イベントの1〜2ヶ月前」に起きる。** 有料レシピ商品のローンチは、最大需要期（Thanksgiving/Christmas・年末年始）の1〜2ヶ月前に置くこと。訪日の山（桜・紅葉）は、層④の訪日商品を売る15ヶ月目以降にのみ、補助的に参照する。

### 5.3 市場別に効くコンテンツの違い

| 市場 | 特に反応する切り口（v2＝家庭料理） |
| --- | --- |
| 米国 | 「近所のスーパーで買える材料だけで作る」。入手性の訴求が最も効く |
| オーストラリア | 「アジア食材店で何を買えばいいか」「一度の買い物で何品作れるか」。food-motivatedで実用情報に強く反応 |
| 英国 | 「なぜこの調味料なのか」の背景説明。文化・由来を好む |
| シンガポール | 「価格対品質」「代替品の比較」。食の解像度が高く、比較・検証コンテンツが最も刺さる |
| カナダ | 米国と同傾向。差別化不要 |

**この差は、コンテンツを分けるのではなく「切り口の配分」で吸収する。** アカウントは分けない。

## 6. この戦略が外れるとしたら（前提の脆さ）

| 前提 | 外れる条件 | 検知方法 |
| --- | --- | --- |
| 英語1本でTier 1をカバーできる | 米国からの流入が想定の半分以下 | 3ヶ月目にInstagramインサイトの国別分布を確認 |
| 可処分所得の高い市場ほど有料レシピ商品を買う | 支出は外食に向かい、家庭料理のデジタル商品には払わない | 5ヶ月目のレシピ商品ローンチで購入者の国別分布を確認 |
| 現地食材で日本食を作る需要が実在する | 無料レシピで満足し、「食材の置き換え」に課金しない | 無料PDF（2ヶ月目）のDL率と、リストの「食材で詰まった経験」アンケートで検証 |
| 訪日セグメントが層④を成立させる規模でいる | リスト内の訪日予定者が10%未満 | **3ヶ月目に登録アンケートで実測**（`01_事業計画書.md` 3.3）。10%未満なら層④を計画から外す |

**3ヶ月目・5ヶ月目のチェックポイントで、これらを必ず実データで検証する。** 外れていた場合はTier定義を組み直す。

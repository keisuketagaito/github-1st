# AIプロンプト集

作成日：2026年7月27日
関連：`01_AI運用設計.md`（どの工程で使うかの全体像）

**使い方**：`【】` の部分だけを差し替えて、そのまま貼り付ける。
**原則**：出力は常に「下書き」。事実の検証は `01_AI運用設計.md` 5章の検証ルールに従う。

## 共通の前置き（毎回の会話の冒頭に置く）

```
あなたは、訪日外国人（英語圏の2回目以降のリピーター）向けに日本の飲食店情報を
発信するメディアの編集アシスタントです。

読者：米国・オーストラリア・英国・シンガポール・カナダの30〜45歳。
      日本は2回目以降。渋谷・浅草・築地は経験済み。
      「観光客がいない店」「予約が取れない店」に行きたいが、
      予約手段・言語・支払い方法の壁で行けずにいる。

このメディアの価値は「どの店が美味しいか」ではなく
「その店に実際に入れるようにすること」です。

厳守事項：
- 私が提供していない店舗情報（営業時間・予約手段・価格など）を推測で補わないこと。
  情報が足りない場合は「要確認」と明示すること。
- 存在しない店名を出さないこと。
- 出力は英語（米国表記）。ただし私への説明は日本語で。
```

## P-01 ｜ 取材ルートの下調べ

```
【エリア名（例：新宿三丁目）】で、以下の条件に合う店舗の候補を15件挙げてください。

条件：
- 徒歩8分圏内に収まること（移動効率が最優先）
- カテゴリが分散していること（寿司/焼鳥/蕎麦/居酒屋/喫茶 など）
- 価格帯が分散していること（¥1,000台 〜 ¥15,000台）
- 観光客向けチェーン店を含めないこと

各店について、以下を「分かる範囲で」記載してください。
分からない項目は必ず「要確認」と書き、推測で埋めないこと。

| 店名 | カテゴリ | 想定価格帯 | 最寄駅と徒歩分 | 予約要否（推測）| 確認すべき点 |

最後に、この15件を1日で4〜6店回る場合の最も効率的な訪問順と、
昼と夜のどちらに行くべきかを提案してください。
```

> **注意**：この出力は「候補リスト」であって「掲載リスト」ではない。行く店は自分で決め、実際に行った店だけを掲載する。

## P-02 ｜ 音声メモ → 標準9項目への構造化（最も使用頻度が高い）

```
以下は、私がある飲食店を出た直後に録音した音声メモの文字起こしです。
これを、下記の標準フォーマットに構造化してください。

【文字起こしを貼り付け】

出力フォーマット（英語。ただし不明項目は "TO VERIFY" と記載）：

Name / Area:
Why this one:（1〜2文。「美味しい」以外の理由。私のメモにある観察を使う）
Reservation:（手段 / 何日前から / 海外電話番号の可否 / 海外カードの可否 / 代行の可否）
Payment:（現金のみか / カード / IC / 目安予算）
Watch out:（タトゥー / 子連れ / 撮影 / 香水 / 滞在時間制限 / お通し）
What to say:（必要な場面：予約時・入店時・会計時のどれか）
Access:（最寄駅・出口・徒歩分数・迷いやすいポイント）
Best time:（曜日・時間帯）
Pair with:（徒歩圏で前後に組める場所）

厳守：私のメモに含まれていない情報は絶対に補完せず、"TO VERIFY" と書くこと。
最後に、次回訪問時に確認すべき項目を箇条書きで挙げてください。
```

## P-03 ｜ 店で使える日本語スクリプトの生成

```
【店名 / カテゴリ / 予約手段】の店で、英語話者の客が使う日本語スクリプトを
以下の3場面ぶん作ってください。

1. 予約時（電話 または 店頭）
2. 入店時
3. 会計時

各スクリプトは以下の3行構成にしてください：
  日本語（そのまま店員に見せられる、丁寧すぎず短い文）
  ローマ字（ヘボン式）
  英訳

条件：
- 1文は12語以内。スマホ画面で読める長さにすること
- 相手の返答として想定されるもの（「何名様ですか」「お時間は」等）も
  日本語＋英訳で併記すること
- 敬語は過剰にしない。実際に店で使われる自然な言い方にすること

最後に、この店で追加で必要になりそうな場面があれば提案してください。
```

## P-04 ｜ フック10案（動画の最初の3秒）

```
以下の店の情報をもとに、45秒のショート動画の「最初の3秒」で使うフックを
10案作ってください。

【P-02で構造化した店舗情報を貼り付け】

条件：
- 12語以内、口語、英語
- 「Top 10」「Best restaurants」系は使わないこと（競合過多で埋もれるため）
- 以下のいずれかの型に寄せること：
  a. 拒絶の予告（"This place will turn you away. Here's how it won't."）
  b. 不可能性（"You cannot book this online. At all."）
  c. 数字の意外性（"I asked 12 places. Only 4 take foreign cards."）
  d. 禁止（"Don't do this at a sushi counter."）
  e. 秘密の共有（"Two years here. Still zero tourists."）

10案それぞれについて、想定される弱点を一言で添えてください。
```

## P-05 ｜ 45秒台本

```
以下のフックで、45〜55秒のショート動画の台本を作ってください。

フック：【P-04で選んだもの】
店舗情報：【P-02の出力を貼り付け】

構成（秒数を必ず守ること）：
  0–3秒   フック
  3–10秒  問題提起（読者が実際に困っていること）
  10–35秒 解決の実演（何を画面に映すかも指示すること）
  35–48秒 実際に入れた結果
  48–55秒 CTA：無料PDFへの誘導

条件：
- 話し言葉で。書き言葉にしないこと
- 1文は短く。字幕で読める長さに
- 各パートで「画面に何を映すか」を [映像: ...] の形で指示すること
- CTAは毎回入れること

台本のあとに、撮影時の注意点を3つ挙げてください。
```

## P-06 ｜ 英語字幕のネイティブ化

```
以下は、私が話した内容の文字起こしです。
ショート動画の字幕として使えるように整えてください。

【文字起こしを貼り付け】

条件：
- 米国英語。カジュアルだが断定的に（旅行者は判断を求めている）
- 1行あたり最大32文字、1画面2行まで
- 日本語の料理名はヘボン式ローマ字＋短い説明（例：Yakitori — grilled chicken skewers）
- タイムコードは不要。行ごとに改行するだけでよい
- 冗長な相づち・言い直しは削除すること

出力のあとに、元の発言から意味が変わってしまった箇所があれば指摘してください。
```

## P-09 ｜ 週次メールの下書き

```
今週の週次メール（600〜800語）の下書きを作ってください。

今週訪れた店：【P-02の構造化データを貼り付け】
読者から来た質問：【DMやコメントから1つ】

構成：
1. 今週の1軒の話（実体験のトーン。ただし私が提供した事実のみ使うこと）
2. そこから読者が使える教訓を1つ
3. 読者質問への回答
4. 追伸：軽い一言

条件：
- 売り込みは入れないこと（売り込みは月1回だけ）
- 私が書いていない体験を創作しないこと。
  体験談として膨らませたい箇所は【ここに実体験を入れる】と明示すること
- 件名を3案

※このメールの価値は実体験にあります。AIが作るのは器で、
  中身は私が入れます。器だけを作ってください。
```

## P-10 ｜ コメント・DM返信の下書き

```
以下のコメント／DMへの返信を、それぞれ2案ずつ作ってください。

【コメント・DMを貼り付け】

条件：
- 英語。friendly かつ簡潔（3文以内）
- 具体的な店名や予約手段は、私が確認済みの情報のみ使うこと。
  不明な場合は「確認して後で返す」という趣旨にすること
- 売り込みを入れないこと
- 質問で返して会話を続ける形を1案は含めること

返信案のあとに、この質問が「Ask a Local」シリーズの
コンテンツになりうるかどうかを判定してください。
```

## P-11 ｜ 週次の数値レビュー

```
今週の数値です。読み解いて、来週の行動を3つ提案してください。

【KPIダッシュボードの該当週を貼り付け】
先行指標の定義：メールリスト純増数、平均保存率
遅行指標：売上、フォロワー数

出力：
1. 今週の要約（3行）
2. 異常値・変化点の指摘（前週比・4週移動平均との乖離）
3. 考えられる原因の仮説（複数ある場合は確からしい順に）
4. 来週やるべき行動を3つ（優先順位つき、具体的に）
5. 判断を保留すべき点（データ不足でまだ言えないこと）

注意：フォロワー数の増減に引きずられないこと。
この事業の先行指標はメールリスト純増と保存率です。
```

## P-12 ｜ 競合の定点観測（月1回）

```
以下は、監視している競合アカウント【N】件の今月の数値です。

【アカウント名 / フォロワー数 / 今月の投稿数 / 伸びた投稿の内容 / 販売商品と価格】

分析してください：
1. 今月フォロワーを最も伸ばしたアカウントと、その要因の仮説
2. 「伸びているが商品化していない」領域はどこか
   （＝我々が入るべき隙間）
3. 我々と直接競合し始めたアカウントがあるか
4. 価格帯の変化があるか

最後に、我々が今月やるべきでないこと（＝競合が既に押さえていて
今から入っても勝てない領域）を挙げてください。
```

## P-13 ｜ ガイドPDFの体裁統一（商品制作時）

```
以下は、収録予定の店舗データ【N】件です。
すべてを同一フォーマットに統一してください。

【店舗データを貼り付け】

統一ルール：
- 見出し階層、項目の並び順、記法をすべて揃える
- 通貨は USD 基準＋日本円併記（例：¥12,000 / approx. $80）
- 日付形式は "March 3"（"3/3" は使わない）
- 距離はメートル法、体感を (≈ 5 min walk) で補う
- 料理名はヘボン式ローマ字＋短い説明

統一後、以下を報告してください：
1. 情報が欠けている店舗と、欠けている項目の一覧
2. 記述に矛盾がある箇所
3. 他店と重複していて差別化が弱い店舗

※ 欠けている情報を推測で埋めることは絶対にしないでください。
  欠損は欠損として報告してください。
```

## プロンプト運用のルール

1. **プロンプトを毎回書き直さない。** 型が固まるまでは修正し、固まったらこのファイルを更新して以後は固定する（`01_AI運用設計.md` の L2 段階）
2. **出力が悪いときは、プロンプトではなく入力を疑う。** 音声メモが雑なら、どんなプロンプトでも良い出力は出ない
3. **「要確認 / TO VERIFY」が出たら必ず埋める。** 埋まらない店は掲載しない
4. **プロンプトを改善したら、必ずこのファイルに反映する。** 頭の中だけに置くと、外注化の段階で引き継げない

## 共通の前置き（毎回の会話の冒頭に置く）

```
あなたは、英語圏の「日本食を家で作りたい人」向けに、日本の家庭料理を
「現地で手に入る食材で作れる形」に翻訳して発信するメディアの編集アシスタントです。

読者：米国・オーストラリア・英国・カナダ・シンガポールの28〜50歳。
      自炊習慣があり、食に可処分所得を使う。
      日本食レストランには行くが、家では作れていない。
      レシピは見つかるが、みりんが売っていない・だしをどうするか・
      醤油の種類が多すぎる・計量単位が違う、といった「食材と分量の翻訳」で
      詰まって諦めた経験がある。

このメディアの価値は「レシピそのもの」ではなく
「食材事情を翻訳すること（何を買い、何で代替するか）」です。

厳守事項：
- 私が実際に作って食べて検証していない代替食材・味付けを、推測で提案しないこと。
  検証していない項目は「要検証（TO VERIFY）」と明示すること。
- 存在しない食材や、実際には失敗する代替を断定的に書かないこと。
- 出力は英語（米国表記）。ただし私への説明は日本語で。
```

## P-01 ｜ まとめ撮りの献立設計・買い出し下調べ

```
今週のまとめ撮り（1セッションで3〜4品を並行調理）の献立案を作ってください。
最優先の制約は「同じ調味料を使い回せること」です。買い出しは週1回に集約し、
食材費と買い出し回数を最小化したい（事業計画書 7.2）。

今週の軸にしたい調味料 または テーマ：【例：醤油・みりん・だしで回す週】
避けたい食材（在庫・季節・アレルギー等）：【例：なし】

条件：
- 3〜4品が、上記の共通調味料でほぼ回せること
- 難易度・調理法が分散していること（煮る/焼く/和える など）
- 少なくとも1品は「代替食材の検証」ネタになること
  （みりん→? / だし→? / 酒→? のように、海外で手に入りにくい材料を含む品）
- 5本柱（The Pantry / Weeknight / Substitutions / Make It Work / 調理器具レビュー）の
  どれに当たるかも各品に付記すること

各品について、以下を表で出してください。

| 品名（英/日） | 5本柱の区分 | 共通で使う調味料 | 追加で必要な食材 | 検証したい代替食材 |

最後に、これらを1回の買い出しで揃えるための買い物リストを、
「一般スーパー / アジア系食料品店 / オンライン」の3区分に分けて作ってください
（事業計画書 5.2 の Where to buy に対応）。
```

> **注意**：この出力は「献立の候補」であって「掲載レシピ」ではない。実際に作って食べて検証した品・代替食材だけを掲載する。

## P-02 ｜ 検証メモ → レシピ標準9項目への構造化（最も使用頻度が高い）

```
以下は、私がある家庭料理を作って食べた直後に録音した音声メモの文字起こしです。
これを、下記のレシピ標準フォーマット（事業計画書 5.2 の9項目）に構造化してください。

【文字起こしを貼り付け】

出力フォーマット（英語。ただし私が検証していない項目は "TO VERIFY" と記載）：

1. Dish name / photo note:（品名。撮影した写真のメモがあれば）
2. Why this dish:（1〜2文。日本の食卓での位置づけ。私のメモにある観察を使う）
3. Ingredients — 3列表記：
   | In Japan（日本の材料）| Buy where you live（海外で買えるもの）| Substitute with（代替可能なもの）|
4. Where to buy:（一般スーパー / アジア系食料品店 / オンライン のどこで買えるか）
5. Measurements:（グラム＋カップ/oz を併記。何人分か）
6. Steps:（手順を6〜10ステップで。私のメモの範囲で）
7. What goes wrong:（失敗しやすい点と回避法。最も保存される要素。私が実際に詰まった点を使う）
8. Make it work for you:（ベジ / ハラル / グルテンフリー対応。検証済みのもののみ）
9. Storage:（保存・作り置きの可否）

厳守：
- 私のメモに含まれていない情報、特に「検証していない代替食材」は絶対に補完せず、
  "TO VERIFY" と書くこと。実際に代替品で作って食べていない提案は書かない。
- Ingredients の Substitute 列は、私が検証したと明記したものだけを確定にし、
  それ以外は "TO VERIFY" とすること。

最後に、次回のまとめ撮り時に検証すべき項目（未検証の代替食材など）を箇条書きで挙げてください。
```

## P-03 ｜ 代替食材の検証結果を3列表記＋Q&Aに構造化

```
以下は、ある材料について私が実際に複数の代替品で作って食べ、比較した検証メモです。
これを、レシピ商品と「食材の置き換えQ&A」に使える形に構造化してください。

対象の材料：【例：みりん Mirin】
私の検証メモ：【文字起こし・箇条書きを貼り付け。試した代替品／分量／味の結果を含む】

出力（英語。検証していない選択肢は "TO VERIFY" と明示）：

1. 3列表記の行（この材料をレシピの Ingredients 表に差し込める形）：
   | In Japan | Buy where you live | Substitute with |

2. 代替候補の比較表：
   | Substitute | Ratio（置換比率）| Result（私の検証結果）| Verdict（推奨/条件付き/不可）|
   ※ Result・Verdict は、私のメモにある実際に作って食べた結果のみを使うこと。
     メモにない代替品を勝手に足さない。足す場合は "TO VERIFY" 行として分けること。

3. Where to buy（一般スーパー / アジア系食料品店 / オンライン）

4. 読者向けの短いQ&A 1問（例："No mirin — what do I use?" への40語以内の回答）。
   Substitutions シリーズの投稿・メールにそのまま使える形にすること。

厳守：私が実際に代替品で作って食べた、とメモに書いていない結論は断定しないこと。
未検証の候補は "TO VERIFY" として、次回検証リストに回してください。
```

## P-04 ｜ フック10案（動画の最初の3秒）

```
以下のレシピ情報をもとに、45秒のショート動画の「最初の3秒」で使うフックを
10案作ってください。

【P-02で構造化したレシピ情報を貼り付け】

条件：
- 12語以内、口語、英語
- 「Top 10」「Best recipes」系は使わないこと（競合過多で埋もれるため）
- 軸は「食材の置き換え」＝無料レシピサイトで埋まらない買い物の意思決定
- 以下のいずれかの型に寄せること：
  a. 代替の提示（"No mirin? Here's what actually works — I tested all three."）
  b. 不要の宣言（"You don't need dashi powder. Here's the 5-minute version."）
  c. 制約下での実演（"Only what's at a regular grocery store. No Asian market."）
  d. 禁止（"Don't do this when you cook rice."）
  e. 検証者としての権威（"I've cooked this every week for two years. Here's what goes wrong."）

10案それぞれについて、想定される弱点を一言で添えてください。
```

※ 欠けている情報、特に未検証の代替食材を推測で埋めることは絶対にしないでください。
  欠損は "TO VERIFY" として報告してください。

## プロンプト運用のルール

1. **プロンプトを毎回書き直さない。** 型が固まるまでは修正し、固まったらこのファイルを更新して以後は固定する（`01_AI運用設計.md` の L2 段階）
2. **出力が悪いときは、プロンプトではなく入力を疑う。** 音声メモが雑なら、どんなプロンプトでも良い出力は出ない
3. **「要確認 / TO VERIFY」が出たら必ず埋める。** 埋まらない店は掲載しない
4. **プロンプトを改善したら、必ずこのファイルに反映する。** 頭の中だけに置くと、外注化の段階で引き継げない

# AI前提の運用設計

作成日：2026年7月27日
関連：`03_AIプロンプト集.md`（実際に使うプロンプト）／`02_マーケティング運用マニュアル.md`／`../00_戦略/03_媒体戦略.md`

---

## 0. 大原則

> **AIに任せてよいのは「変換」。任せてはいけないのは「一次情報」。**

- **一次情報** ＝ 実際に行った、食べた、予約が取れた、断られた、現金しか使えなかった。
  これが本事業の差別化そのものであり、**AIには原理的に作れない。**
- **変換** ＝ 音声メモの構造化、翻訳、台本化、要約、バリエーション生成、組版。
  ここは人間より速く安い。**ここを人間がやっている限り、取材の時間が消える。**

この線引きは倫理の話ではなく、**事業設計の話**である。AIに一次情報を書かせた瞬間に、無料の情報源と区別がつかなくなり、$19の根拠が消える。同時に、YouTubeが収益化の判定軸に置く「オリジナリティ」と「編集の労力」の要件とも、この線引きは完全に一致する。

**この線を守る限り、AIをどれだけ使っても事業は強くなる。越えた瞬間に壊れる。**

## 1. AI活用マップ

| # | 工程 | AIの役割 | 人間が必ずやること | 削減効果 |
| --- | --- | --- | --- | --- |
| 1 | 取材先の下調べ | 候補店の営業情報・エリア密集度の整理、ルート案 | **行く店の最終決定** | 2h → 20分 |
| 2 | 取材メモの構造化 | 音声メモ → 標準9項目のデータへ変換 | 現地での観察・記録 | 1.5h → 15分 |
| 3 | 日本語スクリプト生成 | 場面別の日本語文＋ローマ字＋英訳 | **店で実際に通じるかの検証** | 1h → 10分 |
| 4 | 動画台本 | フック10案、構成、CTA文 | 撮影・話し方・取捨選択 | 2h → 30分 |
| 5 | 字幕・英語化 | 文字起こし、英語字幕、ネイティブ表現化 | 有料商品のみ最終チェック | 3h → 30分 |
| 6 | キャプション・ハッシュタグ | 本文案、タグ構成、投稿時間の提案 | 送信前の確認 | 1h → 10分 |
| 7 | カルーセル・サムネ | 構成案、コピー案、Pinterest用リサイズ指示 | 最終選定 | 1.5h → 30分 |
| 8 | メール執筆 | 下書き、件名A/B案 | **実体験の挿入**（ここが本体） | 2h → 40分 |
| 9 | コメント・DM返信 | 定型質問への下書き | 送信前確認、個別性の高い質問 | 2h → 40分 |
| 10 | ガイドPDFの組版 | 統一フォーマットへの流し込み、体裁の均一化 | 内容の正確性の担保 | 8h → 1.5h |
| 11 | 週次の数値分析 | 数値の要約、異常値の指摘、仮説の提示 | **意思決定** | 1h → 15分 |
| 12 | 競合の定点観測 | 変化点の要約 | 戦略判断 | 1h → 15分 |

**合計：週あたり およそ 26時間 → 6時間。** この差が、週15時間で回せるかどうかを決める。

**削減した時間の使い道は「取材」以外にない。** AI導入で浮いた時間を投稿本数の増加に回すと、一次情報の在庫が枯れて、結局は無料情報の焼き直しになる。**浮いた時間は必ず現地に投下する。**

## 2. AIを使わない工程（意図的に人間が行う）

| 工程 | 理由 |
| --- | --- |
| **店の選定と実訪問** | 事業の核。ここを外注・自動化した瞬間に差別化が消える |
| **予約手段の検証** | 「電話で通じた」「海外カードが弾かれた」は、実際に試さないと分からない。AIの推測は誤情報になる |
| **写真・動画の撮影** | AI生成画像を店の写真として使うことは、事実の捏造にあたる |
| **返金対応・クレーム対応** | 信頼の回復は人間の仕事 |
| **タイアップの商談** | 関係構築が資産 |
| **有料商品の最終校閲** | 返金率に直結する |

## 3. 週次AIパイプライン（これが運用の背骨）

取材1回（4〜6店）から公開までを、以下の流れで回す。**プロンプトは `03_AIプロンプト集.md` の番号に対応。**

### 土曜／日曜 — 取材（5.0h）

```
[人間] 4〜6店を訪問
  ├─ 撮影：外観3秒 / 席3秒 / 提供5秒 / 一口3秒（1店5分の型）
  └─ 各店の退店直後に「音声メモ2分」を録る
      → 予約手段・支払い・注意点・滞在時間・迷いポイントを口頭で吐き出す
      ※ 後日は必ず忘れる。その場で録ることが唯一の担保
```

### 日曜夜 — 構造化（30分）

```
[AI] P-02  音声メモ（文字起こし）→ 標準9項目の構造化データ
        ↓
[人間]     事実確認して 店舗データベース.xlsx に追記（1店2分）
        ↓
[AI] P-03  各店の日本語スクリプト（予約/入店/会計）を生成
        ↓
[人間]     次回の取材時に、実際に店で使えるか検証する ← 重要
```

### 火曜夜 — 制作（2.0h）

```
[AI] P-04  1店につきフック10案 → 人間が1つ選ぶ
[AI] P-05  選んだフックで45秒台本 → 人間が言い回しを直す
[人間]     撮影素材を編集（1本25〜30分 × 5本）
[AI] P-06  文字起こし → 英語字幕（表現をネイティブ化）
```

### 木曜夜 — 仕上げ（2.0h）

```
[AI] P-07  キャプション・ハッシュタグ・投稿時間
[AI] P-08  カルーセル1本の構成とコピー
[人間]     Canvaの型に流す → Pinterestへも転用
[AI] P-09  週次メールの下書き → 人間が実体験を挿入（ここが本体）
```

### 日曜夜 — 締め（1.0h）

```
[AI] P-10  コメント・DMの返信下書き → 人間が確認して送信
[AI] P-11  週次数値の要約と異常値の指摘 → 人間が意思決定
[人間]     翌週の取材エリアと訪問店を確定
```

## 4. AI運用の禁止事項（違反すると事業が壊れる）

| # | 禁止 | 何が起きるか |
| --- | --- | --- |
| 1 | **訪問していない店の情報をAIに書かせる** | ハルシネーションで存在しない店・閉店した店・誤った予約手段が混入する。**商品の根幹が壊れ、1件の露見で全体の信用を失う** |
| 2 | **AI生成画像を店の写真として使う** | 事実の捏造。掲載店からの信頼を失い、タイアップの道が閉じる |
| 3 | **英語の最終出力を無検証で有料商品に載せる** | 英文品質は返金率に直結する |
| 4 | **AIに「おすすめの店50選」を出させて、それを商品にする** | 無料情報と区別がつかず、$19の根拠が消える |
| 5 | **テンプレートの使い回しだけで量産する** | YouTubeの収益化ポリシー（オリジナリティ・編集の労力）に抵触する |
| 6 | AI音声・AI画像を使いながら明示しない | 規約違反。使う場合は概要欄に明記する |

**1と4は、この事業における最重要の禁止事項。** 楽をしたくなる瞬間に必ず誘惑が来るので、明文化しておく。

## 5. AIが出した情報の検証ルール

AIの出力は「下書き」であって「事実」ではない。以下は**必ず人間が一次ソースで確認する**。

| 種別 | 検証方法 |
| --- | --- |
| 営業時間・定休日 | 店頭 または 公式（食べログ/Instagram） |
| 予約手段・受付開始日 | **実際に予約を試す** |
| 海外カード・海外電話番号の可否 | **実際に試す**（推測は不可） |
| 価格 | 訪問時の会計 |
| 現金のみ／タトゥー／子連れ | 店頭確認 |
| 最寄駅・徒歩分数 | 実際に歩く |
| 日本語スクリプト | 次回訪問時に店で使ってみる |

**「AIがそう言った」は、掲載の根拠にならない。**

| 用途 | ツール | 月額目安 |
| --- | --- | --- |
| 文章生成・構造化・分析 | Claude（有料プラン） | 3,000円 |

| 予約投稿・分析 | Metricool等 | 2,500円 |

収支モデルの「ツール類 12,000円/月」に収まる。**AI導入によるコスト増は月1万円弱で、削減される時間は週20時間。** 判断するまでもない。

## 7. AI活用の成熟度ロードマップ

| 段階 | 時期 | 状態 |
| --- | --- | --- |
| **L1：下書き生成** | 1〜3ヶ月目 | 都度プロンプトを書いて、台本・キャプションの下書きを作らせる |
| **L2：型の固定** | 4〜6ヶ月目 | `03_AIプロンプト集.md` を確定させ、毎回同じプロンプトを使う。出力の品質が安定する |
| **L3：パイプライン化** | 7〜12ヶ月目 | 取材メモ→構造化→台本→字幕までを一連の流れで回す。所要時間が読めるようになる |
| **L4：外注との併用** | 13ヶ月目〜 | AIで下書き、外注が仕上げ、自分は取材と判断のみ。**ここで週15時間の壁を超えられる** |

**L2に到達しないうちに投稿本数を増やさないこと。** 型が固まる前に量を増やすと、品質のばらつきがそのまま残る。

## 8. AI前提の運用が失敗するとしたら

| 失敗の形 | 兆候 | 対処 |
| --- | --- | --- |
| AIの出力をそのまま出し、内容が薄くなる | 保存率が3%を下回り続ける | 一次情報の密度を上げる。AIの使用範囲を「変換」に戻す |
| 取材時間がAI作業に食われる | 月の訪問店舗数が15店を下回る | AI工程を削り、取材を優先する。**取材は最後まで守る** |
| プロンプトが毎回違い、品質が安定しない | 出力の手直し時間が増えている | L2（プロンプト集の確定）に戻る |
| ハルシネーションが商品に混入 | 読者から「その店は閉店している」の指摘 | 5章の検証ルールを再徹底。該当版を即時改訂して全購入者に配信 |

**最後の項目が起きたときの対応速度が、この事業の信頼を決める。** 指摘から48時間以内に改訂版を配信すること。それができるなら、むしろ「更新され続けるガイド」という差別化の証明になる。

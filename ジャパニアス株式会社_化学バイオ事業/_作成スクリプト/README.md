## 作り方
```bash
export MA_WORK=<作業フォルダ> REPO=<リポジトリ>   # MA_WORK/up/ に受領ファイル（pl.xlsx・customers.xlsx・employees.xlsx）
python3 -I build_master.py                         # → MA_WORK/work/master_raw.xlsx
soffice --headless --convert-to xlsx --outdir MA_WORK/work/recalc MA_WORK/work/master_raw.xlsx
python3 -I $REPO/.claude/skills/ma-deal-docs/scripts/inject_cache.py master_raw.xlsx recalc/master_raw.xlsx master.xlsx
OUT=<出力pptx> python3 -I build_im.py              # 表はすべてマスターの貼付範囲を paste_range で貼付
```

## 本件固有の運用
- 上場会社の一事業部門の事業譲渡のため、対象事業単独のBS・決算書はない。受領した事業部PL（月次）を
  マスター「事業部PL月次」に転記し、IM用シートはそこを数式で参照する。BS・株主・役員・不動産・設備・VR→は未使用。
- 正常化調整は行っていない（依頼者指示：恣意的な調整をしない）。営業利益は本社共通費配賦後、事業所利益は配賦前。
- 顧客名は匿名（A〜T社、2026/11期の売上順）。実名対応はマスター「取引先」O列（社内用）。
  従業員は氏名・学校名・個人別給与を載せず、給与は集計値のみ。
- 社内限情報（他社仲介・売主の許容条件・面談メモ・ロングリスト等）はマスター「プロセス関連」シートに隔離。

## 受領資料の照合で見つけた点（要確認）
- 事業部PLの欄外「人件費（加算）」（所長1名分、FY26見込 8,607千円）は営業利益に含まれていない。販管費の本社給与手当等（4,532千円）との関係は要確認。
- 2026/11期の10・11月は見込値。顧客別売上（12〜10月実績）は事業部PL（同期間）を3,478千円下回る。
- 2024/11期の顧客別売上合計は事業部PLを1,485千円下回る（集計範囲の差）。
- 受領PLの「一人当たり売上」（通期）は見込月を含む売上÷9月までの稼働数のため過大。12〜9月で再計算した。
- 公式サイト（jna.co.jp）は作成環境から閲覧不可。サイト記載内容・2025/11期全社業績は依頼者提示値に基づく。

1項目でも満たせないときは、満たせない理由と残作業を報告に書く。

## A. マスター（数字の正本）

- [ ] 公式フォーマット（`assets/master_template.xlsx`、または依頼者記入途中の公式マスター）で作っている
- [ ] 受領資料をすべて読み、マスターに転記した（決算書3期・内訳書・試算表・順位表／売上台帳・給与台帳・登記・課税明細・認定証 等）
- [ ] 依頼者が記入した部分も**科目ごとに前期と比較**して行ずれ・桁ずれがないか確認した（合計が合っても行ずれは起きる）
- [ ] 数式エラー0件、借貸一致・決算書合計・販管費計・純利益のチェックセルがすべてTRUE
- [ ] 調整後EBITDAが PLハイライト／修正PL／評価書 で一致（修正PLの「正常化調整の前提」ブロック1か所から参照）

- [ ] 未確認事項・論点は `その他` シートに集約し、社内限の情報は「プロセス関連（社内確認事項）」だけにある

## B. 概要書の中身

- [ ] テンプレート（`assets/im_template.pptx`）由来の頁で構成し、表紙の業種・地区を依頼者の指定どおりにした

- [ ] リード文・Comment・注記の数字もマスターの値から生成した（手打ちしていない）
- [ ] 業種の核になる頁を足した（例：卸売市場＝収益源・品目別売上・許認可・季節性、養殖＝生産サイクル）。使わない頁は削除した
- [ ] 主要得意先・仕入先は年間取引高で示した（なければ内訳書残高で代替し注記）。個人の取引先は匿名
- [ ] 進行期（試算表）があれば前年同期比で示し、年換算していない
- [ ] 財務ハイライト（B/S）は前期末と進行期試算表のうち**純資産の高い方**を表示した（試算表なら「決算整理・法人税等は未計上」と注記し、前期末の純資産も併記）。時価純資産・土地の含み損は評価書で扱い、概要書には書かない（依頼者方針 2026/11）
- [ ] 未確認は「要確認」、推測は「推察」「想定」「（仮説）」と書いた。マイナスは打ち手・一過性とセット
- [ ] 写真：受領済みなら拠点頁に入れた。未受領・取得不可なら「受領後に掲載」と書き、依頼者に取得方法を伝えた（Webはネットワーク許可が必要）

- [ ] `force_white_headers` のあと描画で、**白地の見出し（ノンネームの「事業内容」等、2頁の「本件のご照会先」）が消えていない**ことを確かめた（図形スタイルは白でも枠の書式で黒字の見出しがある。2026/11 の初版関数はこれを白にしてしまい、ノンネームテンプレートの見出しが白地に白文字になっていた）

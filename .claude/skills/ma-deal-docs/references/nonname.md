# ノンネームシートの作り方 ― 当社フォーマット

## 鉄則：ゼロから作らない／社名を割らない

**必ず `assets/ノンネームシート_テンプレート.pptx` を複製して作る。**
白紙から組み立ててはいけない（概要書・評価書と同じ）。

```python
import sys
sys.path.insert(0, '.claude/skills/ma-deal-docs/scripts')
from nn_builder import *

prs = open_nn_template()
fill_nonname(prs, { '業種': …, 'エリア': …, 'ビジネス面': [...], ... })
place_table(find_table(prs, 'ビジネス面'), y=3.74, heights=[1.52, 0.88, 1.12])
ng = check_anonymity(prs, BANNED)   # 社名が割れる語の残存チェック
assert not ng
```

ノンネームシートは**概要書の要約ではない**。
NDA締結前に買手候補へ渡す1枚もので、**社名が特定されないこと**が最優先。
興味を持ってもらう情報量と、特定されない情報量の綱引きになる。

## 基本仕様（鶴岡中央青果 261015 から採取）

| 項目 | 値 |
|---|---|
| 用紙 | A4縦 8.27 × 11.69 インチ（概要書・評価書はA4横なので注意） |
| スライド | 1枚のみ |
| レイアウト | 「タイトル スライド」1種。ロゴ・Confidential・著作権表記を保持 |
| テーマ | 企業概要書／評価書と同一（dk2=`0B3041` / lt2=`E3E7E9` / accent4=`0889C9`） |
| ラベル列 | 幅1.575 / 14pt太字 / 地 `bg2` / 中央揃え（縦） |
| 値列 | 幅5.827 / 定型値は14pt、箇条書きは11pt・`buChar ▪` |

## ページ構成

| ブロック | 位置（既定） | 内容 |
|---|---|---|
| タイトル | y=0.20 | `M＆A案件 ノンネームシート` |
| 事業内容 | 見出し y=0.95／表 y=1.36 | 業種／エリア／売上高／従業員 の4行 |
| 特徴・強み | 見出し y=3.76／表 y=4.13 | ビジネス面／財務面／組織面 の3行（箇条書き） |
| 補足事項 | 見出し y=7.33／表 y=7.70 | 譲渡理由／スキーム／希望譲渡価額 の3行 |
| 本情報の取扱について | y=9.37 | **定型文。削除も改変も禁止** |

**行高は前案件の文字量のまま固定されている。** 文章量を変えたら必ず
`place_table()` で行高を取り直し、必要なら `move_text()` で下の見出しも動かす。
放置すると行が重なり、下の見出しを押し潰す（PowerPointは行を自動で伸ばすため）。

## 書いてよいこと／書いてはいけないこと

| ✗ 書かない | ✓ 言い換える |
|---|---|
| 店名・会社名・商標名 | 「全国的に知名度の高い手打ちそば店」 |
| 代表者名・著書名 | 「代表者」「創業者」 |
| 固有の賞・媒体名（そば百名店 等） | 「大手グルメサイトの全国上位店に複数年選出」 |
| 市区町村名 | 地方名（北関東・東北・近畿 …） |
| 固有の取引先名 | 「同業著名店・ベーカリーへの原料卸」 |
| 特徴的すぎる固有の製法・地名産品 | 一段抽象化する（「在来農法」「地元産の銘柄」） |
| 実額の売上高・利益 | レンジ（「1億円未満」「10億円以上」） |
| 従業員の実数 | レンジ（「5名未満」「20名以上」） |
| 価格の温度感・報酬の取決め・他社仲介の併走 | **一切書かない。** 希望譲渡価額は原則「応相談」 |

知名度が高い案件ほど、**魅力的な事実がそのまま特定材料になる**。
「この一文で検索したら社名が出てくるか」を一行ずつ確かめる。
迷ったら一段抽象化する。買手の興味は面談で詰めればよい。

## 書き方の型

- **ビジネス面** … 事業の仕組み・参入障壁・販路の広がり。4項目以内
- **財務面** … 売上規模のレンジ、EBITDAの水準、不動産・借入の有無。2項目
- **組織面** … 運営体制、属人性、承継の下地、伸び代。3項目

読み手は1枚で判断する。1項目は原則**2行以内**に収める。
弊社の見立てを書くときは「（弊社の評価）」と明示する。

無報酬の役員がいる、営業日が限られるなど**EBITDAの読み方に影響する前提**は、
財務面の同じ行に1節として添える。隠すと概要書段階で信頼を失う。

## 検証（納品前に必ず通す）

```bash
python /mnt/skills/public/pptx/scripts/office/validate.py <シート.pptx>
soffice --headless --norestore -env:UserInstallation=file:///tmp/lo-nn \
  --convert-to pdf --outdir . <シート.pptx>
pdftoppm -r 110 -jpeg <シート.pdf> nn     # 行の重なりを目視
```

`check_anonymity(prs, BANNED)` の `BANNED` には、店名・商標・代表者名・
市区町村名・受賞名・取引先名を**その案件の分だけ全部**入れる。
ビルドスクリプトに `assert not ng` を書いておけば、後から文章を足したときも
社名が漏れた瞬間にビルドが止まる。

**ファイル名にも社名を入れない。** 買手へそのまま転送できる名前にする
（例：`ノンネームシート_そば店_北関東_261021.pptx`）。

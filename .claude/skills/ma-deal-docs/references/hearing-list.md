# ヒアリング項目一覧の作り方

面談議事録と既存資料の齟齬、および買手から想定される質問を、次回面談用の質問リストとしてWordで成果物化する。

## 構成

8分野・60〜80項目。優先度を付ける。

- 【高】＝トップ面談前に確定させたい事項
- 【中】＝基本合意までに確認したい事項

| # | 分野 | 主な内容 |
|---|---|---|
| 1 | 会社分割スキーム | 分割の設計／実行上の障害（該当案件のみ） |
| 2 | 譲渡条件・オーナーのご意向 | 希望価額、関与形態、ロックアップ、アーンアウト、連帯保証 |
| 3 | 株主・資本構成 | 株主名簿、名義株、定款、譲渡制限 |
| 4 | 事業・取引条件 | 売上構成、取引先・商流、在庫・原価、外注 |
| 5 | 組織・人事 | キーパーソン、引継ぎ計画、就業規則、退職金規程 |
| 6 | 財務・税務 | 資産の時価、借入条件、簿外債務、税務調査 |
| 7 | 契約・法務・許認可 | 賃貸借契約、COC条項、知的財産、係争 |
| 8 | プロセス関連（社内確認事項） | 契約締結、資料回収、社内進行管理 |

第8章の末尾には必ず「※本項は社内確認事項であり、買手候補への開示資料には記載しない」と注記する。

## 良い質問の作り方

**議事録の内容をそのまま質問に変換しない。**議事録と既存資料を突き合わせ、矛盾や説明のつかない点を質問にする。そのほうが相手も答えやすく、買手からの質問を先回りできる。

例：
- 「原則買取100%で在庫を抱えない方針」と聞いたが、棚卸資産廃棄損が3期連続で増加している → この乖離の要因は何か
- 「ロイヤリティ料率は概ね20%」と聞いたが、支払計上額は売上高比1.2〜5.3%にとどまる → 料率の適用範囲と支払形態はどうなっているか
- 議事録に出てくる取引先名が、売上先リストに存在しない → 売上計上先なのか版権元なのか

数字を添えて聞くと、相手が具体的に答えられる。

## Wordの体裁

- 游ゴシック、本文10pt
- 見出し1（章）：13pt太字・紺・下罫線／見出し2（節）：11pt太字・青
- 箇条書きは `■` の記号（`LevelFormat.BULLET`で定義。文字として `■` を直接書かない）
- 冒頭に作成日と目的を1段落で置く

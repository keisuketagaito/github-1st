# 不動産パートの作り方（登記簿・課税明細・契約書の突合）

不動産は、中小企業M&Aで**最も論点が隠れている領域**である。代表者個人名義の事業用地、会社債務の担保になっている個人資産、借地、相続登記の未了、未登記建物、農地など、決算書だけでは何も見えない。概要書に載せる前に、必ず資料を突き合わせて洗い出す。

## 1. 集める資料（すべて法人・個人の両方）

| 資料 | 取れる情報 | 注意 |
|---|---|---|
| 固定資産税課税明細書（市町村ごと） | 所在・地番・家屋番号の有無・課税地目・面積・建築年・**評価額** | 物件リストの出発点。法人分と代表者個人分の**全市町村分**をもらう。親族名義の敷地がある場合は親族分も |
| 登記簿謄本（土地・建物の全部事項） | 所有者・取得原因・登記地目・地積・**乙区の担保**・共同担保目録・**不動産番号（13桁）** | 課税明細から取得リストを作って請求する（§6） |
| 共同担保目録（謄本に付属） | 同じ担保に入っている物件の一覧 | 課税明細にも取得リストにも載っていない物件がここで見つかる |
| 賃貸借契約書（借地・借家・貸地） | 貸主／借主・賃料・期間・更新・用途制限・**譲渡・転貸禁止条項**・満了日 | 当社が借りている物件と、当社が貸している物件の両方 |
| 決算書の固定資産内訳・償却台帳 | 簿価 | 複数筆がまとめて計上されていることが多い → 個別簿価は「要確認」 |
| 本人聴取 | 用途（何に使っているか）、稼働状況、名義の経緯 | 「この建物は何か」を課税明細の余白に書いてもらうと早い |

スキャンPDFは文字が取れない。`pdftoppm -png -r 150` で画像にして目視で読む。

## 2. 手順

1. **課税明細から物件リストを作る**（法人／個人 × 市町村 × 土地／建物）
2. **登記簿取得リストを作り、謄本を取得する**（§6）
3. **謄本を解析する**：`scripts/registry_parse.py <PDFフォルダ>` で所有者・地目・地積・現存担保・共同担保目録を一覧化。結果は必ず数件、原本と目視で照合する
4. **突合する**：課税明細 × 謄本 × 共同担保目録 × 契約書 × 決算書。差異を§4のパターンに当てはめて「論点」として拾う
5. **拠点に紐付ける**：地番ごとに「どの養魚場・工場・本社の敷地か」を決める。概要書の拠点一覧の敷地面積（坪）と所有地の合計を照合すると、借地や聴取漏れが見つかる（例：拠点一覧2,100坪に対し所有地992坪 → 差分は借地の疑い）
6. **担保をグループ化する**：共同担保目録の番号は法務局ごとに違うが、同じ極度額・同じ権利者・同じ設定日なら同一の根抵当権。物件をグループに束ねる
7. **マスターに入力**：`不動産(所有) ②`（物件明細）、`不動産(登記･担保)`（担保・明細・集計・要確認）、`不動産(賃借)`（契約）、`土地`（時価評価）。数値はここから概要書に貼る
8. **概要書を作る**（§5）

## 3. 謄本を読むときの落とし穴

- **抹消済みの担保**は原本では下線で示されるが、テキストでは区別できない。「2番 1番根抵当権抹消」という登記から、順位1番が抹消済みと判定する
- **共同担保目録の見出し**は「共 同 担 保 目 録」の1行。乙区本文中の「共同担保 目録第641号」を見出しと誤認すると、それ以降の乙区（＝現存する担保）を読み落とす
- **地積・地目は表題部の最後の行が現在値**。それより上は変更履歴（分筆・国土調査による更正など）
- **所有者は甲区の最後の所有権登記**。住所変更などの付記登記は所有者を変えない
- **建物の床面積は、主たる建物＋附属建物の各階の合計**。附属建物が4棟あって課税明細の数字と大きく違う、ということがよくある。**合計は必ず検算する**（1階＋2階の足し算を誤った実例あり）
- テキスト層の都合で氏名の1文字が落ちることがある（「鳥塚康弘」→「鳥康弘」）。同じ住所の他の謄本と照合する
- 取扱店の表記は設定当時のまま。担当支店が変わっていることがある（聴取で確認）

## 4. 突合で見つかる典型論点（チェックリスト）

| パターン | 見つけ方 | 概要書での扱い |
|---|---|---|
| **代表者個人名義の事業用地** | 謄本の所有者 | 買取／賃貸借の手当てが必要。拠点別に「土地＝個人、建物＝法人」を明示 |
| **個人名義地が会社債務の共同担保** | 乙区の債務者＝会社、所有者＝個人 | 担保解除と不動産の手当てを一体で設計する論点として明記 |
| **借地（第三者名義）** | 拠点の敷地が謄本で第三者名義 | 契約書から賃料・期間・更新・用途制限を記載。契約書未受領なら要確認 |
| **譲渡・転貸禁止条項** | 賃貸借契約書 | 株式譲渡では賃借人は変わらないが、事前説明・承諾取得が望ましい旨を記載 |
| **貸地・貸家（賃料収入）** | 賃貸借契約書、非稼働拠点の聴取 | 「非稼働資産」が実は収益を生んでいる → ポジティブ材料。満了日は要確認 |
| **相続登記の未了** | 所有者が故人・先代 | 手続き状況（依頼済み・完了見込み）を聴取して記載 |
| **未登記建物** | 課税明細にあるが謄本がない／構造・面積が一致しない | 表題登記の要否を要確認 |
| **課税明細の転記漏れ・差異** | 登記面積≫課税面積 | 要確認。未登記増築の可能性も |
| **共同担保目録にだけ載っている物件** | 目録と課税明細の照合 | 取得リストに追加して謄本を取る（課税されていない建物のこともある） |
| **登記地目が農地（田・畑）** | 謄本の地目 | 法人への移転には農地法の許可、または非農地証明＋地目変更登記が前提 |
| **休眠担保** | 戦前・昭和の少額抵当権が残存 | 事業に関係なければ概要書には載せず、マスターに記録 |
| **決算書の合算計上** | 固定資産内訳の摘要 | 個別簿価は要確認と注記 |

## 5. 概要書のページ構成

参考にするのは他案件の「不動産概況」「不動産公図」ページ。公図の画像がなくても、色分け（法人＝紺、代表者個人＝黄土色、第三者＝灰色）の考え方は担保の図解で再現できる。

| ページ | 中身 | 作り方のポイント |
|---|---|---|
| **不動産概況** | 拠点ごとに 所在地／土地面積／土地の所有区分／建物の所有区分／土地時価／建物評価額／担保 ＋ 注記 ＋ ポイント3点 | リード文は「稼働◯拠点のうち◯拠点を自社グループで保有、借地は◯のみ」と**強み**から書く。数字は千円 |
| **担保設定・権利関係** | 担保グループごとに 金融機関・極度額 → 担保物件を色分けのチップで並べる ＋ 権利関係の留意点 | 「債務者はすべて当社、第三者債務の物上保証なし」と明記。チップが右端からはみ出さないよう幅を自動計算する |
| **不動産詳細（明細）** | 法人土地／法人建物／個人土地…を**1枚15〜18行まで**で分割 | 行が増えたら内容で分ける（生産拠点と本社、市ごと等）。拠点ごとに行の塗りを交互にして読みやすくする。担保番号の列と、下にコールアウト帯（担保の対応関係） |

- 時価は **固定資産税評価額÷0.7**（公示価格水準の目安）。建物は簿価＝時価の前提とし、個別簿価が不明なら時価の列を設けない（空欄だらけの列は載せない）
- 代表者個人の**非事業用資産**（自宅以外の農地・山林など）は明細を載せず、集計値1行にとどめる（個人資産であり本件と無関係）
- 用途が分かるたびに区分を見直す。「非事業用」としていた土地が、後から本社・冷凍庫の敷地と判明することがある

## 6. 登記簿取得リスト（確認リスト）の運用

- 課税明細から作った取得リストに、**取得状況（取得済／要確認／未取得）・取得日・13桁不動産番号**を入れていく
- 「要確認」＝謄本は取れたが課税明細の建物と一致しない（未登記の可能性）
- 未取得・追加確認は別シートにまとめる。区分は **会社所有／個人所有／親族・第三者所有（当社建物の敷地・借地）** の3つ
- 共同担保目録・契約書・追加の課税明細で見つかった物件は、新しい資産IDを振って追記する

## 7. 代表者個人所有地の買取価格の試算

売主から「いくらで売ればいいか」と聞かれる前に、マスターに試算シート（`個人不動産_買取試算`）を作る。

| 区分 | 例 | 扱い |
|---|---|---|
| A 生産拠点の敷地 | 養魚場・工場 | 買取必須 |
| B 本社・倉庫等の敷地 | 当社建物が建っている土地 | 買取対象 |
| C 用途要確認 | 隣接地・個人の居宅 | 要協議 |
| D 社長自宅 | | 対象外を想定 |
| E 非事業用 | 田・畑・山林 | 対象外 |

| シナリオ | 算式 | 意味 |
|---|---|---|
| ① 時価 | 固評÷0.7 | 上限の目安 |
| ② 固定資産税評価額 | 固評×100% | 売主が欲張らない前提の基本線。地方の養魚池・雑種地は実勢が固評÷0.7を下回ることが多く、時価として説明しやすい |
| ③ 下限 | 時価×1/2 | 個人→法人で時価の1/2未満だと時価で譲渡したとみなされる（所得税法59条）。**固評の約71%が実質的な下限** |
| ④ 任意の掛け目 | 固評×入力セル | 交渉用 |
| ⑤ 一部賃貸借 | 高額な拠点を除く | 買手の初期負担を抑える案 |

あわせて書く論点：
- **買主側の受贈益**：時価より安く取得すると差額に課税される可能性。評価額の大きい筆は不動産鑑定で時価の裏付けを取る
- **農地法**：登記地目が田・畑の筆を列挙
- **担保抹消**：対象地に会社債務の根抵当権があれば、移転前に弁済・借換えで抹消
- **スキーム**：土地の買取額が株式の希望価格を大きく上回ることがある。賃貸借（賃料は公租公課の2〜3倍が地方の事業用借地の目安）や将来買取条項との比較を示す
- **売主の手取り**：取得費不明なら概算取得費（譲渡価額の5%）、長期譲渡の税率20.315%で概算（税理士確認要と明記）

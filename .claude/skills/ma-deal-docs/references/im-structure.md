# 企業概要書（IM）の標準構成とページの作り方

スライドサイズは 11.69 × 8.27 インチ（A4横）。フォントは游ゴシック（本文）／Arial（数字）。

## 標準ページ構成

セクション扉を挟んで5部構成。案件により事業概要パートのページ数が最も変動する。

| # | セクション | ページ |
|---|---|---|
| 1-3 | — | 表紙／はじめに（留意事項・照会先）／目次 |
| 4-11 | エグゼクティブサマリー | 扉／基本情報／本件想定スキーム／会社分割スキームの前提整理／財務ハイライト（P/L）／財務ハイライト（B/S）／分割後B/Sイメージ／譲渡希望条件 |
| 12-23 | 事業概要 | 扉／商流／制作実績・取扱商品・事例／制作フロー／特徴、強み、成長性等 |
| 24-25 | — | 主要販売先別売上高／仕入先別取引高 |
| 26-31 | 組織、拠点、設備等 | 扉／組織図／株主及び役員／従業員／拠点概要／保有設備一覧 |
| 32-36 | 財務情報詳細 | 扉／貸借対照表／損益計算書／売上原価の内訳／販売費及び一般管理費 |
| 37-40 | Appendix | 扉／沿革／代表者経歴／報酬体系 |
| 41 | — | 裏表紙 |

会社分割がない案件では「本件想定スキーム」「会社分割スキームの前提整理」「分割後B/Sイメージ」を落とし、不動産保有がなければ「不動産詳細」を落とす。**使わないページは残さず削除する。**空欄だらけのページは買手に「情報が出てこない会社」という印象を与える。

## 案件ごとの構成の決め方

標準構成は出発点にすぎない。**受領資料と聴取内容をすべて読んでから**、その会社の「魅力」と「買手が必ず気にする論点」を書き出し、それぞれにページを割り当てる。ページを足す判断の目安：

| 案件の特徴 | 追加するページ（例） |
|---|---|
| 不動産を保有している／代表者個人名義の事業用地がある | 不動産概況・担保設定と権利関係・不動産詳細（法人／個人で分割）→ `real-estate.md` |
| 仕入・販売価格が協定価格・公定価格で決まる | 価格形成の仕組み（仕入と販売の図解）＋販売単価の推移 |
| 生き物・農産物など季節性がある | 生産サイクル（年間カレンダー） |
| 原料・品種・製法に優位性がある | 一般品との比較表（特性・用途・希少性） |
| 顧客・用途が多様 | 商品・用途別の顧客構成 |
| 許認可が要る | 許認可一覧（新規参入障壁として見せる） |
| 拠点・設備が多い | 拠点一覧・所在地図・写真、保有設備一覧（全件を転記し行数で分割） |
| 業績が悪化している | 一過性要因の定量化と正常収益力（財務ハイライトとセット） |

1ページ1メッセージ。同じ論点を2ページに分けるなら、見出しに①②を付けて「何で分けたか」（土地／建物、市ごと等）をタイトルに書く。

## 買手に魅力が伝わる書き方

事実は隠さない。ただしマイナスだけを並べると買手は検討をやめる。**プラスを先に、マイナスは「一過性」「手当て可能」「対応済み・手続き中」とセットで**書く。

| 事実 | 書き方の例 |
|---|---|
| 直近期が営業損失 | 原料の不漁による仕入コスト増（約◯百万円）を分離し、数量要因は限定的と示す |
| 事業用地が代表者個人名義 | 稼働◯拠点のうち◯拠点を自社グループで保有、借地は◯のみで賃料負担が軽微 |
| 非稼働の不動産 | 第三者へ賃貸し年間◯千円の賃料収入 |
| 相続登記が未了 | 司法書士へ依頼済み、◯月頃完了見込み |
| 価格決定権がない | 協定価格により過度な価格競争に晒されにくい。実際に◯期連続で値上げ |

売主から聴取した状況の変化（手続きの進捗、契約の更新など）は、その都度すぐに反映する。

## 1ページの情報量の上限

実際に描画して確かめた目安（A4横・游ゴシック）：

- **表**：9.5pt・行高0.30inで見出し＋15行程度、9pt・0.265inで18行程度。超えたら内容で分割する
- **字幕（リード文）**：2行まで。1行は全角約70字（11pt）
- **注記**：3〜4行。1行は全角約95字（8〜8.4pt・幅10.96in）。1行に収まるよう文を切る
- **全行が「—」になる列は載せない**（例：建物だけのページの時価列）

## 修正依頼を受けたとき

- **ページ番号はタイトルで照合する。**依頼者のページ番号はフッター表記で、表紙などを数えずにスライド番号とずれることが多い。作業前に「P24＝スライド25＝不動産概況」のような対応を確認する
- **依頼者が編集した最新版を受け取ったら、それを起点にする。**作り直さず、該当箇所だけを差し替える（依頼者の言い回しの変更を消さない）。作業後に旧版との差分を取り、「変更したスライドはこれだけ」と報告する
- **数字を直したら、波及先をすべて検索して直す**（リード文・ポイント欄・合計・注記・他ページ・マスター・確認リスト）
- 概要書の修正で分かった事実（用途・名義・担保の対象）は、先にマスターへ戻す
- 修正の過程で自分の過去の誤りに気づいたら、黙って直さず、どこをどう直したかを報告する

## ノンネームシート・プロセスレター

- **ノンネーム**は特定されないことが目的。業種は大分類（例：水産養殖業）、エリアは地方単位（近畿）、数字は丸める（売上「2億円以上」、従業員「15名以上」、創業「50年超」）。魚種・品目・地名・団体名・固有の件数を入れない。**NGワードリストを作って最終版を機械的にスキャン**する。損失は隠さず「直近期は一過性要因により損失（前2期は営業黒字）」のように書く
- **プロセスレター**は社内用。確定していない項目は「要確認」、社内判断が要る項目（案件ランク・日程）は空欄のまま残す。定型の枠に収まらないときは段落数を数えて行数上限を確認する（自動縮小が無効なテンプレートが多い）

## ページ共通の構造

ほぼ全ページが同じ骨格を持つ：

- 左上：タイトル（プレースホルダー）
- 右上：セクション名のテキストボックス
- タイトル下：**字幕（リード文）**。そのページで最も言いたいことを1〜2行で断言する
- 本文：表または図
- 最下部：注記（※で始まる補足・出所・要確認事項）

リード文は「何が書いてあるか」ではなく「**だから何なのか**」を書く。「売上高の推移は下表のとおりです」ではなく「輸出売上の反落を国内売上の伸長が補い、2026年1月期も高水準を維持」と書く。

字幕プレースホルダーは高さ0.26インチで自動拡張する。2行に収まる長さ（全角110字程度）を目安にし、3行になるとその下のコンテンツと重なる。

## ページ別のポイント

### 財務ハイライト（P/L）

参考にすべき構造は「①実績トレンド ②見通し／示唆」の2行見出し＋右側2ボックス。

- 上段「Comment」：≪売上高≫≪売上総利益≫≪営業利益≫≪見通し≫の見出し付きで、数字の**動いた理由**を書く。「大型案件により拡大」のような根拠の薄い説明ではなく、PL上で検証できる要因（輸出売上の増減、粗利率、販管費）で説明する
- 下段「【調整項目】」：≪科目群≫ごとに調整理由を列挙し、最後に `✓ 調整後EBITDA（過去3期平均）は◯◯千円` と結論を置く
- 単年が極端に低い場合は3期平均が実力を下回るため、**直近2期平均も併記**する

### 財務ハイライト（B/S）

会社分割で切り出す資産には表内に `※` を付け、注記で「※印の科目は会社分割による承継対象（本取引の譲渡対象外）です」と明記する。これを書かないと買手は「潤沢な金融資産も付いてくる」と読む。

### 商流

対象会社（中央）／主要販売先（右）／主要仕入先・外注先（下）の3ブロック。仕入先と外注先が実態として同じなら1ブロックに統合してよい。

対象会社ブロックは**事業ライン別**に分ける（例：ライセンス案件／OEM受託案件／自社オリジナル商材）。ブロック間の矢印には流れの名前を書く（商品化許諾／製品納入・買取100%／ロイヤリティ）。

未確認の商流（料率など）は最下部に専用バンドを設け、「現時点の仮説｜要ヒアリング」と明示したうえで**仮説と実績を並べる**。

### 組織図

従業員ページのNo.と対応させる。ページ内に「※図中のNo.は『従業員』ページの従業員No.と対応」と注記すると、買手が人員構成を追える。兼務・育児休業・入社予定も脚注に落とす。

### 制作実績・事例ページ

権利元の系統（大手出版社／ライトノベル・ゲーム原作など）で分類すると、買手が最も知りたい「どの版元と取引実績があるか」が伝わる。バナー画像の著作権表記はそのまま転記する。個別事例ページは商品構成・展開時期・受注規模が揃ってから作る。揃わないうちは「データルームにて開示予定」と注記して器だけ用意する。

### 譲渡希望条件

条件1スキーム／条件2希望価格／条件3付帯条件／その他譲渡理由の4バンド。各バンドは2行程度に収め、フォントは12pt。長文になるとバンドからはみ出す。

代表者の継続関与の意向は付帯条件の一般的条件に埋もれさせず、独立した行として書く。買手の最大の関心事になる。

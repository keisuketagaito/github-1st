# 企業概要書（IM）の標準構成とページの作り方

スライドサイズは 11.69 × 8.27 インチ（A4横）。フォントは游ゴシック（本文）／Arial（数字）。

## 標準ページ構成

セクション扉を挟んで5部構成。案件により事業概要パートのページ数が最も変動する。

| # | セクション | ページ |
|---|---|---|
| 1-3 | — | 表紙／はじめに（留意事項・照会先）／目次 |
| 4-11 | エグゼクティブサマリー | 扉／基本情報／本件想定スキーム／会社分割スキームの前提整理／財務ハイライト（P/L）／財務ハイライト（B/S）／分割後B/Sイメージ／譲渡希望条件 |
| 12-23 | 事業概要 | 扉／商流／制作実績・取扱商品・事例／制作フロー／特徴、強み、成長性等 |
| 24-25 | — | 主要販売先別売上高／仕入先別取引高 |
| 26-31 | 組織、拠点、設備等 | 扉／組織図／株主及び役員／従業員／拠点概要／保有設備一覧 |
| 32-36 | 財務情報詳細 | 扉／貸借対照表／損益計算書／売上原価の内訳／販売費及び一般管理費 |
| 37-40 | Appendix | 扉／沿革／代表者経歴／報酬体系 |
| 41 | — | 裏表紙 |

会社分割がない案件では「本件想定スキーム」「会社分割スキームの前提整理」「分割後B/Sイメージ」を落とし、不動産保有がなければ「不動産詳細」を落とす。**使わないページは残さず削除する。**空欄だらけのページは買手に「情報が出てこない会社」という印象を与える。

## ページ共通の構造

ほぼ全ページが同じ骨格を持つ：

- 左上：タイトル（プレースホルダー）
- 右上：セクション名のテキストボックス
- タイトル下：**字幕（リード文）**。そのページで最も言いたいことを1〜2行で断言する
- 本文：表または図
- 最下部：注記（※で始まる補足・出所・要確認事項）

リード文は「何が書いてあるか」ではなく「**だから何なのか**」を書く。「売上高の推移は下表のとおりです」ではなく「輸出売上の反落を国内売上の伸長が補い、2026年1月期も高水準を維持」と書く。

字幕プレースホルダーは高さ0.26インチで自動拡張する。2行に収まる長さ（全角110字程度）を目安にし、3行になるとその下のコンテンツと重なる。

## ページ別のポイント

### 財務ハイライト（P/L）

参考にすべき構造は「①実績トレンド ②見通し／示唆」の2行見出し＋右側2ボックス。

- 上段「Comment」：≪売上高≫≪売上総利益≫≪営業利益≫≪見通し≫の見出し付きで、数字の**動いた理由**を書く。「大型案件により拡大」のような根拠の薄い説明ではなく、PL上で検証できる要因（輸出売上の増減、粗利率、販管費）で説明する
- 下段「【調整項目】」：≪科目群≫ごとに調整理由を列挙し、最後に `✓ 調整後EBITDA（過去3期平均）は◯◯千円` と結論を置く
- 単年が極端に低い場合は3期平均が実力を下回るため、**直近2期平均も併記**する

### 財務ハイライト（B/S）

会社分割で切り出す資産には表内に `※` を付け、注記で「※印の科目は会社分割による承継対象（本取引の譲渡対象外）です」と明記する。これを書かないと買手は「潤沢な金融資産も付いてくる」と読む。

### 商流

対象会社（中央）／主要販売先（右）／主要仕入先・外注先（下）の3ブロック。仕入先と外注先が実態として同じなら1ブロックに統合してよい。

対象会社ブロックは**事業ライン別**に分ける（例：ライセンス案件／OEM受託案件／自社オリジナル商材）。ブロック間の矢印には流れの名前を書く（商品化許諾／製品納入・買取100%／ロイヤリティ）。

未確認の商流（料率など）は最下部に専用バンドを設け、「現時点の仮説｜要ヒアリング」と明示したうえで**仮説と実績を並べる**。

### 組織図

従業員ページのNo.と対応させる。ページ内に「※図中のNo.は『従業員』ページの従業員No.と対応」と注記すると、買手が人員構成を追える。兼務・育児休業・入社予定も脚注に落とす。

### 制作実績・事例ページ

権利元の系統（大手出版社／ライトノベル・ゲーム原作など）で分類すると、買手が最も知りたい「どの版元と取引実績があるか」が伝わる。バナー画像の著作権表記はそのまま転記する。個別事例ページは商品構成・展開時期・受注規模が揃ってから作る。揃わないうちは「データルームにて開示予定」と注記して器だけ用意する。

### 譲渡希望条件

条件1スキーム／条件2希望価格／条件3付帯条件／その他譲渡理由の4バンド。各バンドは2行程度に収め、フォントは12pt。長文になるとバンドからはみ出す。

代表者の継続関与の意向は付帯条件の一般的条件に埋もれさせず、独立した行として書く。買手の最大の関心事になる。

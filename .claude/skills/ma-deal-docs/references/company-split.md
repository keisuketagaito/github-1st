# 会社分割スキーム資料の作り方

非事業用資産（投資有価証券・保険積立金・車両・不動産等）を新設分割で切り出し、事業会社の株式のみを譲渡するスキーム。オーナーが資産を手元に残しつつ、買手は事業に必要な資産だけを取得できる。

## 資料構成（全5頁）

| # | ページ | 内容 |
|---|---|---|
| 1 | 表紙 | |
| 2 | 譲渡スキーム（イメージ） | 1枚もののスキーム図。現状／譲受企業＋対象会社／オーナー＋新設会社の3ブロック |
| 3 | 分割対象資産の確認 | 科目・内容・期末簿価・備考の一覧 |
| 4 | 会社分割スキームの前提整理 | 現状／対象会社／新設会社の内訳をテキストで整理 |
| 5 | 分割後BSイメージ | 分割前／対象会社／新設会社の3面BS |

## 分割後BSの作り方

3つのBSを同じ行構成（現金及び預金／その他流動資産／有形固定資産／無形固定資産・投資等／資産合計／借入金／その他負債／純資産／負債・純資産合計）で並べる。列を揃えると差分が一目で分かる。

- 対象会社＝分割前 － 承継額
- 新設会社＝承継額のみ（負債なしなら純資産＝資産合計）
- 3面とも借貸一致することを確認する

現預金の扱いは案件により異なる。借入同等額のみ残してネットキャッシュ±0とする案もあれば、全額残置する案もある。**どちらにせよ、その前提を図とBSの両方に明記する。**

## 案件マスターへの反映

「分割後BS」タブを新設する。`修正BS(借方)` をコピーして作り、下部に負債・純資産の部を追記する構成が扱いやすい。列は以下：

| 列 | 内容 |
|---|---|
| C | 修正後BS（分割前）＝修正BSの修正後列を参照 |
| D | 分割承継額（△で表示） |
| E | 分割後BS（分割会社）＝C+D |
| F | 新設会社BS ＝ －D |

純資産側に「【分割承継純資産】」行を設け、`=分割後BS!D<資産合計行> - D<負債合計行>` で承継純資産を算出する。この1行で借貸が一致する。

## 必ず注記する前提

- **分割の形態**：分割型（人的）分割か分社型（物的）分割か。分社型の場合、分割会社に新設会社株式が資産計上され純資産は減少しないため、別途現物配当等が必要
- **適格性**：適格分割（簿価承継）を前提とするか。非適格なら承継資産の含み損益に課税が生じる
- **担保・財務制限条項**：承継資産が借入金の担保に供されていないか。純資産が大きく減少するため、財務制限条項（純資産維持条項）への抵触を必ず確認する
- **契約の承継可否**：保険契約の契約者変更、車両の名義変更、債権者保護手続
- 分割手続に要する期間（SPA締結後1〜1.5ヶ月程度が目安）

## 評価への影響

切り出す資産がネットキャッシュのキャッシュライクアイテムに算入されている場合、**分割後は当該金額が丸ごと除外される**。時価純資産も同額減少するため、コスト／マーケット両アプローチの試算結果が大きく変わる。分割後BSを作ったら、必ず評価への影響額を試算して依頼者に提示する。

# 評価パート（VR→ セクション）

**評価書の作成・更新は専用スキル `ma-valuation` を読むこと**（`.claude/skills/ma-valuation/SKILL.md`）。
評価基準日の決め方、修正BSの科目別評価方法、修正PLの調整項目、年買法・EV/EBITDAマルチプル法の算式、
評価書23ページの構成、当社フォーマットのテンプレート（`assets/valuation_report_template.pptx`）まで
揃っている。本ファイルは案件マスター側の最低限の要点のみを残す。

## 採用するアプローチ

| アプローチ | 手法 | 採否 |
|---|---|---|
| コストアプローチ | 時価純資産＋営業権法（年買法） | 採用 |
| マーケットアプローチ | 類似会社比準法（EV/EBITDAマルチプル法） | 採用 |
| インカムアプローチ | DCF法・収益還元法 | 不採用（詳細な事業計画が存在せず算定困難） |
| インカムアプローチ | 配当還元法 | 不採用（少数株主視点の手法であり本件取引の性質に不適） |

## 算式（要点のみ）

```
【年買法】
基準営業利益 ＝ Σ(修正後税考慮後営業利益 × 加重)   加重は直近期50%・前期30%・前々期20%
税考慮額     ＝ 修正後営業利益 × △34%
営業権       ＝ 基準営業利益 × 倍率（1〜3倍）
想定株式価値 ＝ 時価純資産 ＋ 営業権

【EV/EBITDAマルチプル法】
基準EBITDA   ＝ Σ(修正後EBITDA × 加重)          修正後EBITDA ＝ 修正後営業利益 ＋ 減価償却費
EV           ＝ 基準EBITDA × 倍率（3〜5倍）
想定株式価値 ＝ EV ＋ ネットキャッシュ
```

> **非流動性ディスカウントは適用しない。**当社フォーマットの評価書は
> `想定株式価値 ＝ EV ＋ ネットキャッシュ` である。EVに30%のディスカウントを掛ける流儀もあるが、
> 当社は掛けない。掛けると過去の評価書と整合しなくなる。

## マスター側の注意

- 税効果は実効税率34%。繰越欠損金を有し課税所得の見込みが立たない会社では
  繰延税金資産の回収可能性を認めず、税効果をゼロとする（保守的な取扱い）
- 資料が未受領で評価できない科目は**簿価評価とし、その理由を明細シートと評価書の両方に残す**
- 概要書の調整後EBITDAと評価書の修正後EBITDAは**同じ調整方針**で算定し、3期とも一致を検算する
- **テンプレートの既知の不具合**：`年買法` の加重平均の集計行が `=SUM(G5:G7)` のように
  修正額行を含んで二重計上するケースがある。`=SUM(G6:G7)` に是正すること。
  `年買法!K4`（想定株式価値表の時価純資産）にダミー値がベタ書きされていることもある（`=C7` に直す）
- **`修正PL` / `修正SGA` の3列ブロックは C/F/I/L/O 始まりで第2期〜進行期に対応する。**
  未使用ブロックを消すつもりで評価基準期のブロックを消す事故が起きやすい。
  消す前に3行目のヘッダーで対応する期を確認する

## 時価純資産の算定（修正BS）

評価基準日の簿価に修正額を加減する。

| 科目 | 取扱い | 必要資料 |
|---|---|---|
| 現金・預金 | 残高証明との一致を確認し簿価評価 | 残高証明書 |
| 受取手形 | 割引手形は「受取手形／割引手形」で両建て計上されているか確認 | 手形帳・割引明細 |
| 貸倒引当金 | 売掛債権を個別に回収可能性判断するため**全額戻入**（経常的な貸倒れがない前提） | － |
| 売掛金 | 補助残高一覧・年齢表で個別判断。3期同額の残高は理由を確認。民事再生等は回収不能見込額を減額 | 補助残高一覧表・年齢表 |
| 棚卸資産 | 滞留・陳腐化を減額（例：販売可能価格が原価の70％なら30％減額） | 商品有高帳・滞留明細 |
| 減価償却資産 | 台帳から適正償却額を再計算し、不足額を減額（**超過していれば増額修正もある**） | 固定資産減価償却内訳明細書 |
| 土地 | 路線価×地積、または固定資産税評価額×倍率。路線価は国税庁「路線価図・評価倍率表」で確認 | 路線価図・固定資産税課税明細書・登記簿謄本 |
| 電話加入権 | 換金価値なしとしてゼロ評価 | － |
| 有価証券 | **評価実施日（基準日ではない）**の終値・基準価格×保有数量 | 有価証券内訳書・残高証明書 |
| 敷金・保証金 | 賃貸借契約書の**契約解除時の返還金額**へ評価替え（償却条項に注意） | 賃貸借契約書 |
| 保険積立金 | 解約返戻金額で評価。簿外の積立（経営セーフティ共済等）も拾う | 保険証券・解約返戻金試算表 |
| 未払給与 | 賃金規程の締日から基準日までの経過日数分を追加計上（社保概算15％を加算） | 就業規則・賃金規程・給与台帳 |
| 賞与引当金 | 支給対象期間の経過月数分を引当（社保概算15％を加算） | 就業規則・賞与支給実績 |
| 退職給付引当金 | 退職金規程に基づく要支給額－外部積立額（中退共等）。原則**自己都合**で算定し、定年間際の者のみ会社都合 | 退職金規程・中退共残高 |
| 役員退職慰労引当金 | 役員退職慰労金規程に基づき計上（最終月額報酬×在任年数×役位別倍率） | 役員退職慰労金規程 |

資料が未受領で評価できない科目は**簿価評価とし、その理由を明細シートと評価書の両方に残す**。
「評価できなかった」ことも重要な情報で、DDでの追加調整余地を示す。

税効果は実効税率34％。修正額が僅少な場合は修正BS上で認識せず、
年買法シートの時価純資産算定で一括考慮してよい（その旨を注記する）。
土地（事業用で売却見込みが低い）・電話加入権（流動性なし）は税効果を認識しない。

### 役員退職慰労金の論点

役員退職慰労金は**株式価値から減算される**（引当後の株式価値が売主の手取りの原資になる）。
売主から見ると、退職金で受け取る部分と株式譲渡益で受け取る部分では税率が異なるため、
「退職金を多く出すほど手取りが増える」とは限らない。買手から見ると、対象会社に現預金が多ければ
退職金として支出して特別損失で節税できるメリットがある。**双方の利害が一致しない論点**なので、
評価書では引当前後の株式価値を分けて示し、税負担の試算は税理士に委ねる旨を注記する。

## 正常収益力の算定（修正PL／修正SGA）

営業利益ベースで調整する。**B/Sの修正事項は原則としてP/Lの修正事項**（減価償却過不足額、
退職給付引当金、貸倒引当金）。

**中小オーナー企業に特有の調整**

- **役員報酬・役員賞与**：M&A時に退任予定の役員の報酬を控除し、継続勤務予定の役員の報酬は
  修正しない。新体制で必要となる役員報酬は標準額に置換える。法定福利費は概算料率15％で連動調整
- 役員保険料、オーナー個人に帰属する経費（譲渡後に発生しない費用）
- 貸倒引当金繰入額（直接評価の観点から控除）
- 寄付金（譲渡後に発生しない費用）
- 買取予定不動産がある場合、今後発生が見込まれる減価償却費・固定資産税・管理費を各期に加算

**非経常的・臨時的な損益の控除**

固定資産売却損益、投資有価証券売却損益、保険解約益、債務免除益、補助金収入など。

**支払利息・手形売却損の控除**

正常収益は債権者への分配前（資金調達コスト控除前）であるべきため。

**判断が要る論点：構造的な費用の営業費用化**

特別損失に計上されている費用が3期連続で発生し増加傾向にある場合、それは非経常ではなく
事業に構造的に内在する費用である。例えば版権グッズ事業の棚卸資産廃棄損は、
他勘定振替高を戻し入れたうえで営業費用として認識するのが実態に即する。
**「特別損失に載っているから除外」と機械的に処理しない。** 発生の継続性と事業構造との関係で判断する。

**事業に供されていない資産に係る費用**

稼働していない拠点・未供用の建物に係る減価償却費は、正常収益力から控除する。
この調整は営業利益を押し上げる一方、EBITDAの計算では減価償却費からも同額を除くため**EBITDAベースでは中立**になる。
概要書の調整後EBITDAと一致することを必ず確認する。

## 年買法（コストアプローチ）

カナリア評価書で採用している標準手法。

```
修正後税考慮後営業利益 ＝ 修正後営業利益 ×（1 － 34％）
基準営業利益 ＝ Σ(修正後税考慮後営業利益 × 加重)   加重は直近期50％・前期30％・前々期20％
営業権       ＝ 基準営業利益 × 倍率（1〜3倍）
想定株式価値 ＝ 時価純資産 ＋ 営業権
```

営業権倍率1〜3倍は国内中小企業M&Aのボリュームゾーン。
倍率は買手企業のM&A方針、取り組み意欲、想定シナジー等によっても変動する旨を Point 帯に書く。

基準営業利益がマイナスの場合、営業権はゼロとし、想定株式価値＝時価純資産となる。
`vr_builder.goodwill_nenbai()` はマイナスを0に丸める。

**テンプレートの既知の不具合**：案件マスター『年買法』シートの加重平均集計行が
`=SUM(G5:G7)` のように修正額行を含んで二重計上する。`=SUM(G6:G7)` に是正すること。

## 超過収益法（研修資料の手法／参考）

研修資料「企業評価演習問題」で教えている、営業権をより精緻に算定する手法。
時価総資産が大きい会社で年買法との差が開くため、必要に応じて併記する。

```
(1) 修正税引前純利益の3期加重平均 D ＝ A×0.2 ＋ B×0.3 ＋ C×0.5
(2) 期待利子率 F ＝ 10年国債利回り ＋ リスクプレミアム（通常3.0％）
    期待利益   G ＝ 時価総資産（買取予定不動産を含む）E × F
    超過利益   H ＝ D － G
(3) 営業権     ＝ H × 複利年金現価係数 I（持続年数3年）
    株式時価総額 ＝ 時価純資産 ＋ 営業権
```

`vr_builder.goodwill_excess()` で算定する。
**複利年金現価係数は係数表から読んだ値を `annuity_factor` に明示指定すること。**
研修資料の設例（期待利子率3.027％・持続年数3年）は係数2.7771を用いており、
単純な現在価値計算（2.8271）とは一致しない。

## EV/EBITDAマルチプル法（マーケットアプローチ）

```
修正後EBITDA ＝ 修正後営業利益 ＋ 減価償却費
基準EBITDA   ＝ Σ(修正後EBITDA × 加重)          加重は年買法と同じ
EV           ＝ 基準EBITDA × 倍率（3〜5倍）
非流動性ディスカウント ＝ EV × △30％
想定株式価値 ＝ EV － ディスカウント ＋ ネットキャッシュ
```

非流動性ディスカウントは、上場会社の株価倍率に市場性（流動性）が織込まれているため
非上場株式への適用にあたり控除する。**コストアプローチには適用しない。**

**ネットキャッシュ**は修正後BSの残高を参照する。
キャッシュライク＝現預金・非事業用の投資有価証券・保険積立金・役員貸付金等、
デットライク＝有利子負債（一年以内返済分を含む）・未払法人税等。
事業運営に供されていない運用資産をキャッシュライクに入れるかは事業性の有無で判断し、
判断根拠をコメントに残す。会社分割で切り出す資産は**ネットキャッシュから除外する**。

**役員借入金の扱いは必ず依頼者に確認する。** 法形式上は負債だが実質は資本に近く、
譲渡時に債務免除・相殺で整理されることも多い。どちらを主たる前提に置くかで株式価値が大きく変わるため、
主ケースと参考ケースを分けて併記し、どちらを主としたかを明記する。

## コストとマーケットが乖離したとき

両アプローチの結果が大きく離れることは珍しくない。**乖離そのものが分析結果**なので、
数字を寄せに行かず、乖離の理由を書く。

- 資産が重く収益力が薄い会社：コスト＞マーケット。価値が資産性に依拠していることを示す
- 資産が軽く収益力が高い会社：マーケット＞コスト。価値が収益力・のれんに依拠していることを示す
- 有利子負債が重い会社：マーケットがマイナスになりうる。EVは出ても株式価値が残らない構造を説明する

## ページ別のポイント

### 株価評価にあたっての注意点（P.3）

6項目の定型文。**売主の期待値を調整するための最重要ページ**なので削除も改変もしない。
番号は丸バッジ（楕円 0.28×0.28、x=0.67）、項目間は横罫線で区切る。

### 採用するアプローチの選定（P.6）

4行×5列の表（評価アプローチ／着目点／評価手法／採用可否と選定理由）。
採用は青丸＋「採用」、不採用は×＋「不採用」のバッジ。最下部に Point 帯。
**不採用の理由を具体的に書く。**「事業計画が存在しないため」で終わらせず、
何があれば採用できたのかまで書くと、売主が次に何を用意すべきか分かる。

### 株式価値の試算結果（P.7）

上段に「試算の前提条件」（評価対象／算定日／基準日／参照期間／目的の5行表）、
下段に「株式価値試算結果」。各アプローチを `value_range()` のバンドで示し、
右側にレンジ図（`range_chart()`）を置く。不採用のアプローチは
「※※※※※ 不採用 ※※※※※」のグレーバンドで明示する。

### BS補足／修正BS（P.10〜13）

左に表、右に Comment（縦長ボックス）。Comment は**科目名：内容**の形式で、
数字が動いた理由と要確認事項をセットで書く。
「◯◯千円である」だけの記述は情報量がない。

### 修正PLの算定（P.18）

3期×（帳簿価額／修正額／修正後）の表。修正の根拠は Comment に科目ごとに書く。
調整後EBITDAは**企業概要書の財務ハイライト（P/L）と必ず一致させる。**
一致しない場合はどちらかが誤っている。

### 年買法／EV/EBITDA（P.20〜21）

左に時価純資産（または ネットキャッシュ）、右に基準営業利益（または 基準EBITDA）の計算表、
下に倍率別の想定株式価値表。最下部に Comment 帯（算定の前提を3つ程度横並び）、
右下に Point 帯（倍率が変動する要因）。

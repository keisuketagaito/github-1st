# 株式価値評価書（Valuation Report）の作り方

## 採用するアプローチ

中小企業M&Aでは通常、以下2手法を採用しインカムアプローチは不採用とする。

| アプローチ | 手法 | 採否 |
|---|---|---|
| コストアプローチ | 時価純資産＋営業権法（年買法） | 採用 |
| マーケットアプローチ | 類似会社比準法（EV/EBITDAマルチプル法） | 採用 |
| インカムアプローチ | DCF法・収益還元法 | 不採用（詳細な事業計画が存在せず算定困難） |
| インカムアプローチ | 配当還元法 | 不採用（少数株主視点の手法であり本件取引の性質に不適） |

## 時価純資産の算定（修正BS）

評価基準日の簿価に修正額を加減する。各科目の考え方：

| 科目 | 標準的な取扱い |
|---|---|
| 貸倒引当金 | 売掛債権を個別に回収可能性判断するため**全額戻入**。経常的な貸倒れがない前提 |
| 売掛金 | 年齢表・補助残高一覧で個別判断。粉飾・長期滞留は減額 |
| 棚卸資産 | 滞留・陳腐化を減額 |
| 減価償却資産 | 台帳から適正償却額を再計算し、不足額を減額 |
| 土地 | 路線価÷0.8（または÷0.7）、固定資産税評価額×倍率で時価算出 |
| 電話加入権 | 換金価値なしとしてゼロ評価 |
| 有価証券 | 評価実施日（基準日ではない）の終値・基準価格で評価 |
| 敷金・保証金 | 賃貸借契約書の**契約解除時の返還金額**へ評価替え（償却条項に注意） |
| 保険積立金 | 解約返戻金額で評価 |
| 未払給与 | 賃金規程の締日から基準日までの経過分を追加計上（社保概算15%を加算） |
| 賞与引当金 | 支給対象期間の経過分を引当（社保概算15%を加算） |
| 退職給付引当金 | 退職金規程に基づく要支給額－外部積立額 |
| 役員退職慰労引当金 | 役員退職慰労金規程に基づき計上 |

資料が未受領で評価できない科目は**簿価評価とし、その理由を明細シートと評価書の両方に残す**。「評価できなかった」ことも重要な情報で、DDでの追加調整余地を示す。

税効果は実効税率34%。修正額が僅少な場合は修正BS上で認識せず、年買法シートの時価純資産算定で一括考慮してよい（その旨を注記する）。

## 正常収益力の算定（修正PL／修正SGA）

営業利益ベースで調整する。BSの修正事項は原則としてPLの修正事項でもある。

**中小オーナー企業に特有の調整**

- **役員報酬・役員賞与**：M&A時に退任予定の役員報酬を控除し、新体制の標準役員報酬に置換える。社会保険料も概算料率15%で連動調整する。オーナー賞与が大きい会社ではここが最大の調整項目になる
- 役員保険料、オーナー個人に帰属する経費（譲渡後に発生しない費用）
- 貸倒引当金繰入額（直接評価の観点から控除）
- 寄付金（譲渡後に発生しない費用）

**非経常的・臨時的な損益の控除**

固定資産売却損益、投資有価証券売却損益、保険解約益、債務免除益など。

**支払利息・手形売却損の控除**

正常収益は債権者への分配前であるべきため。

**判断が要る論点：構造的な費用の営業費用化**

特別損失に計上されている費用が3期連続で発生し増加傾向にある場合、それは非経常ではなく事業に構造的に内在する費用である。例えば版権グッズ事業の棚卸資産廃棄損は、他勘定振替高を戻し入れたうえで営業費用として認識するのが実態に即する。**「特別損失に載っているから除外」と機械的に処理しない。**発生の継続性と事業構造との関係で判断する。

## 年買法（コストアプローチ）

```
基準営業利益 ＝ Σ(修正後税考慮後営業利益 × 加重)   加重は直近期50%・前期30%・前々期20%
税考慮額     ＝ 修正後営業利益 × △34%
営業権       ＝ 基準営業利益 × 倍率（1〜3倍）
想定株式価値 ＝ 時価純資産 ＋ 営業権
```

営業権倍率1〜3倍は国内中小企業M&Aのボリュームゾーン。

**テンプレートの既知の不具合**：加重平均の集計行が `=SUM(G5:G7)` のように修正額行を含んでしまい二重計上するケースがある。`=SUM(G6:G7)` に是正すること。

## EV/EBITDAマルチプル法（マーケットアプローチ）

```
基準EBITDA   ＝ Σ(修正後EBITDA × 加重)          修正後EBITDA ＝ 修正後営業利益 ＋ 減価償却費
EV           ＝ 基準EBITDA × 倍率（3〜5倍）
非流動性ディスカウント ＝ EV × △30%
想定株式価値 ＝ EV － ディスカウント ＋ ネットキャッシュ
```

非流動性ディスカウントは、上場会社の株価倍率に市場性（流動性）が織込まれているため非上場株式への適用にあたり控除する。コストアプローチには適用しない。

**ネットキャッシュ**は評価基準（修正後BS）の残高を参照する。キャッシュライク＝現預金・非事業用の投資有価証券・保険積立金等、デットライク＝有利子負債・未払法人税等。事業運営に供されていない運用資産をキャッシュライクに入れるかは事業性の有無で判断し、判断根拠をコメントに残す。

## 評価書（PowerPoint）の構成

全23頁程度。

| # | ページ |
|---|---|
| 1-4 | 表紙／はじめに（留意事項・照会先）／株価評価にあたっての注意点／目次 |
| 5-7 | Section1 Valuation Summary：扉／採用するアプローチの選定／株式価値の試算結果 |
| 8-15 | Section2 Financial Analysis（B/S）：扉／過去BSの推移／BS補足［資産］／修正内容詳細／修正BS［資産］／BS補足［負債・純資産］／修正BS［負債・純資産］／ネットキャッシュの算定 |
| 16-19 | Section2 Financial Analysis（P/L）：扉／過去PLの推移／販管費の修正／修正PLの算定 |
| 20-22 | Section3 Valuation Details：扉／年買法による算出／EV/EBITDAマルチプル法による算出 |
| 23 | 裏表紙 |

不動産を保有しない案件では「修正内容詳細［土地］」を「評価科目別の検討結果」に差し替える。科目ごとに帳簿価額・評価差額・評価額・調整事由を一覧化すると、評価しなかった科目とその理由も同じ表で示せる。

各ページのCommentは、**数字が動いた理由**と**要確認事項**をセットで書く。「◯◯千円である」だけの記述は情報量がない。

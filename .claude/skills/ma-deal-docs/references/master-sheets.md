# 案件マスターのシート構成と転記先

案件マスターは3つのセクションに分かれている。セクション見出しシート（`財務入力→` `VR→` `IM→`）は空で、区切りとしてのみ存在する。

## 共通ルール（`ルール`シート）

1. 文字は「游ゴシック」、数字は「Arial」。備考欄などの細かい文章は「游ゴシック Medium」
2. タイトル・合計欄は太字
3. **数字は円単位で入力する。表示は千円単位に設定済み**
4. 背景は紺・水色・グレー・白・青（パレット上部の色）。線は紺・白・青

## 財務入力→（決算書の転記）

| シート | 内容 | 備考 |
|---|---|---|
| `BS(借方)` | 資産の部。C〜E列＝過去3期、F列＝4期目、G列＝進行期TB | 63行に借貸一致の`EXACT()`チェックあり |
| `BS (貸方)` | 負債・純資産の部 | シート名の`BS`と`(貸方)`の間にスペースがある。参照時に注意 |
| `PL` | 損益計算書。2列1組（帳簿価額／売上高比）で1期 | 63〜64行に当期純利益の整合チェックあり |
| `CR` | 製造原価報告書。製造業以外は空欄のまま | |
| `SGA` | 販売費及び一般管理費。PLの販管費行がここを参照 | |

期のヘッダーは`BS(借方)!C4:G4`が原本で、他シートは全てここを参照している。ここだけ直せば全シートに伝播する。

## VR→（株式価値評価）

| シート | 内容 |
|---|---|
| `株式価値 ` | 3アプローチのレンジ集計（グラフ用）。自動計算のため触らない |
| `修正BS(借方)` / `修正BS(貸方) ` | 評価基準日の時価純資産。C列＝簿価、D列＝修正額、E列＝修正後 |
| `売掛・棚卸` `減価償却` `土地` `保険` `有価証券` `未払人件費・賞与` `退職金` `税効果` | 修正BSの明細。使わない科目はテンプレートのダミー値を消し「該当なし」と理由を書く |
| `分割後BS` | 会社分割案件で使用（標準テンプレートには無い。必要時に作成） |
| `ネットキャッシュ` | キャッシュライク／デットライクの集計。EV/EBITDA法が参照 |
| `修正PL` / `修正SGA` / `修正CR` | 正常収益力。3期分×（帳簿価額／修正額／修正後） |
| `年買法` | コストアプローチ。時価純資産＋営業権 |
| `EV EBITDAマルチプル` | マーケットアプローチ |
| `参照企業` | 類似上場会社。倍率は算定日時点の株価で更新する前提 |

## IM→（企業概要書）

IM→の各シートには、概要書の表と**同じ行・列・書式の「貼付範囲」**を組む。概要書はその範囲をコピーして貼るだけで作る
（作り方・書式・列構成の標準は `references/im-design.md`、書式キットは `scripts/master_im_style.py`）。

- 各シートのA2に赤字で「■ 貼付範囲 B4:F25 → 企業概要書『財務ハイライト（P/L）』」と書き、ルールシートに一覧を置く
- 範囲内の数値は財務入力→・VR→のシートを数式で参照する（IMシートに数字を手入力しない）
- リード文・Comment用の集計は範囲の下の「参考（貼付範囲外）」欄で計算する
- 横に並べる表も同じ行に置かない（行高が共有される）

| シート | 貼付範囲の中身 | 概要書の対応ページ |
|---|---|---|
| `会社概要` | 項目／内容 | 基本情報 |
| `PLハイライト` | 3期＋進行期、前期比・利益率行、調整項目、調整後EBITDA | 財務ハイライト（P/L）。調整後EBITDAは修正PLを参照 |
| `BSハイライト` | 直近期末の資産｜負債・純資産の左右2列 | 財務ハイライト（B/S）。範囲外に4期推移と借入先別残高 |
| `売上構成`（事業別・商品別等） | 区分／金額／構成比／内容。切り口は案件ごとに選ぶ | 事業別売上高・収益源 |
| `取引先` / `仕入先` | 3期×（金額・構成比）、業種等、備考 | 主要得意先・仕入先の3期推移 |
| `外注先` | 同上 | 商流ページ（仕入先と実態が同じなら統合してよい） |
| `株主` / `取締役` | 鳥塚の列構成（役員報酬・代表者との関係・業務範囲） | 株主及び役員。範囲外に役員報酬3期推移（評価書用） |
| `従業員` | 部署→役職→勤続年数順。氏名は載せない | 従業員一覧／組織図（№で対応） |
| `拠点(本社等)` / `不動産(賃借) ` | 拠点／所在地／所有区分／面積／主な建物／用途 | 拠点概要 |
| `不動産概況` / `不動産詳細` | 拠点別の土地・建物の所有区分と時価、筆・棟別明細 | 不動産概況・不動産詳細（保有なしならページごと落とす） |
| `不動産(所有)` | 課税明細・内訳書の転記元データ（貼付範囲ではない） | — |
| `設備` | 建物内訳＋科目別簿価（台帳受領後は台帳一覧） | 保有設備一覧 |
| `月別売上` | 12か月＋月平均比 | 季節性（業種による） |
| `貸借対照表` / `損益計算書` / `販管費` | 財務入力→を3期・概要書の体裁で並べ直した範囲 | 財務情報詳細 |
| `沿革` / `その他補足` | 年月／内容、項目／内容 | Appendix |
| `その他` | 要確認事項・ネクストステップ・Web調査メモの置き場 | （ヒアリング項目一覧の原本） |
| `スケジュール(横/縦)` `グラフ` `表` | 補助的な作図用 | |

`その他`シートは軽視されがちだが、**要確認事項の唯一の集約先**として機能する。ここに残した論点がそのままヒアリング項目一覧と、評価書・概要書の「要確認」注記になる。

## 数式まわりの注意

- LibreOffice Calcで評価できない関数は使わない（`XLOOKUP` `FILTER` `UNIQUE` `SORT` 等）。`INDEX`/`MATCH`で代替する
- 割り算は `IFERROR(...)` で包む。進行期の列が空のまま `#DIV/0!` を撒き散らすことが多い
- **行を削除・挿入すると他シートの参照が壊れる。**特にPLハイライトの調整項目行は要注意。行構成を変えたら必ず `recalc.py` を通して `#REF!` が出ていないか確認する
- openpyxlで保存したファイルはキャッシュ値を持たないため、`recalc.py`（LibreOffice経由）を通すまで `data_only=True` では全てNoneになる
- ただしLibreOfficeで保存し直したファイルは游ゴシックが代替フォントに置換され、貼付範囲の書式が崩れる。再計算したファイルからは値だけ取り、`scripts/inject_cache.py` で元ファイルに書き戻す

# 案件マスターのシート構成と転記先

案件マスターは3つのセクションに分かれている。セクション見出しシート（`財務入力→` `VR→` `IM→`）は空で、区切りとしてのみ存在する。

## 共通ルール（`ルール`シート）

1. 文字は「游ゴシック」、数字は「Arial」。備考欄などの細かい文章は「游ゴシック Medium」
2. タイトル・合計欄は太字
3. **数字は円単位で入力する。表示は千円単位に設定済み**
4. 背景は紺・水色・グレー・白・青（パレット上部の色）。線は紺・白・青

## 財務入力→（決算書の転記）

| シート | 内容 | 備考 |
|---|---|---|
| `BS(借方)` | 資産の部。C〜E列＝過去3期、F列＝4期目、G列＝進行期TB | 63行に借貸一致の`EXACT()`チェックあり |
| `BS (貸方)` | 負債・純資産の部 | シート名の`BS`と`(貸方)`の間にスペースがある。参照時に注意 |
| `PL` | 損益計算書。2列1組（帳簿価額／売上高比）で1期 | 63〜64行に当期純利益の整合チェックあり |
| `CR` | 製造原価報告書。製造業以外は空欄のまま | |
| `SGA` | 販売費及び一般管理費。PLの販管費行がここを参照 | |

期のヘッダーは`BS(借方)!C4:G4`が原本で、他シートは全てここを参照している。ここだけ直せば全シートに伝播する。

## VR→（株式価値評価）

| シート | 内容 |
|---|---|
| `株式価値 ` | 3アプローチのレンジ集計（グラフ用）。自動計算のため触らない |
| `修正BS(借方)` / `修正BS(貸方) ` | 評価基準日の時価純資産。C列＝簿価、D列＝修正額、E列＝修正後 |
| `売掛・棚卸` `減価償却` `土地` `保険` `有価証券` `未払人件費・賞与` `退職金` `税効果` | 修正BSの明細。使わない科目はテンプレートのダミー値を消し「該当なし」と理由を書く |
| `分割後BS` | 会社分割案件で使用（標準テンプレートには無い。必要時に作成） |
| `ネットキャッシュ` | キャッシュライク／デットライクの集計。EV/EBITDA法が参照 |
| `修正PL` / `修正SGA` / `修正CR` | 正常収益力。3期分×（帳簿価額／修正額／修正後） |
| `年買法` | コストアプローチ。時価純資産＋営業権 |
| `EV EBITDAマルチプル` | マーケットアプローチ |
| `参照企業` | 類似上場会社。倍率は算定日時点の株価で更新する前提 |

## IM→（企業概要書）

| シート | 概要書の対応ページ |
|---|---|
| `会社概要` | 基本情報 |
| `PLハイライト` | 財務ハイライト（P/L）。調整項目と調整後EBITDAもここ |
| `BSハイライト` | 財務ハイライト（B/S） |
| `取引先` | 主要販売先別売上高 |
| `仕入先` | 仕入先別取引高 |
| `外注先` | 商流ページ（仕入先と実態が同じなら統合してよい） |
| `株主` / `取締役` | 株主及び役員 |
| `従業員` | 従業員／組織図 |
| `拠点(本社等)` | 拠点概要（本社）。登記上の本店所在地と実際の事務所の所在地が違うことがあるので両方書く |
| `不動産(賃借) ` | 賃貸借の状況。**当社が借りている物件（借地・借家）と、当社が貸している物件（貸地・貸家）を分けて**記載。契約書から貸主／借主・賃料・期間・更新・用途制限・譲渡転貸禁止を転記。テンプレートのダミー（西宮市◯◯店等）は必ず消す |
| `不動産(所有)` / `不動産(所有) ②` | 不動産詳細。法人・代表者個人の物件明細。G列「所有（建築）年月・事由」は謄本の甲区から「令和1年9月22日 相続（2019年）｜登記 令和2年10月8日」の形で埋める（保有なしなら概要書からページごと落としてよい） |
| `不動産(登記･担保)` | 【追加シート】謄本・課税明細・共同担保目録の突合結果。担保グループ／物件明細（所有区分・拠点・事業用区分・担保番号）／集計／要確認事項。不動産概況・担保・明細ページの原本 |
| `個人不動産_買取試算` | 【追加シート】代表者個人所有地の買取価格（時価・固評・下限・掛け目・一部賃貸借）と売主手取りの概算。作り方は `real-estate.md` §7 |
| `設備` | 保有設備一覧 |
| `その他` | 要確認事項・ネクストステップ・Web調査メモの置き場 |
| `スケジュール(横/縦)` `グラフ` `表` | 補助的な作図用 |

`その他`シートは軽視されがちだが、**要確認事項の唯一の集約先**として機能する。ここに残した論点がそのままヒアリング項目一覧と、評価書・概要書の「要確認」注記になる。

## グラフ入りのマスターを編集するとき

**openpyxl で保存しない。**グラフのスタイル・配色パーツが失われ、グラフの見た目が崩れる（7つのグラフが全部崩れた実例あり）。`scripts/xlsx_xml.py` の `Book` で zip 内の XML を直接書き換える（セル書き換え・行追加・シート追加）。

- 文字列は inlineStr で書く（sharedStrings を触らない）。書式は既存セルの `s=` を引き継ぐ
- 新シートの rId は `workbook.xml.rels` 全体から採番する（theme・styles と衝突させない）
- 数式を変えたら `calcChain.xml` とその参照を消し、`fullCalcOnLoad="1"` を付ける
- 保存後に確認すること：グラフの数が変わっていない／rId が重複していない／openpyxl で読める／LibreOffice で再計算して `#REF!` などのエラーが出ない
- LibreOffice で再保存したファイルは、別のシートのフィルター定義のせいで openpyxl が読めないことがある。数式を検算したいときは、そのシートだけを抜き出したコピーで再計算する

## 数式まわりの注意

- LibreOffice Calcで評価できない関数は使わない（`XLOOKUP` `FILTER` `UNIQUE` `SORT` 等）。`INDEX`/`MATCH`で代替する
- 割り算は `IFERROR(...)` で包む。進行期の列が空のまま `#DIV/0!` を撒き散らすことが多い
- **行を削除・挿入すると他シートの参照が壊れる。**特にPLハイライトの調整項目行は要注意。行構成を変えたら必ず `recalc.py` を通して `#REF!` が出ていないか確認する
- openpyxlで保存したファイルはキャッシュ値を持たないため、`recalc.py`（LibreOffice経由）を通すまで `data_only=True` では全てNoneになる

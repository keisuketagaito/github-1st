# 企業概要書の作成フォーマット（貼付範囲方式・鳥塚準拠デザイン）

概要書は「**案件マスターを埋める → 貼付範囲をコピーして貼る → 業種に合わせて構成を変える**」の順で作る。
鳥塚案件の概要書（64ページ、M&A承継機構フォーマット）がこの流れと見た目の基準である。
初回実装は鶴岡中央青果（`株式会社鶴岡中央青果/案件マスター_鶴岡中央青果_261014.xlsx`／`企業概要書_鶴岡中央青果_261014.pptx`）。
迷ったらこの2ファイルを開いて同じ形にする。

## 1. 作成フロー

| # | 作業 | 成果物・道具 |
|---|---|---|
| 1 | 受領資料を財務入力→（BS・PL・SGA）と転記元データ（不動産・従業員等）へ転記 | 案件マスター |
| 2 | VR→で修正PL・修正BSを作る（調整後EBITDAの原本） | 案件マスター |
| 3 | **IM→の各シートに「貼付範囲」を組む**。行・列・書式は概要書の表と同じ。数値は数式で財務シートを参照 | `scripts/master_im_style.py` |
| 4 | 再計算してキャッシュ値を書き戻す（書式を壊さないため） | LibreOffice＋`scripts/inject_cache.py` |
| 5 | 業種に合わせてページ構成を決め、テンプレートのページを削除・転用・追加する（§5） | テンプレートpptx |
| 6 | 各ページに貼付範囲を貼る。パワポ上で数字は打たない | `scripts/im_paste.py` の `paste_range` |
| 7 | リード文・Commentをテンプレートの既存の枠に書く（§3の書式） | `set_lead` / `fill_comment` / `comment` |
| 8 | 検証：数式エラー0・チェックTRUE、validate、全ページをレンダリングして重なり確認 | SKILL.md Step 6 |

**数字の修正はマスターで行い、範囲を貼り直す。**パワポの表を手で直すと、次に貼り直した瞬間に消える。

## 2. 貼付範囲の決まり（案件マスター側）

- 各IMシートの**A2に赤字で「■ 貼付範囲 B4:F25 → 企業概要書『財務ハイライト（P/L）』」**と書く。ルールシートに全範囲の一覧を置く（`write_paste_index`）
- 範囲の先頭行に「(単位：千円)」を右寄せ9ptで入れる（範囲ごと貼れば単位も付いてくる）
- 列幅はインチで決める（`cw`）。**Excelの列幅＝パワポ上の列幅**になるよう換算済み
- 行高はptで決める。目安：本文19pt、比率行14pt、空行8pt、詳細表（BS/PL/販管費）11.6pt、従業員14.5pt
- 数値は円入力・千円表示（`KI`）。△表示、千円丸め、%はパワポ側でも表示形式どおりに文字化される
- 範囲の下に「参考（貼付範囲外）」欄を置き、リード文・Comment用の集計（3期平均、人数、平均年齢、比率）をそこで計算する。**リード文の数字もマスターから取る**
- **横に並べる2つの表を同じ行に置かない。**行高が共有され、片方の行が押し広げられる。Excelでは縦に離し、パワポで横に並べる
- 調整項目の理由など、Commentの原本になる文章は範囲の右隣（範囲外）に置く

## 3. デザイン仕様（パワポ側）

### 表（`paste_range` がマスターの書式をそのまま再現）

| 要素 | 仕様 |
|---|---|
| 見出し行 | 塗り紺 `0B3041`、白字、游ゴシック10pt、中央（会社概要は左寄せ太字） |
| 科目列 | 塗りグレー `E3E7E9`、游ゴシック10.5pt、黒 |
| 数値 | Arial（東アジア文字は游ゴシック Medium）10.5pt、右寄せ |
| 比率行（前期比・利益率） | 7pt斜体、右寄せ。科目列もグレーで右寄せ |
| 小計・調整項目合計・合計行 | 淡青 `E1F3FB` 太字。調整後EBITDAはグレー太字＋紺の上下罫線 |
| 罫線 | 縦は白（12700EMU）、横はグレー `A6A6A6` 細線、上罫線なし |
| セル余白 | 左右0.04インチ、上下0、上下中央揃え |
| 空セル | 文字なし（フォントを行高の6割に縮めて行を押し広げない） |

### リード文（字幕プレースホルダー）

- `set_lead`：サイズ・太字はレイアウト既定のまま、フォントだけ游ゴシック（latin・ea）を明示。テンプレートの `+mj-ea` のままにしない
- 2行（全角110字程度）以内。3行になると表と重なる。「何が書いてあるか」ではなく「だから何なのか」を書く

### Comment枠

- **テンプレートにある枠を使う。**独自の色付き箱や青い見出しは作らない
  - P/L：見出し枠「Comment」（id 8）＋本文（id 9）、【調整項目】枠（id 2）＋本文（id 10）
  - B/S：Comment（id 2＋7）、【時価修正】（id 6＋8）
  - 損益計算書・販管費：Comment（id 2＋6／id 2＋3）
  - 枠がないページ（基本情報の「本件のポイント」、拠点の状況、季節性など）は `comment()` でP/Lページの枠を複製して置く
- 本文の書式（`fill_comment`）：`≪見出し≫` は10pt太字黒、`・本文` は9pt黒、空文字は空行、段落後3pt。すべて游ゴシック
- 【調整項目】【時価修正】は見出し9pt・本文8.5pt・段落後1ptまで詰めてよい。最後に `✓ 調整後EBITDA…` `✓ 簿価純資産…→時価純資産…` で結論を置く
- 見出しと本文を同じ行に書かない（`≪土地≫・…` は見出し扱いで全部太字になる）

### 注記・ラベル帯・図形

- 表の下の注記は `note()`：黒、游ゴシック8pt。**位置は `range_height()` で表の高さから計算する**（固定位置にしない）。折り返しで表が伸びるので0.1〜0.15インチ空ける
- 「株主」「役員」「本社」「所有」「賃借」等のラベル帯はテンプレートの図形を `place()` で動かして使う
- 組織図はテンプレートの箱（部門＝id 31、メンバー＝id 32、取締役会＝id 72、代表＝id 30、人員構成＝id 82）を `clone()`／`set_box()` で増やす。線はグレー `808080` 0.75pt
- 商流図・事業フローなど図形で描くページは、見出し紺 `0B3041`、ボックス淡青 `E1F3FB`／白＋グレー枠、本文黒。青文字の見出しは使わない
- マスターの宛先透かし（「株式会社●●御中」）は `remove_watermark()` で外す。黄色の作成ガイド帯は `remove_yellow()`、画像実体のない極小ピクチャは `remove_null_pics()` で除去

```python
import sys; sys.path.insert(0, '.claude/skills/ma-deal-docs/scripts')
from im_paste import *
from openpyxl import load_workbook
from pptx import Presentation

wb = load_workbook('案件マスター.xlsx', data_only=True)     # 書式も値も読める
prs = Presentation('概要書テンプレート.pptx')
S = list(prs.slides)
remove_yellow(prs); remove_null_pics(prs); remove_watermark(prs)

s = S[5]                                                     # 財務ハイライト（P/L）
set_lead(s, f'…調整後EBITDAは3期平均{…}千円。')
remove(s, 18)                                                # テンプレートの見本画像
ref = paste_ref(wb, 'PLハイライト')                           # A2の表記から 'PLハイライト!B4:F25'
paste_range(s, wb, ref, 0.34, 1.6, 6.62)
note(s, 0.34, 1.6 + range_height(wb, ref) + 0.12, 6.62, ['※EBITDA＝営業利益＋減価償却費。…'])
place(shape_by_id(s, 8), 7.06, 1.6, 4.29, 3.95); place(shape_by_id(s, 9), 7.06, 2.18, 4.28, 3.3)
fill_comment(shape_by_id(s, 9), ['≪売上高≫', '・…', '≪売上総利益≫', '・…'])
```

## 5. 業種に合わせたページ構成

テンプレート（36ページ）を出発点に、**使わないページは削除、足りないページは同じ体裁のページを転用・複製**する。
空欄だらけのページを残さない。

| 判断 | 例 |
|---|---|
| 削除 | 製造業でなければ「製造原価報告書」。代表者経歴・今期予算・事業計画が未受領なら削除（受領後に追加）。会社分割がなければスキーム関連3ページ |
| 転用 | 「事業計画」→ESの「事業概要」（基本情報の直後へ移動）。「拠点概要（工場）」→「不動産概況」。「外注費」→「月別売上（季節性）」 |
| 追加 | 業種の核になる仕組みを1〜数ページ：商流（全業種）、生産サイクル・品種比較（養殖・農業）、収益源（市場・手数料ビジネス）、制作実績（受託制作）、価格形成の仕組み（相場商品） |
| 分割 | 不動産・設備が多い場合は「法人所有①土地／②建物／社長所有」のようにページを分ける（鳥塚：不動産6ページ、設備14ページ） |

業種別の追加ページ例：

| 業種 | 追加・強化するページ |
|---|---|
| 卸売市場・卸売業（鶴岡中央青果） | 事業の仕組みと収益源（買付／受託手数料／センター費）、月別売上（季節性）、不動産概況 |
| 養殖・一次産業（鳥塚） | 生産サイクル、品種別の特性比較、商品・用途別の顧客構成、価格形成の仕組み、拠点（養魚場）ごとの写真 |
| 受託制作・ライセンス | 制作実績（権利元の系統別）、制作フロー、事業ライン別の商流 |
| 製造業 | 製造原価報告書、工場・設備（台帳ベース）、主要製品と生産能力 |

## 6. 落とし穴

- **LibreOfficeで保存したマスターをそのまま使わない**：游ゴシックが代替フォントに置換され、貼付範囲の書式が崩れる。必ず `inject_cache.py` で元ファイルに値を書き戻す
- **openpyxlで保存しただけのマスターは値を持たない**：`data_only=True` で None になる。再計算を飛ばさない
- 表の行は文字の折り返しで伸びる。注記は `range_height()`＋余白で置き、レンダリングで確認する。伸びる列（業種等・備考）は行高を22pt程度にしておく
- 2段見出し・縦結合はExcel側で `merge_cells` しておけば、そのままパワポでも結合される
- テンプレートのComment本文枠は `spAutoFit`。文章が多いと枠から下にはみ出すので、本文は1ブロック2行程度に抑える
- 比率の分母が0・空の期は `IFERROR(…,"")` で空欄にする（`#DIV/0!` を貼らない）

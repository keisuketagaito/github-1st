# 実例：鶴岡中央青果 企業概要書261027（公式マスター方式の完成形）

依頼者から「めちゃ良い感じ」と評価された版。**次の案件の概要書はこの作り方・この水準以上で作る。**
成果物は `株式会社鶴岡中央青果/企業概要書_鶴岡中央青果_261027.pptx`（36頁）と `案件マスター_鶴岡中央青果_261027.xlsx`。

## 流れ（スクリプトの対応）

| # | 作業 | スクリプト | 要点 |
|---|---|---|---|
| 1 | 追加資料を読む | `parse_bunrui2.py`（分類別売上の大分類計）、`parse_chingin.py`（賃金台帳） | Drive の大きいPDFは `read_file_content` の結果ファイルから本文を抜いて集計 |
| 2 | 公式マスターを埋める | `build_master.py` | 依頼者記入途中の公式マスター（`up5/b.xlsx`）を起点に、財務入力（3期＋進行期試算表）・VR→・IM→を全部埋める。行ずれ・テンプレート不具合も直す |
| 3 | 再計算して値を書き戻す | `soffice --convert-to xlsx` → `scripts/inject_cache.py` | 游ゴシックが崩れないよう、書式は元ファイル・値は再計算ファイルから |
| 4 | 検算 | `verify.py` | 数式エラー0・チェックセルTRUE・調整後EBITDA／時価純資産／年買法が前版と一致 |
| 5 | 概要書を組む | `build_im.py` | 表はすべて `paste_range` でマスターの貼付範囲を貼る。リード文・Commentの数字もマスターから読む |
| 6 | 描画して直す | `scripts/render_check.py` | 全頁を一覧画像で確認→折返し・重なりを直す、を3〜4周 |
| 7 | 検査して納品 | `validate.py --original`、`scripts/check_confidential.py` | 社内限の語0件を確認。PDFも出力 |

`build_im.py` のベースは前版の概要書（261019）。新規案件では `im_builder.open_template()` でテンプレートを複製し、
`keep_slides` / `duplicate_slide` で頁構成を作ってから、同じ要領で貼る。

## 描画チェックで実際に出た不具合と直し方（次回は最初から避ける）

| 症状 | 原因 | 直し方 |
|---|---|---|
| P/Lの表で数値列がすべて空 | テンプレートの列幅定義が C:G で1つにまとまっており、1期目（C列）を非表示にしたらC〜Gが全部消えた | `ungroup_cols()` で列ごとに分解してから `hide_cols()` |
| 株主・役員の表がスライド上端にずれて描画 | 2段見出しの2段目が全列とも縦結合の続き | 2段目の行（4行目）を非表示に |
| 得意先・仕入先の表が注記と重なる | 取引内容・所在地・業種が折り返して行が伸びた | 列幅を広げ、文言を短く（「青果卸売業（推察）」→「青果卸売業」＋注記で推察を明示）、fscale 0.72 |
| 損益計算書・販管費がフッターに掛かる | 期の見出しが狭い1列に入り3〜4行に折返し | 期見出しを2列結合（`E3:F3`等）、科目列を広げる、fscale 0.62 |
| 年齢が「63_)」と表示 | 表示形式の `_)` を文字化していた | `fmt_value` で `_x`・`*x` を除去（修正済み） |
| 従業員の雇用形態「パートタイム労働者」で行が伸びる | 文字列が長い | マスター側で「パート」に統一 |
| 平均年齢が組織図（50.9）と従業員一覧（51.0）で不一致 | テンプレートの `÷365` の年齢計算 | `DATEDIF(…,"Y")` に置換し、組織図の箱もマスター値で更新 |
| ドーナツグラフのラベルが重なる | LibreOfficeのラベル配置 | 円グラフ＋凡例に構成比を入れ、データラベルは出さない |

## 依頼者に確認・報告した論点（概要書以外で効いたもの）

- 依頼者記入のSGAの1期分が1行ずれていた（合計は合うので検算セルでは見つからない）→ 科目ごとに前期と比較
- 進行期の新規借入（＋165百万円）、主要販売先の依存度、社内勘定（KK・パッケージ）の性質
- Webの写真はネットワーク許可がないと取得できない。Driveのフォルダに別案件の資料が混在していた

# 鶴岡中央青果 株式価値評価書261116（マスター貼付型・鳥塚形式・24頁）

依頼者に「全然ダメ」と差し戻された261019版（要約表を手で組んだ37頁）を、鳥塚案件の評価書と同じ作り方で
作り直した実例。**表はすべて案件マスターのシートを丸ごと貼っている。**

## 手順
1. `recalc.sh`：マスターをビルド → LibreOffice で再計算 → **`scripts/vr_prep.py`**（修正BS・修正PL・修正SGAの空行・
   1期目列・TB列を非表示）→ `inject_cache.py`
2. マスター側で、ネットキャッシュの使う科目を上に詰め、土地・有価証券・税効果の空行を非表示（`build_master.py`）
3. `build_vr.py <マスター.xlsx> <出力.pptx>`：テンプレート複製 → 修正内容詳細①土地・②有価証券/税効果を挿入 →
   各頁に `vr_paste`（範囲は `vr_builder.PASTE_MAP`）→ Comment・黄色・P7レンジ図

## 頁構成（24頁）
表紙／はじめに／注意点／目次／Section1／アプローチ選定／試算結果／Section2／過去BS／BS補足［資産］／
修正内容詳細①［土地］／②［投資有価証券・税効果］／修正BS［資産］／BS補足［負債・純資産］／修正BS［負債・純資産］／
ネットキャッシュ／Section2(P/L)／過去PL／販管費の修正／修正PL／Section3／年買法／EV/EBITDAマルチプル／裏表紙

## 描画確認で出た不具合と対策
| 不具合 | 原因 | 対策 |
|---|---|---|
| 修正PL・修正SGAが科目列しか貼られない | 列幅定義が C:Q でまとまっており、C列の非表示で全列が消えた | `vr_prep` で列定義を分解してから隠す |
| P7レンジ図が−100〜150のような目盛になる | 千円に割った値を入れ、軸の `#,##0,` でさらに1/1000 | 円のまま入れる（`set_range_chart`） |
| Comment本文が黄色になる | テンプレート見本文の黄色マーカーが残る | `vr_text()` で `a:highlight` を外す |
| 横長Commentがはみ出す | 3枠それぞれ幅約2.6インチ | 1枠2行に収める |
| ネットキャッシュ表に空の科目が並ぶ | 公式マスターの科目順のまま | 使う科目を上に詰め、残りは非表示 |

## 買手向け評価書（261117・20頁）：`build_vr_buyer.py`
マスターの `買手評価` シート（`build_master.py` の「買手向け評価」ブロック）を貼る。基準日2026/9末試算表、

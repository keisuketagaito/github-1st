# 修正PL・修正SGA（正常収益力）の作り方

正常収益力は**営業利益ベース**で算定する。マスターの `修正SGA` / `修正PL` シートは
期ごとに「帳簿価額／修正額／修正後」の3列ブロックが並ぶ。

> **列の並びに注意。** 3列ブロックは C/F/I/L/O から始まり、それぞれ第2期／第3期／第4期／第5期／進行期に対応する。
> 未受領期のブロックを消すつもりで評価基準期のブロックを消してしまう事故が起きやすい。
> 消す前に必ず3行目のヘッダー（`='BS(借方)'!C4` 等）で対応する期を確認する。

修正SGAの修正額合計（39行目）は修正PLの販管費行の修正額として参照させる。
テンプレートでは未接続なので、`修正PL!G19 = 修正SGA!G39` のように自分で繋ぐ必要がある。

## 正常収益力算定の4つの柱

```
■ B/Sの修正事項は原則としてP/Lの修正事項
　　□ 減価償却の過不足額　□ 退職給付引当金　□ 貸倒引当金

■ 中小企業（オーナー企業）特有の事項
　　□ 役員報酬　□ 役員保険　□ オーナーの個人的な経費（M&A後には生じないと想定される経費）

■ 非経常的・臨時的な損益の控除または修正
　　⇒ 正常収益力の算定という目的から非経常的・臨時的な項目は排除する

■ 支払利息及び手形売却損の控除
　　⇒ 正常収益は債権者への分配前（資金調達コスト控除前）である必要があるため
```

## 科目別の調整

### 役員報酬
**M&A後の役員体制になった場合の正常収益を算出する。**
役員への報酬の多寡による業績変動要因を排除するため、M&A時に退任予定の役員報酬を控除し、
新体制の標準役員報酬に置き換える。

```
例：社長・常務が退任 → 退任分の役員報酬を戻し入れ（＋）
　　新任の標準役員報酬 社長18,000千円・常務12,000千円を控除（△）
```

後任が現行と同水準の報酬を受ける前提を置く場合、戻し入れと控除が同額になり
**差引の修正額はゼロ**になる。その場合も「なぜゼロなのか」を調整事由に明記する
（何も調整していないのか、両建てで相殺されているのかが読み手に分からないため）。

社会保険料も概算料率15%で連動調整する。

### 役員保険料・オーナー個人に帰属する経費
譲渡後に発生しない費用は戻し入れる。生命保険料のうち事業関連性の低いもの、
非事業用車両のリース料、接待交際費のうち適正水準を超える部分など。

接待交際費は「適正水準◯◯千円との差額」という形で調整額の根拠を示す。

### 地代家賃（買取予定不動産がある場合）
オーナー個人から賃借している不動産をM&Aと同時に対象会社で買取る予定であれば、
**各期の地代家賃を控除する**（賃料がかからなくなるため）。

同時に、買取後に発生する費用を加算する：
- **減価償却費**：買取価額 × 償却率（例：建物84,000千円 × 0.022 ＝ 1,848千円）
- **不動産関連費用**：固定資産税・管理費等の諸費用

### 減価償却費
修正BSで算出した**償却不足額を各期の減価償却費として追加計上する。**
買取予定建物がある場合は上記の償却費も加算する。

### 貸倒引当金繰入
**直接評価の観点から一旦控除する。**修正BSで貸倒引当金を全額戻入しているため、
繰入額もPL上から除く。

### 退職金・退職給付費用
既存の退職金計上額は一旦控除し、**要支給額の増加分を各期の退職給付費用として計上し直す。**

### 支払利息・手形売却損
**控除する。**資金の調達方法から独立した会社財産の収益獲得力を評価するため。
営業利益ベースで見る場合はそもそも営業外なので含まれないが、
税引前純利益ベースで超過利益法を使う場合は明示的に控除が必要。

### 非経常的・臨時的な損益
全額控除する。代表例：

- 保険解約益、債務免除益
- 有価証券売却損益、固定資産売却損益、固定資産除却損
- 貸倒引当金戻入益
- 補助金・助成金（継続性がない場合）

**逆に、経常的に発生するものは正常収益力に加算する。**
例：オーナー関連会社向けの賃借料、社員割引に伴う雑収入。
「雑収入」を一括で除外せず、明細を見て経常／非経常を分ける。

### 寄付金
譲渡後に発生しない費用とみなし控除する。

## 営業外収益を営業利益ベースに取り込むときの注意

経常的な雑収入を正常収益力に含める場合、**修正PL上は営業外収益に計上されるため
修正後営業利益には入らない。**この差を放置すると、修正PLの修正後営業利益と
年買法シートの「修正後営業利益」が食い違う。

対処：修正PLに「正常収益力への橋渡し」ブロックを設ける。

```
修正後営業利益（修正PL）            △323
　経常的雑収入（社員割引）の加算      655
正常収益力（修正後営業利益ベース）    332   ← 年買法・マルチプル法はこれを使う
```

この加算後の金額が**企業概要書の調整項目合計と一致する**ことを必ず検算する。

## 構造的な費用の営業費用化（判断が要る論点）

特別損失に計上されている費用が**3期連続で発生し増加傾向にある場合**、
それは非経常ではなく事業に構造的に内在する費用である。

例：版権グッズ事業の棚卸資産廃棄損は、他勘定振替高を戻し入れたうえで
営業費用として認識するのが実態に即する。

**「特別損失に載っているから除外」と機械的に処理しない。**
発生の継続性と事業構造との関係で判断し、判断根拠をコメントに残す。

単発の事象であれば非経常として扱うが、その場合も
「なぜ単発と判断したか」「同種の事象が再発するリスク」を要確認事項に残す。

## 概要書との整合

**概要書の調整後EBITDAと評価書の正常収益力は同じ調整方針で算定する。**
方針を変えるなら両方変える。

```
修正後EBITDA（評価書）＝ 修正後営業利益 ＋ 減価償却費
調整後EBITDA（概要書）＝ 営業利益 ＋ 減価償却費 ＋ 調整項目合計
```

この2つが3期とも一致することを必ず検算する。一致しなければどちらかの調整が漏れている。

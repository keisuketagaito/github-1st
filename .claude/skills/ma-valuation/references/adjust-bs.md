# 修正BS（時価純資産）の作り方

評価基準日の簿価に修正額を加減する。マスターの `修正BS(借方)` / `修正BS (貸方) ` シートは
C列＝帳簿価額（BSシートの該当期を参照）、D列＝修正額、E列＝修正後。
**D列に修正額を入れるだけで修正後と純資産の評価修正額が自動で流れる**構造になっている。

修正額を入れたら必ず **借方の修正後合計 ＝ 貸方の修正後合計** を確認する
（`修正BS(貸方) !C55` のチェックセルが TRUE になること）。

## 資産の部

### 現金・預金
金融機関の残高証明との一致を確認できれば帳簿価額。確認できない場合はその旨を残す。

### 受取手形
**受取手形割引高が直接控除されている場合はオンバランス処理する。**
　受取手形 ×× ／ 割引手形 ××
割引手形は負債側に計上されるため、時価純資産そのものは変わらないが、
総資産（＝超過利益法の期待利益の計算基礎）が変わる。

### 売掛金
補助残高一覧表と3期比較で個別に判断する。**3期同額の残高があれば必ず理由を確認する。**

| 状況 | 取扱い |
|---|---|
| 民事再生手続の申立 | 回収不能と判断し全額減額 |
| 手形交換所による取引停止処分 | 回収不能と判断し全額減額 |
| 経営状態が悪く半年以上回収できていない | 債権金額の一定割合（例：50%）を評価額とする |
| 通常の売掛金 | 帳簿価額 |

### 貸倒引当金
**全額戻入（＝プラス修正）。** 売掛債権を個別に回収可能性判断しており、
かつ経常的に貸倒れが発生している事実がないことから、引当金の計上は不要と判断する。
評価上は個別債権を各々評価しているため二重の控除になる。

### 棚卸資産
滞留・陳腐化を減額する。例：商品1,250千円のうち30%が賞味期限切れ
→ 1,250 × 30% ＝ 375千円を不良在庫として減額。

外部倉庫・他社保管分は実在性の確認が取れなければ「要確認」として残す。

### 減価償却資産（建物・機械・車両・工具器具備品）
**減価償却資産台帳から適正償却額を再計算する。**償却不足額があれば帳簿価額から減額する。
逆に過大償却（増額修正）のケースもある。

台帳が未受領で再計算できない場合は簿価評価とし、その旨を残す。

### 土地
簡便的に**路線価もしくは倍率方式**で評価する。土地の評価額が争点となるケースでは不動産鑑定を検討。

| 方式 | 算式 |
|---|---|
| 路線価方式 | 路線価 × 地積（㎡） |
| 路線価方式（実務の割戻し） | 路線価 ÷ 0.7 ※公示地価水準に割り戻す場合。÷0.8とする流儀もある |
| 倍率方式 | 固定資産税評価額 × 倍率 |

必要な資料：場所に関する情報／路線価図／固定資産税課税明細書（固定資産税評価証明書）／不動産登記簿謄本。
路線価図は国税庁HP「路線価図・評価倍率表」から該当都道府県を辿る。

複数筆ある場合は**筆ごとの一覧表**（所在地・地積・帳簿価額・評価差額・時価評価額・調整事由）を
評価書の「修正内容詳細［土地］」ページに載せる。

### 電話加入権
**換金価値なしとしてゼロ評価。** NTTの加入電話回線を契約するための権利（施設設置負担金）であり、
評価上は資産性を認めない。

### 有価証券・投資有価証券
**評価実施日（基準日ではない）の終値・基準価格**で評価する。
例：1株1,004円 × 保有数量12,000株 ＝ 12,048千円。
必要な資料：有価証券内訳書（数量がわかる資料）／証券会社の残高証明書／時価のわかる資料。

非上場株式は簿価評価とし、発行会社の純資産や配当実績が把握できる場合のみ個別に検討する。

### 敷金・保証金
賃貸借契約書を確認し、**契約解除時の返還金額**で評価する。
償却条項（敷引き）がある場合は返還額まで評価減する。全額返還であることを確認できれば簿価。

### 保険積立金
**解約返戻金額**で評価する。保険会社の「解約返戻金のご案内」で基準日時点の額を確認する。

### 営業権（B/S計上分）
**全額評価減する。** 年買法で営業権を別途算定するため、B/S計上分を残すと二重計上になる。
換金価値も認められない。

### 仮払金・立替金
回収を前提とした支出でなければ資産性を認めず全額評価減する。

## 負債の部

### 買掛金・預り金・未払法人税等・未払消費税等
適正に計上されていることを確認できれば帳簿価額。
預り金は給与に係る源泉税・社会保険料等であり給与台帳で確認する。
未払法人税等・未払消費税等は申告書で確定納付額を確認する。

### 未払給与
**賃金規程の締日から基準日までの経過分を追加計上する。**

```
計算例：締日20日／翌月末支払
　2020年4月末支払い給与 18,600千円 × 11日（3/21〜3/31）÷ 31日 ＝ 6,600千円
```

### 賞与引当金
**支給対象期間のうち評価基準日までに経過した分を引当計上し、社会保険料を概算料率15%で加算する。**

```
計算例：支給対象期間2019/12〜2020/5（6か月）、支給見込22,500千円、基準日2020/3
　22,500千円 × 4か月（当期の労務期間2019/12〜2020/3）÷ 6か月 ＝ 15,000千円
　社会保険料：15,000千円 × 15% ＝ 2,250千円
　引当額合計：17,250千円
```

### 退職給付引当金
退職金規程に基づき、**期末時点の退職金要支給額 － 外部積立額（中退共等）** を引当計上する。

```
計算例：基本給195千円 × 支給倍率11 × 退職理由率0.8 ＝ 1,716千円
```

**原則は自己都合退職**で算定する。対象従業員が定年間際などの場合のみ会社都合で算定する。

### 役員退職慰労引当金
役員退職慰労金規程に基づき計上する。

```
計算例：最終月額報酬2,800千円 × 在任年数32年 × 役位別倍率3.0 ＝ 268,800千円
```

**論点として押さえておくこと：**役員退職慰労金は株式価値から減算される関係にある。
買手は対象会社に現預金が多ければ可能な限り退職金で出したい（特別損失で節税できる）が、
売手は退職金を多く出すと手取額が悪化する（退職金の税 vs 株式譲渡益の税）。
評価書には「株価の一部を退職金や配当として受け取る事を希望される場合、
当該金額は株価から減算されることが一般的です」と注意点ページに明記する。

### 資産除去債務
店舗内装等の原状回復義務。中小企業会計要領では計上不要だが実質的な負債であり、
撤退店舗がある案件では原状回復費用・違約金の見積を確認する。
未確認であれば未計上とし、追加調整の可能性として明記する。

## 税効果

実効税率 **34%**。修正額が僅少な場合は修正BS上で認識せず、年買法シートの時価純資産算定で
一括考慮してよい（その旨を注記する）。

**繰越欠損金を有し課税所得の見込みが立たない会社では、繰延税金資産の回収可能性を認めず
税効果をゼロとする**のが保守的で正しい。その場合は「回収可能性が認められる場合は
評価差額の34%相当だけ時価純資産が上振れする余地がある」と上振れ余地を併記する。

## 評価できなかった科目の扱い

資料が未受領で評価できない科目は**簿価評価とし、その理由を明細シートと評価書の両方に残す。**

不動産を保有しない案件では、評価書の「修正内容詳細［土地］」ページを
**「評価科目別の検討結果」**に差し替える。科目ごとに帳簿価額・評価差額・評価額・調整事由を
一覧化すると、評価しなかった科目とその理由も同じ表で示せる。

さらに「評価の前提と追加調整の可能性」ページで、各論点に**影響の方向（＋＝上振れ要因／
△＝下振れ要因）**を付けて一覧化する。買手・売手双方にとってレンジの幅が読める。

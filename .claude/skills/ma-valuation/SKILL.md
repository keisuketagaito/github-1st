# 株式価値評価書 作成スキル

## このスキルの位置づけ

`ma-deal-docs` が案件資料全体（マスター起点の運用・概要書・会社分割・ヒアリング項目）を扱うのに対し、
本スキルは**評価パートだけを深掘り**する。評価書を作る／直すときは本スキルを主として読み、
マスターの操作・パワポ編集の作法は `ma-deal-docs` 側の
`references/master-sheets.md` と `references/pptx-ops.md` を併せて参照する。

**数値は案件マスター（Excel）が唯一のソース。**評価書のパワポに数字を直接打たない。
概要書の調整後EBITDAと評価書の正常収益力は**同じ調整方針で算定する**。片方だけ変えると、
買手が概要書の数字に倍率を掛けた瞬間に評価書のレンジと乖離する。

## 絶対に外さない4点

1. **非流動性ディスカウントは適用しない。**
   当社の評価書は `想定株式価値 ＝ EV ＋ ネットキャッシュ` である。
   EVに30%の非流動性ディスカウントを掛ける流儀もあるが、**当社フォーマットは掛けない。**
   掛けると株式価値が大きく下振れし、過去の評価書と整合しなくなる。

2. **ネットキャッシュは1つの数字に統一する。**
   「ネットキャッシュの算定」ページとマルチプル法ページで金額が食い違う事故が実際に起きている。
   必ずマスターの `ネットキャッシュ` シートを両方から参照させ、一致を検算する。

3. **評価できなかった科目は「簿価評価」と理由をセットで残す。**
   資料未受領で評価替えできないこと自体が重要な情報で、DDでの追加調整余地を示す。
   黙って簿価にするのではなく、評価書の「評価科目別の検討結果」と修正BSのコメント両方に理由を書く。

4. **B/Sの修正事項は原則としてP/Lの修正事項でもある。**
   減価償却の過不足、退職給付引当金、貸倒引当金は、修正BSで直したら修正PLでも直す。
   片側だけ直すと時価純資産と正常収益力の前提がずれる。

## 全体の流れ

1. 評価基準日を決める（下記）
2. 修正BS（時価純資産）を作る → `references/adjust-bs.md`
3. 修正PL・修正SGA（正常収益力）を作る → `references/adjust-pl.md`
4. 年買法とEV/EBITDAマルチプル法で株式価値を試算する → `references/methods.md`
5. 評価書23ページを組む → `references/report-structure.md`
6. 検証する（下記）

## 評価基準日の決め方

**原則は直近の決算日（本決算）。**進行期の試算表は決算整理（減価償却・棚卸評価・引当）が
未了であり、評価の基礎にはしない。

ただし以下は基準日を決算日に置いたまま反映する：

- **基準日後に判明した事実**は評価差額に織り込む。例：基準日時点の棚卸資産が数か月後に
  全額廃棄されていた場合、基準日時点で既に滞留・陳腐化していたと判断して評価減する。
- 進行期の状況は**参考ページ**として別建てにする。進行期の実績を年換算した感応度分析は、
  撤退・リストラの効果を示すのに有効だが、**評価結果ではない**ことを明記する。

損益計算書の参照期間は基準日を含む**直近3期**。評価書P.7の「試算の前提条件」に
評価対象・算定日・基準日・参照期間・目的を明記する。

## 採用するアプローチ

| アプローチ | 手法 | 採否 |
|---|---|---|
| コストアプローチ | 簿価純資産価額法／時価純資産価額法／**時価純資産＋営業権法（年買法）** | 年買法を採用 |
| マーケットアプローチ | 市場価額法／類似業種比準法／**類似会社比準法（EV/EBITDAマルチプル法）** | 採用 |
| インカムアプローチ | 収益還元法・DCF法 | 不採用（詳細な事業計画が存在せず算定困難） |
| インカムアプローチ | 配当還元法 | 不採用（少数株主視点の手法であり本件取引の性質に不適） |

採否理由の定型文は `references/report-structure.md` に置いてある。

## 検証

納品前に必ず通す。ここを飛ばすと数式エラーの残ったExcelや文字のはみ出したスライドが客先に出る。

```bash
python /mnt/skills/public/xlsx/scripts/recalc.py <案件マスター.xlsx> 300
python /mnt/skills/public/pptx/scripts/office/validate.py <評価書.pptx> --original <テンプレート.pptx>
soffice --headless --norestore -env:UserInstallation=file:///tmp/lo-qa --convert-to pdf --outdir . <評価書.pptx>
pdftoppm -jpeg -r 100 <評価書>.pdf page   # 全ページ目視
```

加えて**評価書固有の検算**を必ず行う：

- 修正BS：借方の修正後合計 ＝ 貸方の修正後合計
- 時価純資産 ＝ 簿価純資産 ＋ 評価差額 ＋ 税効果
- 修正後EBITDA（評価書）＝ 調整後EBITDA（概要書）※3期とも一致すること
- ネットキャッシュ：算定ページとマルチプル法ページで同額
- 基準営業利益 ＝ 修正後税考慮後営業利益の加重平均（直近50%・前期30%・前々期20%）
- 想定株式価値（年買法）＝ 時価純資産 ＋ 営業権
- 想定株式価値（マルチプル）＝ EV ＋ ネットキャッシュ

## テンプレートの使い方

`assets/valuation_report_template.pptx` を複製して中身を差し替える。
スライドサイズはA4横（11.69×8.27インチ）で、概要書テンプレートと同じ。
スライドの追加・削除・表の行数／列数の変更をする前に、必ず
`ma-deal-docs/references/pptx-ops.md` を読むこと。

**概要書テンプレートで評価書を代用しない。**レイアウトは似ているが、
評価書には「修正額／修正後」の3列構成、Comment枠付きの修正BSページ、
アプローチ選定の採否表など専用のレイアウトがあり、作り直すと体裁が揃わない。

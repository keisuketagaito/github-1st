## 掲載誌・書籍の写真について

受賞盾・ステッカー等の**店内掲示物を当社が撮影した写真**は、そのまま概要書に掲載できます
（`受賞01.jpg` `受賞02.jpg` の名前で置いてください。P.36 外部評価・メディア掲載に入れます）。

一方、**掲載誌の誌面そのもの・書籍のページを複写した画像**は、発行元の著作権が及びます。
買手候補へ配布する資料に載せる場合は発行元の許諾が必要になるため、
現状の概要書では誌名・掲載年・内容を文字情報として記載するにとどめています。
許諾が取れた場合、または表紙のみの小さなサムネイル掲載で進める場合はお知らせください。
P.36 のレイアウトを写真入りに切り替えます。

## 撮影のお願い（優先順）

1. 外観（茅葺き・里山）— 1枚で案件の性格が伝わる
2. 客席（囲炉裏・座敷）— 「体験価値」の裏付け
3. 粗挽き蕎麦の寄り — 「ホシ」が見えること
4. 物販商品の集合 — 通販・ふるさと納税の実在性
5. 受賞盾・ステッカー — 外部評価の裏付け

横位置（landscape）で、被写体を中央に寄せて撮影してください。
枠に合わせて中央トリミングするため、端に重要なものが写っていると切れます。

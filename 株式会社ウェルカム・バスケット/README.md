# 株式会社ウェルカム・バスケット（譲渡案件）

| ファイル | 内容 |
|---|---|
| `案件マスター_ウェルカム・バスケット.xlsx` | 公式マスター。財務入力（BS/PL/SGA/CR＝運送原価を区分集約）に2022〜2025年12月期を円単位で転記。IM→（会社概要・PL/BSハイライト・株主・取締役・拠点一覧・確認事項_開示・参考数値）。`その他` シートに要確認事項と社内限メモ（希望価格・競合状況等はここだけ） |
| `ノンネームシート_引越運送業_東海_261104.pptx/.pdf` | ノンネームシート（社名なし・買手へそのまま送れるファイル名） |
| `ティーザー_ウェルカム・バスケット_261104.pptx/.pdf` | ティーザー（実名。秘密保持契約締結後の提示を前提とした雛形に準拠） |
| `企業概要書_簡易版_ウェルカム・バスケット_261126.pptx/.pdf` | ティーザーと企業概要書の中間（13頁）。面談メモ（2026/11）を反映。表はマスターIM→の貼付範囲 |

## 再作成の手順

```bash
bash make_all.sh <ティーザー雛形.pptx>   # マスター → ノンネーム・ティーザー・企業概要書（簡易版）を一括で作り直す
```

`make_all.sh` の中身：`build_master.py`（財務入力・その他）→ `build_master_im.py`（IM→の貼付範囲）→ 再計算（`recalc.py`）→
`inject_cache.py` → `scrub_doc_props` → `build_nonname.py` → `build_teaser.py` → `build_im.py`。
雛形は依頼者から受領したもの（別案件の情報を含むためリポジトリには置かない）。

## 出典と書き分け

- 決算報告書（第23〜25期。2022年12月期は第23期の前期欄）：事実として記載
- 売主面談（2026年11月）：「売主説明」と明示。面談メモにはつばめグループ全体の話が混在しうるため、対象会社単体と確認できないもの（車両台数・進行期見込み・関係会社等）は「確認中」
- 外部調査報告書（TDB）：社外極秘のため直接引用しない。登記・公表情報・売主説明で裏付く事実のみ使用
- 内部限（希望株価・他社仲介・契約方針・焦げ付き先の事情・解雇経緯・税務対応）はマスター `その他` の社内確認事項だけに置く
- 時価純資産・含み損益（未収入金の回収不能見込み額、保険の解約返戻金額）は株式価値評価書で扱い、概要書には金額を出さない

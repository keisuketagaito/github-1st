# 鳥塚案件 企業概要書（261014版）の確認結果と改善点

越ヶ谷製氷冷蔵の資料作成にあたり、鳥塚案件の企業概要書（261014版、64頁）をテンプレートとして使い、同じ作成方法になっているかを確認した。
鳥塚案件の案件マスターは受領していないため、**概要書内のページ同士の突合**で確認している。鳥塚案件のファイル自体は修正していない。

## 1. 数値の抜粋・転記の誤り（優先度：高）

## 3. 作成方法の違い（会社概要・財務ハイライトの貼り方）

鳥塚案件では、主要得意先・仕入先・株主及び役員のページはExcelから図（WMF）で貼り付けている一方、**基本情報と財務ハイライト（P/L・B/S）の表はパワポ上で手入力**になっていた。手入力の表は、マスターを直しても反映されず、No.2・No.4のような食い違いの原因になる。

越ヶ谷製氷冷蔵では次のように改善した。

- 案件マスターに「**案件サマリー**」シートを新設し、会社概要と財務サマリーを1か所に集約（各シートを数式で参照）
- 概要書の「基本情報」「財務ハイライト（P/L）」「財務ハイライト（B/S）」の表は、案件サマリー・PLハイライト・BSハイライトの**計算済みの値をプログラムで読み込んで表として貼付**（手入力なし）
- P/Lハイライトの調整後EBITDAは、評価書の正常収益力と同じ「修正PL」シートを参照し、概要書と評価書の数字が必ず一致するようにした
- ノンネームシートも同じマスターの値から概数（約4.0億円等）を自動算出

マスターを修正したら、`_作成スクリプト/` の手順で概要書・評価書・ノンネームシートを再生成すれば、全資料の数字が揃う。

## 4. 情報管理上の注意（テンプレート流用時）

鳥塚案件の概要書をテンプレートとして複製すると、ファイルのプロパティ（docProps/app.xml）に**鳥塚案件のスライド見出し（鮎・琵琶湖等）と作成者名**が残る。越ヶ谷製氷冷蔵の3資料では生成時にこれを消去済み。今後テンプレートを手作業で複製する場合も、「ファイル＞情報＞問題のチェック＞ドキュメント検査」でプロパティを削除してから外部に出すこと。

### 再生成の手順

数値を直す場合は **必ず案件マスターを先に直す**。

```bash
python scripts/build_master.py                      # マスターを再生成
python /mnt/skills/public/xlsx/scripts/recalc.py 案件マスター_LUXAS株式会社_20260913.xlsx 300
python scripts/build_im.py                          # マスターを読んで概要書を再生成
```

`build_im.py` は `data_only=True` でマスターを読むため、**recalc を通してからでないと数式セルが空になる**。

## 他社仲介資料からの主な修正点

1. **稼働店舗数**：他社資料は「店舗6箇所」・2024年11月期の店舗別売上高を記載していたが、
   決算書「売上高等の事業所別内訳書」により2025年11月期時点の稼働店舗は**8店舗**であることを確認し、
   3期分の店舗別売上高を新たに整理した（`店舗別売上`シート／概要書P.12）。
2. **借入金一覧**：他社資料は2024年11月末残高（218,455千円）を掲載していたが、
   2025年11月末残高（191,858千円・9本）と期中支払利息へ差し替えた。
3. **車両**：BMW X7は他社資料では「進行期に売却済」とされていたが、
   減価償却内訳明細書では2025年11月期中に売却（売却損968千円）である。決算書ベースを正とした。
4. **進行期の反映**：他社資料は2025年11月期の決算書までで止まっていたため、
   進行期（2026年11月期）の5か月分を全面的に反映した（下記）。
5. **調整後EBITDA**：当社の調整方針で再算定（下記）。

### 進行期を読むうえでの留意点（いずれも概要書に注記済）

- 月次に**減価償却費が計上されていない**（2025年11月期の通期実績6,349千円）。通期ではその分だけ営業利益が減少する見込み。
- **法定福利費**が2025年12月・2026年1月にマイナス計上。5か月累計1,005千円は通期実績15,295千円に比して著しく低く、期中未計上分が下期に乗る可能性がある。
- 2026年3月に**棚卸資産廃棄損44,000千円**を計上。2025年11月期末の本社管理分32,000千円＋バックヤード管理分12,000千円に相当すると推察（仮説）。
- 差入保証金が2026年3月に2,024千円減少。うち2,000千円は撤退店舗の敷金返還と推察（仮説）。
- 長期借入金は月次では期首残高のまま据え置かれており、返済額は決算時に一括計上されていると推察。

## 正常収益力（調整後EBITDA）の考え方

M&A実行後に継続的に発生しない費用を戻し入れ、継続的に必要となる費用を控除する。
経営者人件費の前提は「代表者（淺野ゆう子氏）は引継完了後に退任し、現場責任者（淺野崇氏）が
役員に就任して現行と同水準（14,400千円）の役員報酬を受ける」とした。

| | 2023年11月期 | 2024年11月期 | 2025年11月期 |
|---|---|---|---|
| 営業利益 | 2,341 | 3,022 | △19,552 |
| 減価償却費 | 3,911 | 9,295 | 6,349 |
| 調整項目 合計 | 8,856 | 20,449 | 19,884 |
| **調整後EBITDA** | **15,108** | **32,766** | **6,681** |

過去3期平均 18,185千円／直近2期平均 19,724千円（単位：千円）

進行期は上記のとおり減価償却費が未計上のため、調整後EBITDAは算定していない。

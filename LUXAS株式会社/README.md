### 再生成の手順

数値を直す場合は **必ず案件マスターを先に直す**。

```bash
python scripts/build_master.py                      # マスターを再生成
python /mnt/skills/public/xlsx/scripts/recalc.py 案件マスター_LUXAS株式会社_20260923.xlsx 300
python scripts/build_im.py                          # マスターを読んで概要書を再生成
python /mnt/skills/public/pptx/scripts/office/validate.py 企業概要書_LUXAS株式会社_20260923.pptx --original <テンプレート.pptx>
```

`build_im.py` は `data_only=True` でマスターを読むため、**recalc を通してからでないと数式セルが空になる**。
レンダリング確認（文字はみ出し）は LibreOffice でPDF化して行う。LibreOffice は游ゴシックを
PowerPointより1〜2割広く描画するため、PDFで収まっていれば実機でも収まる。

### 進行期（2026年11月期・7か月）を読むうえでの留意点（いずれも概要書に注記済）

- 7か月累計：売上高279,153千円（前年同期比80.9%）、営業利益6,637千円。一方、2026年3月に
  棚卸資産廃棄損44,000千円を特別損失に計上したため**当期純損失38,187千円**。
- 月次に**減価償却費が計上されていない**（2025年11月期の通期実績6,349千円）。
- **法定福利費**が2025年12月・2026年1月にマイナス計上。7か月累計2,779千円は通期実績15,295千円に
  比して低く、期中未計上分が下期に乗る可能性がある。
- 2026年5月に**租税公課4,969千円**を一括計上しており、5月・6月は単月で営業赤字。
- **部門別損益の読み方**：共通部門に本社仕入40,994千円・外注費5,610千円が残っており、
  中央で仕入れた在庫が店舗へ振り替えられていない。したがって**店舗別の粗利・貢献利益は実態より高めに出る**
  （P.13に仮説として明記、要確認）。
- 明和店の販管費が売上高比75.6%と他のFC店（35〜40%）に比べ突出。松阪管理センターの人件費が
  含まれていると推察（棚卸表で管理センター在庫が明和店に計上されていることと整合）。
- 長期借入金は月次では期首残高のまま据え置かれており、返済額は決算時に一括計上されていると推察。

## 正常収益力（調整後EBITDA）の考え方

M&A実行後に継続的に発生しない費用を戻し入れ、継続的に必要となる費用を控除する。
経営者人件費の前提は「代表者（淺野ゆう子氏）は引継完了後に退任し、現場責任者（淺野崇氏）が
役員に就任して現行と同水準（14,400千円）の役員報酬を受ける」とした。

| 営業利益 | 2,341 | 3,022 | △19,552 |
| 減価償却費 | 3,911 | 9,295 | 6,349 |

進行期は上記のとおり減価償却費が未計上のため、調整後EBITDAは算定していない。

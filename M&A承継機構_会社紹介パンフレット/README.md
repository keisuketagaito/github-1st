# M&A承継機構 会社紹介パンフレット（東京商工リサーチ提携先向け）

東京商工リサーチの取引先企業へ配布する会社紹介パンフレット。

- **仕様**：A3横（420×297mm）二つ折り／仕上がりA4縦×4ページ
- **面付**：スライド1＝外面（左：P4裏表紙／右：P1表紙）、スライド2＝内面（左：P2／右：P3）
- **納品物**：`M&A承継機構_会社紹介パンフレット_TSR配布用_260802.pptx` ／ 同名 `.pdf`（校正用）

## 紙面構成

| ページ | 内容 |
| --- | --- |
| P1 表紙 | キャッチ「会社の未来を、次の成長へつなぐ。」／グループ表記／ヒーロービジュアル＋理念 |
| P2 | こんなお悩みはありませんか（6項目）→ 転換メッセージ → 選ばれる理由（4本）→ 実績数値 → 支援領域・業種例 |
| P3 | M&A仲介・アドバイザリー／ワンストップ支援（3領域）→ **料金体系｜完全成功報酬型＋他社比較** → 支援事例（3件・匿名化） |
| P4 裏表紙 | ご相談の流れ（4ステップ）／3つの安心／会社概要／CONTACT |

## トンマナ

コーポレートPPTテンプレート **SL_2026** のテーマカラーをそのまま使用（`ppt/theme/theme1.xml` から抽出）。

| 役割 | 色 | 用途 |
| --- | --- | --- |
| ネイビー | `#0B3041` | 主色。見出し・帯・本文濃色 |
| ミント | `#54CCB3` | 差し色。数字・強調・ブランドマーク |
| ミント（暗） | `#2E9C87` | ミントを白背景に置くとき（可読性確保） |
| グレー | `#5A6670` | 本文 |
| ライトグレー | `#8A959D` | 注記・欧文ラベル |
| 罫線 | `#D8E0E4` | 区切り |

書体は既存資料に合わせ **游ゴシック／游ゴシック Medium**（欧文ラベルと数字のみ Arial）。
pptxgenjs は `<a:latin>` しか書かないため、`src/postprocess.py` で `<a:ea>` を游ゴシックに寄せている。
これを通さないと和文が環境依存フォントに落ちる。

モチーフはロゴマークの花弁（シェブロン五角形）。小見出しの先頭マークと帯のテクスチャに使用。

## ビジュアル

素材写真が使えなかったため（下記「制約」参照）、ビジュアルはすべて `src/gen_visuals.py` で
プログラム生成している。コンセプトは **「つなぐ」— 複数の流れが収束し、ひとつの光になる**。
事業承継とM&Aの本質を抽象化したもので、金融ブランドの表現として成立させるために、
2倍スーパーサンプリング・スクリーン合成による発光・粒状ノイズを重ねている。

| ファイル | 用途 |
| --- | --- |
| `hero_cover.jpg` | P1表紙 全面 |
| `panel_dark.jpg` | P2 転換メッセージのダークパネル |
| `band_service.jpg` | P3 M&A仲介・アドバイザリー帯 |
| `band_contact.jpg` / `band_stat.jpg` | P4 CONTACT帯／P2 実績数値帯 |

## 写真差し替え時の作法（重要）

画像が乗る面はすべて **ビジュアル＋スクリム（半透明の幕）の2枚重ね** で構成している。

```
hero_cover.jpg   ← 差し替える画像
scrim_top.png    ← 上に重なる幕（天側。ロゴの可読性を確保）
scrim_cover.png  ← 上に重なる幕（地側。見出し・理念コピーの可読性を確保）
scrim_panel.png  ← 横方向の幕。左（文字が乗る側）を濃く、右の光は残す
```

コーポレートサイトの写真などに差し替える場合は **画像レイヤーだけを差し替える**。
スクリムは別レイヤーなので、どんな写真に変えても白ヌキ文字の可読性が保たれる。
スクリムを消して画像だけにすると、明るい部分に白文字が乗って必ず読めなくなる
（実際、スクリムを入れる前は光の筋が本文を貫いて読めなかった）。

濃度は `src/gen_visuals.py` の `scrim()` / `hscrim()` で調整できる。

## 再生成

```bash
cd src
python3 gen_assets.py                      # ロゴ・マーク・罫線 → assets/
python3 gen_visuals.py                     # 表紙・帯・スクリム → assets/
npm install pptxgenjs && node build.js     # → MAsg_brochure.pptx
python3 postprocess.py MAsg_brochure.pptx MAsg_final.pptx   # 和文フォント注入
```

## 制約（この版の前提）

- **コーポレートサイト `ma-sg.co.jp` を参照できていない。** 制作環境の外部通信ポリシーにより
  403で遮断され、Wayback Machine経由も不可だった。したがってトンマナは、サイトではなく
  コーポレートPPTテンプレート SL_2026 のテーマ値とロゴから導出している。
  サイトのフォント指定・キーカラー・ヒーロー写真が分かれば、そこに寄せる調整が可能。
- **ストックフォトを取得できない。** Unsplash / Pexels 等も同じポリシーで遮断されている。
- 一次情報の資料内に実写は存在するが、いずれも印刷に耐えない。
  経営者×アドバイザーの写真（協業ご提案資料 P19）は 339×375px、
  役員・メンバーの顔写真は 434〜561px 幅で、A4印刷では小さな円形カット程度にしか使えない。
  顔写真を使う場合は元データ（高解像度）の入手が前提。

| 記載 | 出典 |

## 確認・差し替えが必要な箇所

1. **QRコード**：P4裏表紙のCONTACT帯にプレースホルダを配置済み。遷移先（コーポレートサイト／専用LP）を決めて差し替える。
2. **問い合わせ導線**：現状は「東京商工リサーチのご担当者様まで」に一本化している。承継機構の直通窓口（電話・メール）を併記するかは、TSR様との役割分担を確認のうえ決定する。
3. **他社比較表**：匿名（大手A社／大手B社）で掲載し「他社条件は当社調べ。2026年8月時点」と注記済み。実名比較に変更する場合は景表法・業界自主規制の観点から法務確認が必要。
4. **支援事例**：協業ご提案資料に実名記載のある大型飲食案件（取得額約51.5億円・2026年1月成約）は、広域配布物のため社名を伏せて「成長型M&A」等の抽象記載にとどめていない（当該案件自体を不掲載）。開示可否が確認できれば、実名事例として差し替えると訴求力が上がる。
5. **表紙ビジュアル**：生成画像。コーポレートサイトの写真素材があれば差し替え推奨（上記「写真差し替え時の作法」参照）。
6. **設立年月**：一次情報に記載がないため会社概要から除外している。必要なら追記する。
7. **顔写真の活用**：役員・TSR提携室メンバーの顔写真が協業ご提案資料内にある。高解像度の元データが
   あれば、P4裏表紙に「担当チーム」を置く案も取れる（現状の4ページ構成では紙面に余裕がないため未採用）。
